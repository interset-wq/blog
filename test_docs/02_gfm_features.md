## 键盘按键

### 常用快捷键

- 保存文件: <kbd>Ctrl</kbd> + <kbd>S</kbd>
- 复制: <kbd>Ctrl</kbd> + <kbd>C</kbd>
- 粘贴: <kbd>Ctrl</kbd> + <kbd>V</kbd>
- 撤销: <kbd>Ctrl</kbd> + <kbd>Z</kbd>
- 全选: <kbd>Ctrl</kbd> + <kbd>A</kbd>

### 编辑器快捷键

在VS Code中：
- 打开命令面板: <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>P</kbd>
- 跳转到行: <kbd>Ctrl</kbd> + <kbd>G</kbd>
- 格式化代码: <kbd>Shift</kbd> + <kbd>Alt</kbd> + <kbd>F</kbd>

### 游戏控制

- 移动: <kbd>W</kbd><kbd>A</kbd><kbd>S</kbd><kbd>D</kbd>
- 跳跃: <kbd>空格</kbd>
- 攻击: <kbd>J</kbd>
- 防御: <kbd>K</kbd>
