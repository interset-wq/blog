
```python
import pandas as pd
```

## 三大对象

- **`Series`**：一维带标签数组（一列）。
- **`DataFrame`**：二维表（多列）。
- **`Index` / `columns`**：行标签 / 列标签。

```python
>>> s = pd.Series([10, 20, 30], index=['a','b','c'])
>>> s
a    10
b    20
c    30
dtype: int64
```

## 创建 DataFrame

```python
# 方式1：字典 → DataFrame（键=列名，值=列表）
>>> df = pd.DataFrame({'name': ['Alice','Bob'], 'age': [25,30]})
>>> df
    name  age
0  Alice   25
1    Bob   30

# 方式2：列表套字典（每行一个字典）
>>> df = pd.DataFrame([{'name':'Alice','age':25}, {'name':'Bob','age':30}])
>>> df
    name  age
0  Alice   25
1    Bob   30

# 方式3：读取文件
>>> df = pd.read_csv('data.csv', index_col='id')
>>> df = pd.read_excel('data.xlsx', sheet_name='Sheet1')
```

## 选取：`[]` 取列；`loc` 按标签；`iloc` 按位置

```python
>>> df
    name  age
0  Alice   25
1    Bob   30
>>> df['age'] # 或 df.age，取一列 → Series      ← SELECT age
0    25
1    30
Name: age, dtype: int64
>>> df[['name','age']]   # 取多列 → DataFrame   ← SELECT name, age
    name  age
0  Alice   25
1    Bob   30
>>> df.loc[0]            # 按行标签取一行
name    Alice
age        25
Name: 0, dtype: object
>>> df.loc[0, 'name']    # 按 [行标签, 列名] 取单元格  ← 推荐写法
'Alice'
>>> df.loc[[0], ['name','age']]   # 多行多列
    name  age
0  Alice   25
>>> df.iloc[0]           # 按位置取第 0 行
name    Alice
age        25
Name: 0, dtype: object
>>> df.iloc[:, 0]        # 取第 0 列
0    Alice
1      Bob
Name: name, dtype: object
>>> df.iloc[0, 1]        # 按位置取单元格
25
>>> df.at[0, 'name']     # 取单个值（更快）
'Alice'
>>> df.iat[0, 1]         # 按位置取单个值
25
```

> **一句话记忆**：`[]` 和 `.列名` 取列；`loc` 用标签（能取行和单元格）；`iloc` 用位置；`at/iat` 取单个值。

## 修改 / 新增 / 索引

```python
>>> df
    name  age
0  Alice   25
1    Bob   30
>>> df.loc[0, 'age'] = 31        # 改单元格（不要用 df['age'][0] 链式，易踩坑）
>>> df
    name  age
0  Alice   31
1    Bob   30
>>> df['new'] = df['age'] * 2    # 新增列  ← SELECT age*2 AS new
>>> df
    name  age  new
0  Alice   31   62
1    Bob   30   60
>>> df.reset_index()             # 索引变成普通列（分组后常用）
   index   name  age  new
0      0  Alice   31   62
1      1    Bob   30   60
>>> df.set_index('name')         # 把某列设为索引
       age  new
name
Alice   31   62
Bob     30   60
>>> df.rename(columns={'name':'姓名'})   # 改列名（详见 03）
     姓名  age  new
0  Alice   31   62
1    Bob   30   60
```
