
React Router 是一个第三方路由库，可用于为 React 应用添加路由功能。使用前，需要先在已有的 React 项目中安装该库。

```js
import { StrictMode } from "react";
import { createRoot } from "react-dom/client";
import { BrowserRouter, Routes, Route } from "react-router";
import App from "./App.jsx";

import "./index.css";

createRoot(document.getElementById("root")).render(
  <StrictMode>
    <BrowserRouter>
      <Routes>
        <Route path="/" element={<App />} />
      </Routes>
    </BrowserRouter>
  </StrictMode>
);
```

然后在 `main.jsx` 或 `index.jsx` 文件中配置路由结构，
路由配置中的 `path` 和 `element` 用于将 URL 路径与对应的 UI 组件关联。例如上述配置为根路径 `/` 绑定了 `App` 组件。

## 多视图与路由配置

在大型应用中，通常需要配置多个视图和路由。
路由配置中的 `index` 属性用于指定某个路径下的默认路由。例如，根路径 `/` 会默认渲染 `Home` 组件，`/products` 路径会默认渲染 `ProductsHome` 组件。

```js
<Routes>
  <Route index element={<Home />} />
  <Route path="about" element={<About />} />

  <Route path="products">
    <Route index element={<ProductsHome />} />
    <Route path=":category" element={<Category />} />
    <Route path=":category/:productId" element={<ProductDetail />} />
    <Route path="trending" element={<Trending />} />
  </Route>
</Routes>
```

## 嵌套路由

可以在路由内部嵌套子路由，子路由的路径会自动拼接在父路由路径之后。

```js
<Route path="products">
  <Route path="trending" element={<Trending />} />
</Route>
```

上述配置中，热门商品页面的访问路径为 `products/trending`。

### 动态路由片段

动态路由片段指的是 URL 路径中可以动态变化的部分。

```js
<Route path=":category" element={<Category />} />
```

例如，当用户访问 `products/brass-instruments` 这类 URL 时，页面会渲染 `Category` 组件，你可以根据动态片段的值动态请求对应数据。

### useParams Hook

该钩子用于从 URL 路径中获取动态参数。

```js
import { useParams } from "react-router";

export default function Category() {
  let params = useParams();
   {/* Accessing the category param: params.category */}
   {/* rest of code goes here */}
}
```
