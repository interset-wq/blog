
## 文件系统结构

Linux 使用**单一根目录树**，所有存储设备都挂载到根目录 `/` 之下。与 Windows 的 C 盘、D 盘多顶级目录不同，Linux 只有一个顶级目录，不分盘。

| 目录 | 用途 |
|---|---|
| `/` | 根目录，文件系统的顶层 |
| `/boot` | 引导文件、内核 |
| `/etc` | 系统全局配置文件 |
| `/home` | 普通用户的家目录 |
| `/root` | root 用户的家目录 |
| `/usr` | 用户程序、库与文档 |
| `/var` | 可变数据：日志、缓存、数据库 |
| `/tmp` | 临时文件，重启后清空 |
| `/dev` | 设备文件（一切皆文件） |
| `/proc` | 虚拟文件系统，内核与进程运行时信息 |
| `/sys` | 虚拟文件系统，内核设备与驱动信息 |
| `/mnt` | 手动挂载点 |
| `/media` | 自动挂载的移动设备（U 盘、光盘） |
| `/opt` | 第三方软件安装目录 |

路径：`/` 表示根目录，也用作分隔符；文件名区分大小写、不靠扩展名区分类型；以 `.` 开头的文件是隐藏文件。

## 挂载

Linux 中硬件设备也是文件，但**必须挂载之后才能使用**。挂载是把设备上的文件系统与根目录树下某个目录（挂载点）关联。

```bash
$ mount            # 查看当前所有挂载信息
$ lsblk            # 查看磁盘块设备与挂载点
$ df -h            # 查看各文件系统使用情况
```

开机自动挂载的配置写在 `/etc/fstab` 中。

## 命令格式

命令基本格式为 `命令 [选项] [参数]`，短选项以 `-` 开头（如 `ls -l`），长选项以 `--` 开头（如 `ls --all`）。命令提示符 `$` 表示普通用户、`#` 表示 root 用户。

## 路径

- **绝对路径**：以 `/` 开头，从根目录描述，如 `/etc/nginx/nginx.conf`。
- **相对路径**：不以 `/` 开头，以当前目录为起点，如 `test/a.txt`。
- 特殊路径符：`.`（当前目录）、`..`（上级目录）、`~`（当前用户家目录）。

## 目录操作

```bash
$ pwd                 # 显示当前工作目录
$ cd /etc             # 切换目录
$ cd ~                # 回到家目录
$ cd ..               # 回到上级目录
$ ls                  # 列出当前目录
$ ls -l               # 列表形式，含权限/属主/大小
$ ls -la              # 显示隐藏文件
$ mkdir testdir       # 创建目录
$ mkdir -p a/b/c      # 递归创建多级目录
$ rmdir emptydir      # 删除空目录
```

## 文件操作

```bash
$ touch file.txt      # 创建空文件，或更新时间戳
$ cp a.txt b.txt      # 复制文件
$ cp -r srcdir dstdir # 递归复制目录
$ mv old.txt new.txt  # 重命名
$ mv file.txt ~/      # 移动文件
$ rm file.txt         # 删除文件
$ rm -r testdir       # 递归删除目录
$ rm -rf testdir      # 强制递归删除（慎用）
```

> [!WARNING]
> `rm -rf` 危险，尤其以 root 身份执行时，可能误删整个系统，务必确认路径。

## 链接

- **硬链接**：多个目录项指向同一个 inode，不能跨文件系统，删除任一目录项不影响数据。
- **软链接（符号链接）**：指向文件路径的快捷方式，可跨文件系统，目标被删则失效。

```bash
$ ln original.txt hard.txt    # 硬链接
$ ln -s original.txt soft.txt # 软链接
$ ls -l                       # 软链接显示 -> 指向
```

## 查找

```bash
$ which ls            # 查看命令程序所在路径
$ find /etc -name "*.conf"   # 按文件名查找
$ find / -size +100M         # 按大小查找（+ 大于，- 小于；k/M/G 单位）
$ locate nginx        # 按数据库快速查找
```
