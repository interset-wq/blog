
> 对应 SQL：`IS NULL`、`COALESCE`、`DISTINCT`、`ORDER BY`、`LIMIT`、`ROW_NUMBER`/`RANK`。力扣空值和排序题高频。统一用下面这张小表演示（含空值与重复）：

```python
>>> df = pd.DataFrame({'name': ['Alice','Bob','Alice','Dave','Eve'],
...                    'age':  [25, 30, 25, None, 18],
...                    'city': ['北京','上海','北京','广州','上海']})
>>> df
    name   age city
0  Alice  25.0  北京
1    Bob  30.0  上海
2  Alice  25.0  北京   # 与第 0 行完全重复
3   Dave   NaN  广州   # age 缺失
4    Eve  18.0  上海
```

## 空值处理（NaN）

pandas 用 `NaN`（float）表示空值。

```python
>>> df.isna()                 # 每个位置是否为空
    name    age   city
0  False  False  False
1  False  False  False
2  False  False  False
3  False   True  False
4  False  False  False
>>> df['age'].isna().sum()    # 空值个数
1

>>> df.dropna()               # 删除含空值的行
    name   age city
0  Alice  25.0  北京
1    Bob  30.0  上海
2  Alice  25.0  北京
4    Eve  18.0  上海
>>> df.dropna(subset=['age'])  # 只按某列删（age 为空才删）

>>> df.fillna(0)              # 空值填 0
    name   age city
0  Alice  25.0  北京
3   Dave   0.0  广州          # None → 0

>>> df['age'].fillna(df['age'].mean())   # 用均值填（SQL: COALESCE）
0    25.0
1    30.0
2    25.0
3    24.5       # (25+30+25+18)/4 均值填充
4    18.0
Name: age, dtype: float64
>>> df['age'].ffill()         # 用上一个非空值填充  ← 现代写法！
0    25.0
1    30.0
2    25.0
3    25.0      # 用上一个非空值 25.0 填充
4    18.0
Name: age, dtype: float64
>>> df['age'].bfill()         # 用下一个非空值填充
0    25.0
1    30.0
2    25.0
3    18.0      # 用下一个非空值 18.0 填充
4    18.0
Name: age, dtype: float64
```

### dropna 参数详解

```python
>>> df.dropna(axis=0)            # axis=0/'index' 删行(默认)；axis=1/'columns' 删列
>>> df.dropna(how='any')         # 只要含任一 NA 就删(默认)；how='all' 全部 NA 才删
>>> df.dropna(thresh=3)          # 至少要有 3 个非 NA 值才保留该行
>>> df.dropna(subset=['name'])   # 只根据某些列判断是否缺失
# inplace=True 原地修改（新版不推荐，用 df = df.dropna(...)）
```

> ⚠️ **关键升级**：`fillna(method='ffill')` 在 pandas 2.1 废弃、2.2 删除，改 **`.ffill()` / `.bfill()`**。

## 去重与计数（DISTINCT）

```python
>>> df['city'].unique()             # 唯一值（ndarray）  ← DISTINCT
array(['北京', '上海', '广州'], dtype=object)
>>> df['city'].nunique()            # 唯一值个数  ← COUNT(DISTINCT city)
3
>>> df['city'].value_counts()       # 每个值频数  ← GROUP BY city, COUNT(*)
上海    2
北京    2
广州    1
Name: city, dtype: int64

>>> df.drop_duplicates()            # 删除整行重复
    name   age city
0  Alice  25.0  北京
1    Bob  30.0  上海
3   Dave   NaN  广州
4    Eve  18.0  上海
>>> df.drop_duplicates(subset=['name','age'])   # 按指定列去重
>>> df.drop_duplicates(subset=['city'], keep='first')  # keep: first/last/False
    name   age city
0  Alice  25.0  北京
1    Bob  30.0  上海
3   Dave   NaN  广州
```

> `drop_duplicates(subset=...)`：`subset` 按哪些列判重（缺省=所有列）；`keep='first'` 保留首个（默认）/`'last'` 保留末个/`False` 全删重复。

## 排名（窗口函数 RANK / DENSE_RANK / ROW_NUMBER）

```python
>>> # 用一张带并列分数的表演示
>>> s = pd.Series([90, 80, 90, 70])
>>> s.rank(method='average', ascending=False)   # 默认：同分取平均
0    1.5
1    3.0
2    1.5
3    4.0
dtype: float64
>>> s.rank(method='min',    ascending=False)    # 同分并列取最小 → RANK
0    1.0
1    3.0
2    1.0
3    4.0
dtype: float64
>>> s.rank(method='dense',  ascending=False)    # 名次连续 → DENSE_RANK
0    1.0
1    2.0
2    1.0
3    3.0
dtype: float64
>>> s.rank(method='first',  ascending=False)    # 同分按顺序 → ROW_NUMBER
0    1.0
1    3.0
2    2.0
3    4.0
dtype: float64
```

> **同分（两个 90）时四种 method 的差别**：`min` 两并列都取第 1、下一个是第 3（跳过 2，RANK）；`dense` 两并列取第 1、下一个是第 2（连续，DENSE_RANK）；`first` 按出现顺序给 1、2（ROW_NUMBER）；`average` 给 1.5（平均）。

### 真题实例：分数排名（密集排名）

```python
>>> scores['rank'] = scores.score.rank(method='dense', ascending=False)
>>> df = scores.sort_values('rank')[['score','rank']]
# SQL: DENSE_RANK() OVER (ORDER BY score DESC)
```
