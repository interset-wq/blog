
## 软件包类型

| 类型 | 说明 |
|---|---|
| 源码包（Tarball） | `tar.gz` 压缩源码，需先编译为二进制再安装 |
| 二进制包 | 已编译，直接安装；分 RPM（红帽系）与 DPKG（Debian 系）两大体系 |

## Ubuntu / Debian 系：apt

`apt` 是 Ubuntu 主包管理器（基于 DPKG），需 root 权限（用 `sudo`）。

```bash
$ sudo apt update                # 更新软件源索引
$ sudo apt upgrade               # 升级所有可升级软件
$ sudo apt install nginx         # 安装
$ sudo apt remove nginx          # 卸载（保留配置）
$ sudo apt purge nginx           # 卸载并清除配置
$ apt search nginx               # 搜索
$ apt show nginx                 # 查看软件信息
$ apt list --installed           # 列出已安装
```

DPKG 底层命令：`dpkg -i xxx.deb`（安装）、`dpkg -r`（卸载）、`dpkg -l`（列出）。

## CentOS / RHEL 系：dnf / yum / rpm

红帽系早期用 `yum`，新版（RHEL 8+/CentOS Stream）用 `dnf`（更快，语法兼容 yum）。两者都基于 **rpm** 包管理。

```bash
# dnf 与 yum 用法一致
$ sudo dnf install nginx
$ sudo dnf remove nginx
$ sudo dnf search nginx
$ sudo dnf update
$ sudo dnf list installed
```

rpm 底层命令：

```bash
$ rpm -ivh package.rpm      # 安装（i 安装 v 详情 h 进度）
$ rpm -Uvh package.rpm      # 升级（U 未装则装、F 未装不装）
$ rpm -e 包名               # 卸载
$ rpm -q 包名               # 查询是否安装
$ rpm -qa | grep nginx      # 列出所有已装并过滤
$ rpm -ql 包名              # 列出安装的所有文件
$ rpm -qf /bin/ls           # 查文件属于哪个包
```

> [!NOTE]
> rpm 安装/升级用**包全名**（带版本号），查询/卸载用**包名**，两者容易混淆。rpm 通过本地文件安装，不是联网安装；`yum`/`dnf` 会自动解析依赖联网安装。

## 源码编译安装

```bash
$ wget https://example.com/app.tar.gz
$ tar -zxvf app.tar.gz
$ cd app
$ ./configure --prefix=/usr/local/app
$ make
$ sudo make install
```

## 手动下载的二进制包

```bash
$ wget -O node.tar.xz https://nodejs.org/dist/xxx.tar.xz
$ tar -xf node.tar.xz -C /opt/
$ export PATH=/opt/node/bin:$PATH    # 加入 PATH
```

## 版本管理工具

| 工具 | 用途 |
|---|---|
| `snap` | Ubuntu 沙箱化应用安装 |
| `flatpak` | 跨发行版沙箱应用 |
| `pip` / `npm` / `cargo` | 各语言生态包管理器 |
| `docker` | 容器化应用分发 |

Ubuntu 同时保留 APT 与 DNF/YUM 两套生态的说明，实际按发行版选用对应命令。
