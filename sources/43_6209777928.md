
> 对应 SQL：`INNER/LEFT/RIGHT/FULL JOIN`、`UNION ALL`。统一用下面两张表演示：

```python
>>> df1 = pd.DataFrame({'id': [1, 2, 3], 'name': ['Alice','Bob','Carol']})
>>> df2 = pd.DataFrame({'id': [2, 3, 4], 'dept': ['研发','运营','市场']})
>>> df1
   id   name
0   1  Alice
1   2    Bob
2   3  Carol
>>> df2
   id  dept
0   2   研发
1   3   运营
2   4   市场
```

## merge —— SQL JOIN

```python
>>> pd.merge(df1, df2, on='id')               # INNER JOIN ... ON id（默认 how='inner'）
   id   name dept
0   2    Bob   研发
1   3  Carol   运营

>>> pd.merge(df1, df2, how='left',  on='id')  # LEFT JOIN：左表全保留，无匹配填 NaN
   id   name  dept
0   1  Alice   NaN
1   2    Bob   研发
2   3  Carol   运营

>>> pd.merge(df1, df2, how='right', on='id')  # RIGHT JOIN：右表全保留
   id   name  dept
0   2    Bob   研发
1   3  Carol   运营
2   4    NaN   市场

>>> pd.merge(df1, df2, how='outer', on='id')  # FULL OUTER JOIN：两边全保留
   id   name  dept
0   1  Alice   NaN
1   2    Bob   研发
2   3  Carol   运营
3   4    NaN   市场
```

```python
# 连接键列名不同
>>> df3 = pd.DataFrame({'key': [2, 3], 'score': [88, 95]})
>>> pd.merge(df1, df3, left_on='id', right_on='key')
   id   name  key  score
0   2    Bob    2     88
1   3  Carol    3     95
# 多键连接：on=['id','dept'] 两个键都匹配才算
# suffixes=('','_prev')：同名列加后缀区分，默认 _x/_y
```

也可以用 `df1.merge(df2, ...)` 调用，效果相同。

### 真题实例 1：LEFT JOIN + 空值筛（找没下过单的顾客）

```python
# customers: id, name ；orders: id, customerId
>>> df = customers.merge(orders, left_on='id', right_on='customerId', how='left')
>>> df = df[df['customerId'].isna()]          # LEFT JOIN 中右表键为空的 = 未匹配
>>> df = df[['name']].rename(columns={'name': 'customer'})
# SQL: SELECT name AS customer FROM customers c
#      LEFT JOIN orders o ON c.id=o.customerId WHERE o.customerId IS NULL
```

### 真题实例 2：进店却未交易（LEFT JOIN + isna + 分组计数）

```python
# visits: visit_id, customer_id ；transactions: transaction_id, visit_id, amount
>>> df = visits.merge(transactions, on='visit_id', how='left')
>>> df = df[df.transaction_id.isna()]                     # 没发生交易的访问
>>> df = df.groupby('customer_id', as_index=False).size() # 按顾客计数
>>> df = df.rename(columns={'size': 'count_no_trans'})
# SQL: SELECT v.customer_id, COUNT(*) FROM visits v
#      LEFT JOIN transactions t ON v.visit_id=t.visit_id
#      WHERE t.visit_id IS NULL GROUP BY v.customer_id
```

### 真题实例 3：每个部门工资最高的员工（merge + transform）

```python
# employee: id, name, salary, departmentId ；department: id, name
>>> df = employee.merge(department, left_on='departmentId', right_on='id', how='left')
>>> df = df.rename(columns={'name_x':'Employee','name_y':'Department','salary':'Salary'})
>>> max_salary = df.groupby('Department')['Salary'].transform('max')   # 每组最大值广播回每行
>>> df = df[df.Salary == max_salary]
>>> df = df[['Department','Employee','Salary']]
# SQL: 用 WHERE (DepartmentId, Salary) IN (SELECT DepartmentId, MAX(Salary) GROUP BY ...)
```

### 真题实例 4：温度比前一天高（自连接 + 日期偏移）

```python
# Weather: id, recordDate, temperature
>>> weather_prev = weather.copy()
>>> weather_prev['recordDate'] += pd.Timedelta(days=1)   # 昨天的数据日期+1 对齐今天
>>> merged = weather.merge(weather_prev, on='recordDate', how='left',
...                        suffixes=('', '_prev'))
>>> res = merged[merged['temperature'] > merged['temperature_prev']][['id']]
# SQL: JOIN Weather w2 ON w.recordDate = w2.recordDate + INTERVAL 1 DAY
#      WHERE w.temperature > w2.temperature
```

### 经典套路：找出"两表信息对不上/缺失"的记录

力扣 2892 "Employees With Missing Information" 这类题：用 `indicator=True` 看每行来自哪张表。

```python
>>> merged = pd.merge(df1, df2, how='outer', on='id', indicator=True)
>>> merged
   id   name  dept      _merge
0   1  Alice   NaN   left_only
1   2    Bob   研发        both
2   3  Carol   运营        both
3   4    NaN   市场  right_only
>>> result = merged[merged['_merge'] != 'both']   # 只保留不是两边都有的行
```

`_merge` 列取值：`left_only` / `right_only` / `both`。

### 连接后处理

```python
# 合并后可能产生同名列（如 name_x / name_y），用 rename 或直接取需要列
>>> merged['name_x']  # 左表的 name
>>> merged = merged.drop(columns=['name_y'])
```

## concat —— UNION / 上下拼接 / 左右拼列

```python
>>> pd.concat([df1, df2], ignore_index=True)   # 上下拼接（行方向）← UNION ALL ← 力扣 2888
   id   name  dept
0   1  Alice   NaN
1   2    Bob   NaN
2   3  Carol   NaN
3   2    NaN   研发
4   3    NaN   运营
5   4    NaN   市场

>>> pd.concat([df1, df2], axis=1)              # 左右拼接（列方向）
   id   name  id  dept
0   1  Alice   2   研发
1   2    Bob   3   运营
2   3  Carol   4   市场
```

## merge vs concat 怎么选

| 需求 | 工具 |
|---|---|
| 按某列对齐合并（像 SQL JOIN） | `df.merge(...)` |
| 行方向堆叠（UNION ALL） | `pd.concat([...])` |
| 列方向拼接（把几张表并排） | `pd.concat([...], axis=1)` |

## 一页速览

```python
>>> pd.merge(a, b, on='k', how='left')              # JOIN
>>> pd.merge(a, b, left_on='x', right_on='y', how='left')   # 键名不同
>>> pd.merge(a, b, how='outer', on='k', indicator=True)
>>> pd.concat([a, b], ignore_index=True)            # UNION ALL
>>> pd.concat([a, b], axis=1)                       # 并排
```
