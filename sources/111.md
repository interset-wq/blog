# Tailwind CSS

Tailwind 是**实用优先（Utility-First）** 的 CSS 框架。你无需编写自定义 CSS 规则，而是通过在 HTML 中组合小的实用类来构建设计，快速搭建界面且风格统一。

## 一、核心概念

- **实用类（Utilities）**：每个类只做一件事，如 `p-4`（内边距 1rem）、`text-center`（居中）、`bg-blue-500`（背景色）。
- **组合构建**：一个元素可堆叠多个实用类，避免为每个组件写 CSS 类名和样式规则。
- **按需生成**：Tailwind 只编译你在源码中实际用到的类，产物体积小（配合 `content` 扫描配置）。
- **设计系统**：内置基于 `rem` 的间距比例、调色板、断点等，保证设计一致性。

> 与传统「写 CSS 类名 → 单独定义样式」相比，Tailwind 在 HTML 内就地组合，改样式不必在 CSS 文件间来回跳转。

## 二、安装与配置

### 1. CDN 快速体验（学习/原型）

```html
<script src="https://cdn.tailwindcss.com"></script>
```

### 2. 项目集成（生产推荐）

以 Vite + PostCSS 为例：

```bash
$ npm install tailwindcss @tailwindcss/postcss postcss
```

`postcss.config.js`：

```js
export default {
  plugins: {
    "@tailwindcss/postcss": {},
  },
};
```

CSS 入口（如 `index.css`）引入：

```css
@import "tailwindcss";
```

### 3. 配置文件

Tailwind 扫描源码中出现的类名，按需生成样式：

```js
// tailwind.config.js
export default {
  content: ["./index.html", "./src/**/*.{js,ts,jsx,tsx}"],
  theme: {
    extend: {
      colors: { brand: "#3498eb" },
      spacing: { 18: "4.5rem" },
    },
  },
};
```

> [!IMPORTANT]
> `content` 数组必须包含所有用到类名的文件；漏配会导致类不生效（类被「裁剪」掉）。

## 三、响应式设计

Tailwind 使用断点前缀在不同屏幕尺寸应用样式。默认断点：

| 前缀 | 最小宽度 |
|---|---|
| `sm:` | 640px |
| `md:` | 768px |
| `lg:` | 1024px |
| `xl:` | 1280px |
| `2xl:` | 1536px |

断点遵循**移动优先**：无前缀的类作用于所有尺寸，加前缀的类在该断点及以上生效。

```html
<div class="w-full md:w-1/2 lg:flex-row">
  Responsive layout
</div>
```

- `w-full`：默认占满整行
- `md:w-1/2`：≥768px 时占一半宽
- `lg:flex-row`：≥1024px 时改为横向排列

## 四、Flexbox 工具类

类如 `flex`、`flex-col`、`justify-around`、`items-center` 让创建灵活布局变得简单。

```html
<div class="flex flex-col md:flex-row justify-around items-center">
  <p>Column on small screens</p>
  <p>Row on medium and larger screens</p>
</div>
```

| 类别 | 常用类 | 作用 |
|---|---|---|
| 容器 | `flex` / `inline-flex` | 开启弹性布局 |
| 方向 | `flex-row` / `flex-col` | 主轴方向 |
| 对齐 | `items-center` / `items-start` | 交叉轴对齐 |
| 排列 | `justify-center` / `justify-between` / `justify-around` | 主轴排列 |
| 伸缩 | `flex-1` / `flex-grow` / `shrink-0` | 占位伸缩 |

## 五、网格工具类

Tailwind 内置 CSS Grid 工具类，如 `grid`、`grid-cols-1`、`md:grid-cols-3`。

```html
<div class="grid grid-cols-1 md:grid-cols-3 gap-8">
  <div class="bg-gray-100 p-4">Column 1</div>
  <div class="bg-gray-100 p-4">Column 2</div>
  <div class="bg-gray-100 p-4">Column 3</div>
</div>
```

常用：`grid-cols-{n}`（列数）、`gap-{n}`（间距）、`col-span-{n}`（跨列）、`row-span-{n}`（跨行）、`place-items-center`（整体居中）。

## 六、间距工具类

工具类如 `mt-8`、`mx-auto`、`p-4`、`gap-4` 帮助创建一致间距，无需编写 CSS。

```html
<div class="mt-8 p-4 bg-indigo-600 text-white">
  Spaced content
</div>
```

| 方向前缀 | 含义 |
|---|---|
| `m-` / `p-` | 四边外边距 / 内边距 |
| `mt-` `mb-` `ml-` `mr-` | 上 / 下 / 左 / 右 |
| `mx-` / `my-` | 水平 / 垂直 |
| `gap-` | 网格 / 弹性子项间距 |

数字按 `rem` 比例递增：`p-4` = 1rem、`p-8` = 2rem；`mx-auto` 让块级元素水平居中。

## 七、排版工具类

工具类如 `uppercase`、`font-bold`、`font-semibold`、`text-4xl` 控制文本外观。可设置在断点处调整的字体大小：

```html
<h1 class="text-3xl md:text-5xl font-semibold text-center">
  Responsive Heading
</h1>
```

- 字号：`text-xs` ~ `text-9xl`，或任意值 `text-[20px]`
- 字重：`font-thin` / `font-normal` / `font-semibold` / `font-bold`
- 大小写：`uppercase` / `lowercase` / `capitalize`
- 对齐：`text-left` / `text-center` / `text-right`
- 行高/字距：`leading-{n}`、`tracking-{n}`

## 八、颜色与交互状态

Tailwind 提供丰富调色板，如 `text-red-700`、`bg-indigo-600`、`bg-gray-100`。颜色编号 50~950（50 最浅、950 最深）。

状态前缀让交互效果简单实现：

| 前缀 | 触发时机 |
|---|---|
| `hover:` | 鼠标悬停 |
| `focus:` | 获得焦点 |
| `active:` | 被按下 |
| `disabled:` | 禁用状态 |
| `group-hover:` | 父级（group）悬停时 |

```html
<a href="#" class="bg-pink-500 hover:bg-pink-600 text-white px-4 py-2 rounded-md">
  Hover Me
</a>
```

## 九、边框、环和效果

- **边框**：`border-2 border-red-300` 添加指定厚度和颜色的边框。
- **环**：`ring-1 ring-gray-300` 创建类似轮廓的效果（box-shadow），常用于聚焦或卡片高亮。
- **圆角与缩放**：`rounded-md`、`rounded-xl`、`scale-105` 增加细节润色。

```html
<div class="p-6 rounded-xl ring-2 ring-fuchsia-500 scale-105">
  Highlighted card
</div>
```

其他效果：`shadow-md` / `shadow-lg`（阴影）、`transition` / `duration-300`（过渡）、`opacity-{n}`（透明度）。

## 十、渐变

Tailwind 支持渐变工具类，如 `bg-gradient-to-r from-fuchsia-500 to-indigo-600`：

```html
<div class="p-4 text-white bg-gradient-to-r from-fuchsia-500 to-indigo-600">
  Gradient background
</div>
```

- 方向：`bg-gradient-to-r`（右）/ `-l` / `-t` / `-b` / `-tr` / `-bl`…
- 起止色：`from-{color}`、`via-{color}`（中间过渡）、`to-{color}`

## 十一、暗黑模式

配合 `dark` 前缀按暗黑模式切换样式（需在 `tailwind.config.js` 配置 `darkMode: "class"` 或 `"media"`）：

```html
<div class="bg-white dark:bg-slate-900 text-black dark:text-white">
  Content
</div>
```

## 十二、进阶：复用样式

避免重复长类名组合，可用 `@apply` 在 CSS 中封装：

```css
.btn-primary {
  @apply bg-indigo-600 hover:bg-indigo-700 text-white px-4 py-2 rounded-md;
}
```

## 核心总结

1. Tailwind 是**实用优先**框架，用类组合构建设计，按需生成、风格统一。
2. 响应式用 `sm/md/lg/xl` 前缀，移动优先。
3. 布局核心：Flexbox（`flex`、`justify-*`、`items-*`）与 Grid（`grid-cols-*`、`gap-*`）。
4. 视觉：间距（`m/p`）、排版（`text-*`、`font-*`）、颜色与状态（`hover:` 等）、边框/环/圆角/阴影、渐变、暗黑模式。
5. 生产用 `content` 扫描 + `@apply` 复用，避免重复类名。
