
DRF 的视图层从简到繁有四个层级，按需选用：

| 层级 | 基类 | 适用场景 |
|---|---|---|
| 函数视图 | `@api_view` 装饰器 | 逻辑简单、自定义程度高 |
| 类视图 | `APIView` | 基础类视图，手动写 get/post |
| 泛型视图 | `GenericAPIView` + Mixin | 按配置自动生成 CRUD |
| 视图集 | `ViewSet` / `ModelViewSet` | 一个类包办 list/retrieve/create/update/destroy |

本系列主示例取自项目 `backend/api/views.py`（Learning Log 的两个 ViewSet 与一个注册视图），非项目内的写法用"通用示例"补全。

## 函数视图：@api_view

用 `@api_view` 装饰器把普通函数变成 DRF 视图，支持声明允许的 HTTP 方法：

```python
# 通用示例（非项目代码）
from rest_framework.decorators import api_view
from rest_framework.response import Response
from rest_framework import status
from .models import Music
from .serializers import MusicSerializer


@api_view(['GET', 'POST'])
def music_list(request):
    if request.method == 'GET':
        musics = Music.objects.all()
        serializer = MusicSerializer(musics, many=True)
        return Response(serializer.data)

    elif request.method == 'POST':
        serializer = MusicSerializer(data=request.data)
        if serializer.is_valid():
            serializer.save()
            return Response(serializer.data, status=status.HTTP_201_CREATED)
        return Response(serializer.errors, status=status.HTTP_400_BAD_REQUEST)
```

`@api_view` 自动处理：请求体解析（`request.data` 替代 `request.POST`）、内容协商、响应渲染。

## APIView

`APIView` 是 DRF 最基础的类视图，与 Django 的 `View` 对应，但多了认证、权限、限流、内容协商等能力。

```python
# 通用示例（非项目代码）
from rest_framework.views import APIView
from rest_framework.response import Response
from rest_framework import status
from .models import Music
from .serializers import MusicSerializer


class MusicList(APIView):
    def get(self, request, format=None):
        musics = Music.objects.all()
        serializer = MusicSerializer(musics, many=True)
        return Response(serializer.data)

    def post(self, request, format=None):
        serializer = MusicSerializer(data=request.data)
        if serializer.is_valid():
            serializer.save()
            return Response(serializer.data, status=status.HTTP_201_CREATED)
        return Response(serializer.errors, status=status.HTTP_400_BAD_REQUEST)
```

## GenericAPIView + Mixin

`GenericAPIView` 提供通用的查询集与序列化器配置，配合五个 Mixin 自动获得 CRUD 行为：

| Mixin | 提供的方法 | 对应 HTTP 行为 |
|---|---|---|
| `ListModelMixin` | `list()` | GET 列表 |
| `CreateModelMixin` | `create()` | POST 创建 |
| `RetrieveModelMixin` | `retrieve()` | GET 单对象 |
| `UpdateModelMixin` | `update()` | PUT / PATCH 更新 |
| `DestroyModelMixin` | `destroy()` | DELETE 删除 |

```python
# 通用示例（非项目代码）
from rest_framework import generics, mixins
from .models import Music
from .serializers import MusicSerializer


class MusicListCreate(mixins.ListModelMixin,
                      mixins.CreateModelMixin,
                      generics.GenericAPIView):
    queryset = Music.objects.all()
    serializer_class = MusicSerializer

    def get(self, request, *args, **kwargs):
        return self.list(request, *args, **kwargs)

    def post(self, request, *args, **kwargs):
        return self.create(request, *args, **kwargs)
```

更常用的是直接用 DRF 预组合好的泛型视图：`ListCreateAPIView`、`RetrieveUpdateDestroyAPIView` 等，一行配置搞定。项目的 `RegisterView` 就用到了 `CreateAPIView`：

```python
# 项目 backend/api/views.py：注册视图
from django.contrib.auth.models import User
from rest_framework import generics, permissions

from .serializers import UserCreateSerializer


class RegisterView(generics.CreateAPIView):
    """注册新用户（匿名可访问），成功返回用户数据不发 token。"""

    queryset = User.objects.all()
    serializer_class = UserCreateSerializer
    permission_classes = [permissions.AllowAny]
```

`permission_classes = [permissions.AllowAny]` 覆盖了全局的 `IsAuthenticated`，允许未登录的匿名用户调用注册接口。

## ViewSet 与 ModelViewSet

`ViewSet` 把一组相关操作（list / retrieve / create / update / destroy）打包到一个类里，配合 Router 自动生成路由。`ModelViewSet` 是最常用的子类，**全自动获得完整 CRUD**。

### 项目实例：TopicViewSet 与 EntryViewSet

> 示例：项目 `backend/api/views.py`

```python
from django.db.models import Count
from rest_framework import permissions, viewsets

from learning_logs.models import Topic, Entry
from .serializers import (
    EntrySerializer,
    TopicSerializer,
)
from .permissions import IsOwnerOrReadOnly


class TopicViewSet(viewsets.ModelViewSet):
    """主题 CRUD API：仅本人数据，owner 由视图注入。"""

    queryset = Topic.objects.all()
    serializer_class = TopicSerializer
    permission_classes = [permissions.IsAuthenticated, IsOwnerOrReadOnly]

    def get_queryset(self):
        return Topic.objects.filter(owner=self.request.user).annotate(
            entry_count=Count('entry')
        ).order_by('-date_added')

    def perform_create(self, serializer):
        serializer.save(owner=self.request.user)


class EntryViewSet(viewsets.ModelViewSet):
    """条目 CRUD API：仅本人主题下的条目，支持 ?topic=<id> 过滤。"""

    queryset = Entry.objects.all()
    serializer_class = EntrySerializer
    permission_classes = [permissions.IsAuthenticated, IsOwnerOrReadOnly]

    def get_queryset(self):
        qs = Entry.objects.filter(topic__owner=self.request.user).order_by('-date_added')
        topic_id = self.request.query_params.get('topic')
        if topic_id:
            qs = qs.filter(topic_id=topic_id)
        return qs
```

`permission_classes = [permissions.IsAuthenticated, IsOwnerOrReadOnly]` 是权限列表：认证后仍需通过自定义权限（详见「DRF 权限分页与过滤」一篇）。

### ViewSet 常用可重写方法

| 方法 | 作用 | 典型用途 |
|---|---|---|
| `get_queryset()` | 返回查询集 | 数据隔离（只返回当前用户的数据） |
| `get_serializer_class()` | 返回序列化器类 | 按 action 切换不同序列化器 |
| `get_permissions()` | 返回权限实例列表 | 按 action 动态决定权限 |
| `perform_create(serializer)` | 创建保存前钩子 | 自动注入当前用户到外键字段 |
| `perform_update(serializer)` | 更新保存前钩子 | 更新时补字段 |

上例 `TopicViewSet` 就覆盖了 `get_queryset()`（`filter(owner=...)` 数据隔离 + `annotate` 附带条目计数）和 `perform_create()`（`serializer.save(owner=self.request.user)` 注入 owner）。

> 数据隔离注意：`get_queryset()` 只是"不返回别人的数据"；写入路径还需配合 `perform_create` 注入 owner、权限类做对象级校验，三者结合才完整。

### 动态权限：get_permissions

```python
# 通用示例（非项目代码）
from rest_framework import viewsets, permissions


class ShareViewSet(viewsets.ModelViewSet):
    def get_permissions(self):
        if self.action in ('create',):
            self.permission_classes = [permissions.IsAuthenticated]
        return [permission() for permission in self.permission_classes]
```

`self.action` 是当前 action 名（`list` / `create` / `retrieve` / `update` / `partial_update` / `destroy` 或自定义 `@action` 名）。

### 自定义 action：@action

新版 DRF 用 `@action` 装饰器给 ViewSet 加自定义端点：

```python
# 通用示例（非项目代码）
from rest_framework.decorators import action
from rest_framework.response import Response


class MusicViewSet(viewsets.ModelViewSet):
    queryset = Music.objects.all()
    serializer_class = MusicSerializer

    @action(detail=True, methods=['get'])
    def detail(self, request, pk=None):
        music = get_object_or_404(Music, pk=pk)
        return Response({'singer': music.singer, 'song': music.song})

    @action(detail=False, methods=['get'])
    def all_singer(self, request):
        singers = Music.objects.values_list('singer', flat=True).distinct()
        return Response(singers)
```

`@action` 的 `detail=True` 表示路由是 `/<前缀>/{pk}/<方法名>/`（单对象级），`detail=False` 表示 `/<前缀>/<方法名>/`（列表级）。
