
## 概览

C 是一门**过程式**、编译型语言，强调底层控制与可移植性。它是 C++ 的前身，C++ 几乎兼容全部 C 语法。

| 特性 | 说明 |
| --- | --- |
| 编译型 | 需先编译（`gcc`）再运行 |
| 静态类型 | 变量类型编译期确定 |
| 手动内存管理 | 用 `malloc`/`free` 手动分配释放 |
| 过程式 | 以函数为组织单位，无类/对象 |

## 编译与运行

```bash
gcc main.c -o main
./main
```

### C 程序基本格式

```c
#include <stdio.h>
int main(void)
{
    语句
    return 0;
}
```

## 基本语法

### 变量命名规则

- 可以用小写字母、大写字母、数字和下划线（`_`）来命名；名称的第 1 个字符必须是字母或下划线，不能是数字
- 谨慎使用单下划线和双下划线开头的变量名：操作系统和 C 库经常用这种方式命名，容易冲突
- 区分大小写
- 为了更好的兼容性，变量命名常放在其他代码块的上方

### 提高程序可读性

- 变量名见名知意
- 适当使用注释
- 适当使用空行分隔
- 一行一条语句

### 变量与基本类型

| 类型 | 说明 | 典型大小 |
| --- | --- | --- |
| `int` | 整型 | 4 字节 |
| `float` / `double` | 单/双精度浮点 | 4 / 8 字节 |
| `char` | 单个字符 | 1 字节 |
| `bool`（来自 `<stdbool.h>`） | 布尔（true/false） | 1 字节 |
| `long` / `long long` | 更大整型 | 8 字节 |

> **布尔类型用 `<stdbool.h>` 的 `bool`**：C99 原生提供的是 `_Bool`（`0`/`1`），`<stdbool.h>` 把 `bool`、`true`、`false` 定义为别名，写法更直观。使用前需 `#include <stdbool.h>`。此外 C99 还有 `_Complex`（复数）与 `_Imaginary`（虚数），用于科学计算场景。

```c
#include <stdio.h>
#include <stdbool.h>

int main(void) {
    int age = 25;
    double price = 19.99;
    char grade = 'A';
    bool isAdult = age >= 18;   // bool + true/false

    printf("Age: %d, Price: %.2f, Grade: %c\n", age, price, grade);
    printf("Adult: %d\n", isAdult);  // 1（true）
    return 0;
}
```

#### 进制、修饰符与 printf 格式说明符

- 进制：字面量默认十进制，用 `%d` 打印；`0x`/`0X` 前缀是十六进制，`%x`/`%X` 打印，`%#x` 显示前缀；`0` 前缀是八进制，`%o` 打印，`%#o` 显示前缀
- `short`（短整型）：可能比 `int` 更省内存，范围更小；`%hd`（十进制）、`%ho`（八进制）
- `long`（长整型）：可能占更多内存、范围更大；字面量加后缀 `l` 或 `L`；`%ld`（十进制）、`%lx`（十六进制）、`%lo`（八进制）
- `long long`：更长的有符号长整型，字面量后缀 `ll` 或 `LL`
- `unsigned`（无符号整型）：只表示非负数；`%u`
- 浮点：`float` 字面量加后缀 `f`/`F`；`%f` 十进制计数法、`%e` 指数计数法；代码里的小数默认是 `double`；`long double` 精度更高

### 字符与转义字符

`char` 实际上是较小的整数：例如 ASCII 码 0~127，字符 `'A'` 存储的其实是 65；所有平台上 `char` 都占 1 字节，用单引号包裹，`%c` 打印。C 语言没有字符串类型（字符串见下文）。

常用转义字符：

| 转义字符 | 含义 |
| --- | --- |
| `\n` | 换行 |
| `\t` | 水平制表符 |
| `\r` | 回车 |
| `\\` | 反斜杠 |
| `\'` | 单引号 |
| `\"` | 双引号 |
| `\0` | 空字符（字符串结尾标志） |

### 位、字节与字

- 位（bit）是最小的存储单元，表示一个二进制数 0 或 1
- 1 byte（字节）= 8 bit
- 64 位系统的字长是 64；字长越大，数据转移越快，允许访问的内存也越多

### 数组

```c
int nums[5] = {1, 2, 3, 4, 5};
int matrix[2][3] = {{1, 2, 3}, {4, 5, 6}};

printf("%d\n", nums[0]);   // 1
printf("%d\n", matrix[1][2]); // 6
```

> 数组名本质是指向首元素的指针，且**不携带长度**信息。

### 指针

指针保存内存地址，是 C 的核心特性。

```c
int x = 10;
int *p = &x;   // p 指向 x 的地址

printf("%d\n", *p);  // 解引用，输出 10
*p = 20;             // 通过指针修改 x
```

### 结构体（struct）

把多个相关变量打包为一个复合类型。

```c
#include <stdio.h>

struct Student {
    char name[50];
    int age;
    float gpa;
};

int main(void) {
    struct Student s = {"Alice", 20, 3.8};
    printf("%s is %d years old\n", s.name, s.age);
    return 0;
}
```

### 枚举（enum）

**枚举**为一组具名的整型常量，提高可读性、避免魔法数字。

```c
#include <stdio.h>

// 定义枚举：值默认从 0 递增
enum Day { MON, TUE, WED, THU, FRI, SAT, SUN };

// 可显式指定值
enum Status { OK = 200, NOT_FOUND = 404, ERROR = 500 };

int main(void) {
    enum Day today = WED;
    printf("%d\n", today);   // 2（默认从 0 递增）
    printf("%d\n", ERROR);   // 500

    if (today == WED) {
        printf("It's Wednesday\n");
    }
    return 0;
}
```

**要点**：

- 默认第一个成员为 `0`，之后逐个递增；可手动指定任意值
- 枚举值是 `int` 型，可参与比较、算术、switch
- 配合 `typedef` 使用更简洁：`typedef enum { RED, GREEN, BLUE } Color;` 之后可直接用 `Color c = RED;`

```c
#include <stdio.h>

typedef enum { RED, GREEN, BLUE } Color;

int main(void) {
    Color c = GREEN;
    switch (c) {
        case RED:   printf("red\n"); break;
        case GREEN: printf("green\n"); break;
        case BLUE:  printf("blue\n"); break;
    }
    return 0;
}
```

### typedef（类型别名）

`typedef` 为已有类型定义**别名**，简化复杂类型声明，让代码更可读。

```c
#include <stdio.h>

typedef unsigned int uint;          // uint 是 unsigned int 的别名
typedef struct Point {              // 结构体别名：之后免写 struct
    int x, y;
} Point;
typedef int (*FuncPtr)(int, int);   // 函数指针别名

int main(void) {
    uint n = 100;
    Point p = {3, 4};
    printf("%u (%d,%d)\n", n, p.x, p.y);
    return 0;
}
```

**要点**：

- 本质是"起别名"，**不创建新类型**，不占额外内存
- 常用于：`struct` 免写关键字、函数指针、平台相关的定宽类型（如 `int32_t` 就是 typedef 实现）
- 与 `#define` 区别：`typedef` 由编译器处理、有类型检查；`#define` 是纯文本替换、无类型检查

## 函数

```c
#include <stdio.h>

// 返回较大者
int max(int a, int b) {
    return a > b ? a : b;
}

int main(void) {
    printf("%d\n", max(3, 7)); // 7

```

### 函数指针

```c
int add(int a, int b) { return a + b; }

int (*func)(int, int) = add;  // 函数指针
printf("%d\n", func(2, 3));   // 5
```

#### 实际用途：回调（把函数作为参数传给别人调用）

函数指针最常见的用法是**回调**：写一个通用函数，参数里接收"一个函数指针"，让它去调用我们传入的函数，从而让通用代码"不知道具体逻辑也能跑"。

```c
#include <stdio.h>

typedef int (*Op)(int, int);   // 给"函数指针类型"起别名 Op（见上面的讲解）

// 通用计算器：把"怎么算"交给传入的函数 decide
int apply(int a, int b, Op fn) {
    return fn(a, b);           // 调用传入的那个函数
}

int add(int a, int b) { return a + b; }
int sub(int a, int b) { return a - b; }

int main(void) {
    printf("%d\n", apply(5, 3, add));   // 8 —— 传 add，就算加法
    printf("%d\n", apply(5, 3, sub));   // 2 —— 传 sub，就算减法
    return 0;
}
```

> 这里 `apply` 函数本身不关心是加法还是减法，它只负责"调用你给它的函数"。把 `add`/`sub` 传进去，行为就变了——这就是回调：**定义行为的人和使用行为的人解耦**。C 标准库里的 `qsort` 排序就需要你传一个比较函数，正是回调的经典应用。

再举一个 C 语言里回调的"必经之路"——用 `qsort` 排序时，必须自己写比较函数并传进去：

```c
#include <stdio.h>
#include <stdlib.h>

// 比较函数：返回 <0 / 0 / >0 表示 a 在前/相等/b 在前
int cmp_int(const void *a, const void *b) {
    return *(int *)a - *(int *)b;   // 升序
}

int main(void) {
    int arr[] = {3, 1, 4, 1, 5};
    int n = 5;
    qsort(arr, n, sizeof(int), cmp_int);   // 把比较函数作为回调传入
    for (int i = 0; i < n; i++) printf("%d ", arr[i]);
    return 0;
}
```

> `qsort` 不知道你的数组是什么类型、按什么规则排，它只负责"用你给的比较函数 cmp_int 来决定顺序"。这种"排序框架 + 用户自定义比较"的模式在 C 里全靠函数指针实现。

## 动态内存分配

```c
#include <stdio.h>
#include <stdlib.h>

int main(void) {
    int *arr = (int *)malloc(10 * sizeof(int)); // 分配 10 个 int
    if (arr == NULL) {                           // 检查失败
        return 1;
    }
    for (int i = 0; i < 10; i++) arr[i] = i * i;
    printf("%d\n", arr[3]); // 9
    free(arr);              // 释放，避免内存泄漏
    return 0;
}
```

## 字符串（字符数组）

C 没有内置字符串类型，用 `char` 数组 + `\0` 结尾；字符串一定以空字符 `\0` 结束，这也说明字符串实际能存储的字符数比数组容量小 1。

```c
#include <stdio.h>
#include <string.h>

int main(void) {
    char name[20] = "Alice";
    char other[20];
    strcpy(other, name);        // 拷贝
    printf("%zu\n", strlen(name)); // 4（不含 \0）
    return 0;
}
```

## 宏与预处理器指令

预处理器在编译前对源码做**文本替换**，指令以 `#` 开头。它是编译流程的第一步（预处理 → 编译 → 链接），属于**编译期机制**。

### `#define` — 宏定义

```c
#include <stdio.h>

#define PI 3.14159          // 对象宏（常量）
#define MAX(a, b) ((a) > (b) ? (a) : (b))   // 函数宏
#define SQUARE(x) ((x) * (x))              // 注意多用括号防歧义

int main(void) {
    printf("%.2f\n", PI);          // 3.14
    printf("%d\n", MAX(3, 7));     // 7
    printf("%d\n", SQUARE(2 + 1)); // 9（无括号会变 2+1*2+1=5）
    return 0;
}
```

> **函数宏的坑**：参数一定要整体加括号，否则运算优先级会出错。

### 常用预处理器指令

| 指令 | 作用 |
| --- | --- |
| `#include` | 引入头文件（`<...>` 系统库 / `"..."` 自定义） |
| `#define` / `#undef` | 定义 / 取消宏 |
| `#ifdef` / `#ifndef` | 宏是否（未）定义 |
| `#if` / `#elif` / `#else` / `#endif` | 条件编译（按表达式） |
| `#pragma once` | 头文件只包含一次（防重复包含） |
| `#error` | 编译期报错 |

### 条件编译：`#ifdef` / `#ifndef`

常用于按平台/开关编译不同代码。

```c
#include <stdio.h>

#define DEBUG   // 注释掉则进入 else 分支

#ifdef DEBUG
    #define LOG(fmt, ...) printf("[DEBUG] " fmt "\n", ##__VA_ARGS__)
#else
    #define LOG(fmt, ...)
#endif

int main(void) {
    LOG("value = %d", 42);   // DEBUG 定义时输出 [DEBUG] value = 42
    return 0;
}
```

另一种常见写法：

```c
#ifndef HEADER_UTIL_H
#define HEADER_UTIL_H
// 头文件内容
#endif
```

### 头文件防重复包含的两种方式

```c
// 方式一：#pragma once（简洁，推荐）
#pragma once

// 方式二：include guard（宏守卫，可移植性更好）
#ifndef MY_HEADER_H
#define MY_HEADER_H
/* ... */
#endif
```

> 两者都用于防止同一头文件被 `#include` 多次导致重复定义错误。`#pragma once` 更简洁，guard 写法可移植性更强。

## C 与 C++ 的关键差异

| 维度 | C | C++ |
| --- | --- | --- |
| 编程范式 | 过程式 | 面向对象 + 泛型 + 过程式 |
| 类/对象 | 无（用 struct 模拟） | 有 `class` |
| 内存管理 | `malloc`/`free` | `new`/`delete`，另有 RAII |
| 字符串 | `char[]` | `std::string` |
| 数据结构 | 需手写 | 标准库 STL 提供 |
| I/O | `printf`/`scanf` | `std::cout`/`std::cin` |
