
## 属性透传（Prop Drilling）

属性透传指的是将属性从父组件逐层传递给深层嵌套的子组件，即便中间某些子组件并不需要这些属性。

## Context API

Context 的作用是让父组件能够向子组件共享数据，无需通过属性逐层显式传递。

可以使用 `createContext` 创建一个上下文对象，供其他组件读取；通过 `Provider` 向子组件提供上下文数据。

```js
import { useState, createContext } from "react";

const CounterContext = createContext();

const CounterProvider = ({ children }) => {
  const [count, setCount] = useState(0);

  return (
    <CounterContext.Provider value={{ count, setCount }}>
      {children}
    </CounterContext.Provider>
  );
};

export { CounterContext, CounterProvider };
```

## Redux

Redux 通过提供一个中心化的状态仓库，以及严格的状态更新规则来管理应用状态。它遵循可预测的设计模式，核心概念包括 Action、Reducer 和中间件：

- Action：是从应用发送到状态仓库的信息载体，通常由用户交互触发
- Reducer：是指定状态如何响应 Action 进行更新的函数，确保状态以不可变的方式更新
- 中间件：作用于 Action 分发和 Reducer 执行之间，可用于扩展 Redux 的功能（例如日志记录、处理异步操作），且无需修改核心工作流程

## Zustand

Zustand 是一款适用于中小型应用的状态管理方案。它通过 `useStore` 钩子让组件和页面直接访问状态，无需编写 Action、Reducer 或配置 Provider，即可实现状态的读取和修改。
