
## SSH 与 OpenSSH

**SSH**（Secure Shell，安全外壳协议）是 IETF 制定的、建立在应用层基础上的安全网络协议，专为**远程登录会话**和其它网络服务提供安全性，采用**非对称加密技术（RSA）**加密所有传输数据。

**OpenSSH** 是 SSH 的免费开源实现，是 Linux 最常用的 SSH 服务器/客户端软件。

## 安装与启动

```bash
# Ubuntu
$ sudo apt install openssh-server openssh-client
$ sudo systemctl enable --now ssh

# CentOS / RHEL
# sudo dnf install openssh-server openssh-clients
# sudo systemctl enable --now sshd
```

防火墙放行 22 端口：

```bash
# Ubuntu (ufw)
$ sudo ufw allow 22/tcp
# CentOS (firewalld)
# sudo firewall-cmd --permanent --add-port=22/tcp
# sudo firewall-cmd --reload
```

## 配置文件

主配置文件 `/etc/ssh/sshd_config`：

```ini
Port 22            # 监听端口（默认 22）
PermitRootLogin prohibit-password   # 禁止 root 密码登录（安全）
PubkeyAuthentication yes            # 允许密钥登录
PasswordAuthentication yes          # 允许密码登录（建议改用密钥后关闭）
```

修改后重启服务：`sudo systemctl restart ssh`。

## 连接

```bash
$ ssh user@host           # 密码登录
$ ssh -p 2222 user@host   # 指定端口
$ ssh user@host 'command' # 远程执行单条命令
```

## 密钥登录（免密）

```bash
# 本机生成密钥对（非对称 RSA/Ed25519）
$ ssh-keygen -t ed25519 -C "your@email.com"
# 把公钥传到服务器（一次性）
$ ssh-copy-id user@host
# 验证免密登录
$ ssh user@host
```

原理：公钥存在服务器 `~/.ssh/authorized_keys`，客户端持私钥签名，服务器用公钥验证，无需密码。

## 文件传输

| 命令 | 作用 |
|---|---|
| `scp file user@host:/path` | 加密复制文件到远程 |
| `scp user@host:/path/file .` | 从远程下载 |
| `scp -r dir user@host:/path` | 递归复制目录 |
| `sftp user@host` | 安全文件传送协议，交互式传文件 |

```bash
$ scp app.tar.gz user@192.168.1.10:/tmp/
$ sftp user@host
sftp> put local.txt
sftp> get remote.txt
sftp> exit
```

## WSL 远程连接

- Windows 通过 `wsl --install` 装 Ubuntu 后，SSH 服务在 WSL 内自启动即可。
- 从本机 `ssh user@localhost` 连接 WSL 内服务。
- WSL2 默认 NAT，外部机器访问需做端口转发（`netsh interface portproxy`）或镜像网络模式。
