
## 脚本结构

脚本是命令的集合，首行声明解释器：

```bash
#!/bin/bash
# 这是注释
echo "hello script"
```

## 执行方式

```bash
$ bash script.sh      # 用 bash 解释执行（无需执行权限）
$ chmod +x script.sh && ./script.sh   # 加执行权限后直接运行
$ source script.sh    # 在当前 shell 执行（影响当前环境变量）
```

## 位置参数

| 变量 | 含义 |
|---|---|
| `$0` | 脚本名 |
| `$1`~`$9` | 第 1~9 个参数 |
| `$#` | 参数个数 |
| `$@` / `$*` | 全部参数 |
| `$?` | 上一条命令的退出码（0 成功，非 0 失败） |

```bash
#!/bin/bash
echo "脚本名: $0"
echo "第1个参数: $1"
echo "参数个数: $#"
echo "所有参数: $@"
```

## 变量与输入

```bash
name="world"
echo "hello $name"
read -p "输入内容: " val    # 从键盘读取
echo "你输入了: $val"
```

## 数值运算

```bash
a=10
b=3
echo $((a + b))      # 13，双括号运算
echo $((a * b))      # 30
declare -i sum=a+b   # declare 声明整数类型
echo $((a % b))      # 1
```

## 条件判断

```bash
if [ $1 -gt 10 ]; then
  echo "大于10"
elif [ $1 -eq 10 ]; then
  echo "等于10"
else
  echo "小于10"
fi
```

数字比较：`-eq` 等于、`-ne` 不等于、`-gt` 大于、`-lt` 小于、`-ge` 大于等于、`-le` 小于等于。
文件判断：`-f` 是文件、`-d` 是目录、`-x` 可执行、`-e` 存在。
字符串比较：`= =` 相等（`[ "$a" = "b" ]`）、`!=` 不等、`-z` 为空。

## case 分支

```bash
case $1 in
  start) echo "starting";;
  stop)  echo "stopping";;
  *)     echo "unknown";;
esac
```

## for 循环

```bash
for i in 1 2 3 4 5; do
  echo "i = $i"
done

# 遍历文件
for f in /etc/*.conf; do
  echo "file: $f"
done

# C 风格
for ((i=0; i<10; i++)); do
  echo $i
done

# 命令替换
for ip in $(cat hosts.txt); do
  ping -c1 $ip
done
```

## while 与 until

```bash
count=1
while [ $count -le 5 ]; do
  echo $count
  count=$((count+1))
done

# 无限循环
while true; do
  echo "running..."
  sleep 1
done

# until 条件为假时执行，为真退出
until [ $count -ge 5 ]; do
  count=$((count+1))
done
```

## 循环控制

```bash
break       # 跳出整个循环
continue    # 跳过本次，进入下一次
```

## select 菜单

```bash
select opt in start stop restart quit; do
  case $opt in
    start)   echo "start";;
    quit)    break;;
    *)       echo "invalid";;
  esac
done
```

## 函数

```bash
# 定义
say_hello() {
  echo "hello $1"
}

# 调用
say_hello "world"

# 带返回值（$? 取退出码，函数不能直接 return 字符串）
add() {
  return $(( $1 + $2 ))
}
add 3 4
echo $?        # 7

# 局部变量
my_func() {
  local x=10    # local 声明局部变量，避免污染全局
}
```

## 数组

```bash
arr=(one two three)
echo ${arr[0]}         # one
echo ${arr[@]}         # 全部元素
echo ${#arr[@]}        # 元素个数
for e in "${arr[@]}"; do echo $e; done
```

## 综合示例：批量检查服务

```bash
#!/bin/bash
services=(nginx mysql redis)
for s in "${services[@]}"; do
  if systemctl is-active --quiet "$s"; then
    echo "$s: running"
  else
    echo "$s: stopped"
  fi
done
```
