
`crypto` **密码学**，提供哈希、HMAC、加解密、数字签名、安全随机数等工具。

## 哈希与 HMAC

### `createHash(algorithm)` — 单向哈希（不可逆）

使用 `.update(data).digest("hex")` 提供待哈希数据并返回十六进制字符串：

```js
const crypto = require("crypto");

const hashedPassword = crypto
  .createHash("sha256")
  .update("myStrongPassword")
  .digest("hex");
```

### `createHmac(algorithm, secret)` — 带密钥的哈希

与 `createHash` 类似，但**需要密钥**。适合验证数据完整性和做认证。

```js
const crypto = require("crypto");

// 简单哈希（无密钥，仅完整性校验）
const sha = crypto.createHash("sha256").update("data").digest("hex");

// HMAC（带密钥，可用于认证签名）
const hmac = crypto
  .createHmac("sha256", "super-secret-key")
  .update("data")
  .digest("hex");
```

## 密码哈希：bcrypt（实际开发推荐）

> **实际开发中，密码几乎不用 `crypto.createHash()` 直接哈希**。`createHash` 无盐、速度快，容易被彩虹表攻击和暴力破解。存储密码应使用专门的慢哈希库 **bcrypt**，它自动加盐并内置成本因子。

### 为什么不用 `crypto.createHash` 存密码

- **无盐**：相同密码产生相同哈希，可被彩虹表逆向。
- **速度快**：SHA-256 计算极快，攻击者可每秒尝试数十亿次。
- bcrypt 则刻意**慢**（可调 cost），大幅提升暴力破解成本，并自动生成随机盐。

### 安装与使用（推荐 `bcryptjs`）

```bash
npm install bcryptjs
```

```js
const bcrypt = require("bcryptjs");

// 1. 注册时哈希密码（saltRounds=10 是常见成本因子）
const saltRounds = 10;
const hashedPassword = await bcrypt.hash("myPassword123", saltRounds);
console.log(hashedPassword); // $2b$10$...（含盐、成本、哈希）

// 2. 登录时校验密码
const isMatch = await bcrypt.compare("myPassword123", hashedPassword);
console.log(isMatch); // true / false
```

### 完整示例（注册 + 登录）

```js
const bcrypt = require("bcryptjs");

async function registerUser(username, plainPassword) {
  const hash = await bcrypt.hash(plainPassword, 10);
  // 把 hash 存入数据库，绝不存明文
  await db.saveUser({ username, passwordHash: hash });
}

async function loginUser(username, plainPassword) {
  const user = await db.getUser(username);
  if (!user) return false;
  const ok = await bcrypt.compare(plainPassword, user.passwordHash);
  return ok; // true = 密码正确
}
```

### bcryptjs vs bcrypt

| 库 | 说明 |
| --- | --- |
| `bcryptjs`（推荐） | 纯 JavaScript 实现，免编译、跨平台，API 与 bcrypt 一致，性能足够用 |
| `bcrypt` | 原生实现，性能更高，但依赖 C++ 编译（Windows 需构建工具） |

> 两者 API 完全一致：都是 `hash()` / `compare()`，代码仅 `require` 的包名不同。默认选 `bcryptjs` 即可，避免原生编译问题。

## 加解密

`createCipheriv()` / `createDecipheriv()` 加密和解密数据。两者都需要：算法、密钥（key）、初始化向量（IV）：

```js
const cipher = crypto.createCipheriv("aes-256-cbc", key, iv);
let encrypted = cipher.update("Hello campers!", "utf8", "hex");
encrypted += cipher.final("hex");
```

## 安全随机数

### `randomBytes(size)` — 安全随机字节

生成密码学安全的随机字节。用于 token、密钥，**比 `Math.random()` 更安全**。

### `randomInt(min, max)` — 安全随机整数

在指定范围内生成安全随机整数，适用于 OTP（一次性密码）。

```js
const crypto = require("crypto");

// 随机 token（如重置密码链接）
const token = crypto.randomBytes(32).toString("hex");

// 随机 6 位验证码（OTP）
const otp = crypto.randomInt(100000, 1000000); // [100000, 1000000)
```

## 数字签名

`sign()` / `verify()` 使用公钥/私钥对创建和验证数字签名。

## 小结

| 能力 | 关键 API | 场景 |
| --- | --- | --- |
| 密码哈希 | `bcryptjs.hash()` / `bcryptjs.compare()`（第三方） | **存储密码（推荐）** |
| 单向哈希 | `createHash()` | 数据完整性校验（**不用来存密码**） |
| 带密钥哈希 | `createHmac()` | 数据认证、防篡改 |
| 加解密 | `createCipheriv()` / `createDecipheriv()` | 数据加密传输 |
| 安全随机数 | `randomBytes()` / `randomInt()` | token、OTP、密钥 |
| 数字签名 | `sign()` / `verify()` | 身份认证、防抵赖 |

> 记住：**密码用 bcrypt**（慢哈希 + 自动加盐）；哈希用于**校验**（不可逆），HMAC 用于**认证**（带密钥），加解密用于**保密**（可逆），随机数要用 `randomBytes`/`randomInt` 而不是 `Math.random()`。
