
`Buffer` 是流的数据单元：流把数据切分成一个个 `Buffer` 分块来传输。二者共同解决「二进制数据与大数据量处理」。

## `Buffer` 模块（二进制数据）

**用途**：直接在内存中处理二进制数据（文件、图片、网络流）。

### `Buffer.from()` — 从字符串创建 Buffer

```js
const { Buffer } = require("buffer");

const myStrBuffer = Buffer.from("freeCodeCamp");
console.log(myStrBuffer);          // <Buffer 66 72 65 65 43 6f 64 65 43 61 6d 70>
console.log(myStrBuffer.toString()); // freeCodeCamp
```

### `Buffer.alloc(n)` — 创建指定字节的零填充 Buffer

```js
const someBuffer = Buffer.alloc(10);
someBuffer.write("Hello fCC");
console.log(someBuffer.toString()); // Hello fCC
```

### 截断行为

向 Buffer 写入超过其容量的数据，**多出的部分会被静默截断**。

### `Buffer.byteLength(str)` — 计算字节数

返回存储一个字符串所需的字节数（注意：中文等字符占多字节）。

### 写入、索引与多字节

```js
const { Buffer } = require("buffer");

const buf = Buffer.alloc(6);
buf.write("hello");          // 写入
console.log(buf[0]);         // 104（'h' 的 ASCII 码）
console.log(buf.toString()); // hello

console.log(Buffer.byteLength("中文")); // 6 —— 中文按 UTF-8 每字占 3 字节
```

## `stream` 模块（流）

**用途**：以**分块**方式处理大量数据，而不是一次性全部载入内存。

### 四种流类型

| 类型 | 说明 |
| --- | --- |
| **Readable** | 可读流：分块读取数据 |
| **Writable** | 可写流：分块写入数据 |
| **Duplex** | 双向流：既可读又可写 |
| **Transform** | 转换流：一种在流经时修改数据的 Duplex |

### 管道（Piping）

```js
const readInputFileStream = fs.createReadStream(inputFilePath);
const writeOutputFileStream = fs.createWriteStream(outputFilePath);

readInputFileStream.pipe(writeOutputFileStream);

writeOutputFileStream.on("finish", () => {
  console.log("All data has been written to the file");
});
```

### 关键事件

- `finish` 事件：可写流中所有数据都被刷新后触发。
- `error` 事件：流遇到问题时触发。

### 为什么要用流

处理大文件（如日志、视频）时，流以小块为单位处理，内存占用稳定，避免一次性加载造成内存溢出。

### 用流复制大文件（边读边写，内存占用低）

```js
const fs = require("fs");

const readStream = fs.createReadStream("big.log");
const writeStream = fs.createWriteStream("big-copy.log");

readStream.pipe(writeStream);

writeStream.on("finish", () => console.log("复制完成"));
readStream.on("error", (err) => console.error("读取失败:", err));
```

### Transform 流（边流边处理，如转换大小写）

```js
const { Transform } = require("stream");

const upper = new Transform({
  transform(chunk, enc, cb) {
    cb(null, chunk.toString().toUpperCase());
  },
});

process.stdin.pipe(upper).pipe(process.stdout);
// 输入 hello → 输出 HELLO
```

---

## Buffer 与流的关联

- 流中的 `chunk` 本质上就是 `Buffer`。
- `fs.createReadStream`、`http` 的请求/响应体、标准输入输出，底层都以 Buffer 为数据单元流动。
- 处理二进制 + 大数据时，二者配合：**Buffer 管"一块数据"，stream 管"一长串数据"**。
