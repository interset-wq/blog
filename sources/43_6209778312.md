
> 对应 SQL：条件聚合 / 把行转列、把列转行。

## 概念

- **长表（窄表）**：行多列少，一列是类别、一列是值（类似"一行一个观测"）。
- **宽表**：类别变成列名，值铺开（类似透视表）。

```text
长表:  date  city  sales          宽表:  date   北京   上海
      1/1   北京   100                  1/1   100    90
      1/1   上海    90                  1/2    80   120
      1/2   北京    80
      1/2   上海   120
```

统一用这张长表演示：

```python
>>> import pandas as pd
>>> df = pd.DataFrame({'date': ['1/1','1/1','1/2','1/2'],
...                    'city': ['北京','上海','北京','上海'],
...                    'sales':[100, 90, 80, 120]})
>>> df
  date city  sales
0  1/1  北京    100
1  1/1  上海     90
2  1/2  北京     80
3  1/2  上海    120
```

## pivot —— 长表 → 宽表（行、列、值各指定一列）← 力扣 2889

```python
>>> df.pivot(index='date', columns='city', values='sales')
city  北京   上海
date
1/1    100    90
1/2     80   120
```

- `index`：作为行的那列（这里 `date`）；`columns`：要变成列名的列（`city`）；`values`：填充值的列（`sales`）。

**注意点：**
- 丢失数据：`pivot` 不处理 (index, columns) 重复条目，**有重复组合会报错** → 改用 `pivot_table` + `aggfunc`。
- 顺序：输出不一定按自然顺序（如月份），可先 `pivot` 再 `reindex` 固定顺序：

```python
>>> df = df.pivot(index='month', columns='city', values='temperature')
>>> month_order = ["January","February","March","April","May","June",
...                "July","August","September","October","November","December"]
>>> df = df.reindex(month_order)
```

## pivot_table —— 有重复组合时的透视（支持聚合）

```python
# 假设有重复 (date, city) 组合 → pivot 会报错，改用 pivot_table 聚合
>>> pd.pivot_table(df, index='city', columns='date', values='sales',
...                aggfunc='sum', fill_value=0)
date   1/1  1/2
city
北京    100   80
上海     90  120
```

- `aggfunc`：聚合函数（`sum`/`mean`/`max`/`min`/`count`...），类似 GROUP BY + 聚合。
- `fill_value=0`：把空值填 0。
- `margins=True, margins_name='总计'`：加汇总行/列。
- `index`/`columns`/`values` 都支持传列表（多列）。

## melt —— 宽表 → 长表（折叠成 variable/value）← 力扣 2890

```python
# 宽表
>>> wide = pd.DataFrame({'product': ['A', 'B'],
...                      'Q1': [10, 5], 'Q2': [20, 8]})
>>> wide
  product  Q1  Q2
0       A  10  20
1       B   5   8
>>> wide.melt(id_vars=['product'], var_name='quarter', value_name='sales')
  product quarter  sales
0       A      Q1     10
1       B      Q1      5
2       A      Q2     20
3       B      Q2      8
```

**参数详解：**
- `id_vars`：保持不变作为标识的列（`product`）。
- `value_vars`：要"熔化"成行的列（可省略，缺省=除 id_vars 外所有列，这里 Q1、Q2）。
- `var_name`：被折叠的原列名变成的新列名（默认 `variable`，这里 `quarter`）。
- `value_name`：折叠后的值列名（默认 `value`，这里 `sales`）。

```python
# 指定要折叠的列（不折叠全部）
>>> df = df.melt(
...     id_vars=["product"],
...     value_vars=["quarter_1","quarter_2","quarter_3","quarter_4"],
...     var_name="quarter",
...     value_name="sales",
... )
```

## 交叉表 crosstab（直接按两个/多个因素统计）

```python
>>> pd.crosstab(index=df['city'], columns=df['date'],
...             values=df['sales'], aggfunc='sum')
date   1/1  1/2
city
北京    100   80
上海     90  120
```

> `crosstab` 与 `pivot_table` 结果类似，区别是 `crosstab` 直接吃 Series（`df['city']`），适合快速做二维频数/汇总表。

## 一页速览

```python
>>> df.pivot(index='date', columns='city', values='sales')       # 长→宽
>>> pd.pivot_table(df, index='city', columns='date', values='sales', aggfunc='sum')
>>> df.melt(id_vars=['product'], var_name='q', value_name='sales') # 宽→长
>>> pd.crosstab(index=df['city'], columns=df['date'], values=df['sales'], aggfunc='sum')
```
