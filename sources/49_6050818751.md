
## 进程基础

程序运行后由操作系统注册为**进程**，并分配唯一进程号 **PID**。进程管理三大作用：判断服务器健康状态、查看所有进程、终止进程。

## 查看进程

```bash
$ ps aux          # 查看所有进程（常用）
$ ps -ef          # 全格式查看，含 PPID（父进程）
$ pstree          # 树形显示进程父子关系
$ top             # 动态实时监控，默认约 3 秒刷新，q 退出
$ pgrep nginx     # 按名称查 PID
$ pidof nginx     # 按程序名查 PID
```

`ps -ef` 关键字段：UID（用户）、PID、PPID（父进程）、C（CPU 占用）、STIME（启动时间）、TTY（终端，`?` 表示非终端启动）、CMD（命令）。

## 僵尸进程

子进程先于父进程结束，而父进程没有正确回收子进程，子进程便一直残留在内存，成为**僵尸进程**。常因进程非正常停止或程序编写错误导致。

## 信号

进程关闭/重启依赖**信号**。查看全部信号：`kill -l`。

| 信号 | 含义 |
|---|---|
| 1 (SIGHUP) | 进程重新读取配置后重启 |
| 9 (SIGKILL) | 强制终止，不能被阻塞/处理/忽略 |
| 15 (SIGTERM) | 正常终止，kill 默认信号 |

## 终止进程

```bash
$ kill <pid>          # 发送默认信号 15（正常结束）
$ kill -9 <pid>       # 强制终止（最常用，耗资源进程）
$ killall nginx       # 按进程名终止所有同名进程
$ pkill nginx         # 按名称/属性终止
$ pkill -9 -f "python app.py"   # 按完整命令行匹配强制终止
```

> 终止一个很消耗资源的进程时，最合适的信号值是 9。

## 进程优先级

两个参数表示优先级：**PRI**（priority）和 **NI**（nice）。数值越小越优先被 CPU 处理。

- PRI 由内核动态调整，用户不能直接改；只能通过修改 **NI** 间接影响。
- 关系：`PRI(最终) = PRI(原始) + NI`。
- NI 范围 `-20~19`；普通用户只能调高自己的 NI（0~19），root 才能设负值并可调整任意用户进程。

```bash
$ nice -n 10 command        # 以指定 NI 启动程序
$ renice -n 5 <pid>         # 修改运行中进程的 NI
$ top                       # top 中按 r 可交互调整优先级
```

## 系统基本信息

```bash
$ uname -a          # 内核与系统架构信息
$ hostname          # 主机名
$ lscpu             # CPU 信息
$ who               # 当前登录用户
$ uptime            # 运行时长与负载
```

## 内存监控

```bash
$ free -h           # 内存使用（-h 人类可读单位）
$ vmstat 1 5        # 虚拟内存统计，每秒一次共 5 次
```

`free` 关键列：total / used / free / buff/cache（Swap 即交换分区/虚拟内存）。
`vmstat`：r（运行进程）、b（阻塞）、si/so（swap 换入/换出）、us/sy（用户/系统 CPU）。若 `si`/`so` 频繁非 0，说明内存不足频繁换页，可能引发**颠簸（thrashing）**，性能骤降。

## 磁盘监控

```bash
$ df -h             # 各文件系统使用情况
$ df -i             # 查看 inode 使用
$ du -sh /var       # 目录总占用
$ du -h --max-depth=1 /home   # 逐层统计
$ lsblk             # 块设备与挂载点
$ iostat -x 1       # CPU 与磁盘 I/O 统计
```

`df -h` 看整盘使用率；`du -sh` 看单个目录占用大小。删文件后空间未立即释放，需等所有进程都不再使用该文件，或用 `lsof | grep deleted` 排查占用。

## CPU 与网络负载

```bash
$ top               # 实时进程与 CPU/内存
$ htop              # top 增强版（需安装）
$ uptime            # load average 1/5/15 分钟负载
$ sar -n DEV 1      # 网络接口统计（需 sysstat）
```

## 磁盘与硬件排查

```bash
$ dmesg | grep -i error    # 内核/启动日志查硬件错误
$ fsck /dev/sda1           # 检查修复文件系统（需 root，先卸载）
$ smartctl -a /dev/sda     # 查看硬盘健康（需 smartmontools）
```

## WSL 专属监控

```bash
$ cat /proc/meminfo        # 内存详情（WSL 默认使用宿主机内存的一部分）
$ cat /proc/cpuinfo        # CPU 详情
```

WSL2 默认内存上限由 `.wslconfig` 控制，可在 Windows 用户目录下配置 `memory=4GB` 等。
