
## 受控组件(Controlled input)

受控组件指的是将输入框的值存储在 React 状态中，并通过 `onChange` 事件更新状态的组件。这种方式能让你完全掌控表单数据，支持即时验证和条件渲染。

```jsx
import { useState } from "react";

function App() {
  const [name, setName] = useState("");

  const handleChange = (e) => {
    setName(e.target.value);
  };

  const handleSubmit = (e) => {
    e.preventDefault();
    console.log(name);
  };

  return (
    <>
      <form onSubmit={handleSubmit}>
        <label htmlFor="name">Your name</label> <br />
        <input value={name} id="name" onChange={handleChange} type="text" />
        <button type="submit">Submit</button>
      </form> 
    </>
  );
}

export default App;
```

受控组件的优点：

- 即时访问数据
- 即时表单验证
- 可以使用条件禁用提交按钮
- 可以有规划控制输入框的值

## 非受控组件(Uncontrolled inputs)

非受控组件不会通过 `useState` 钩子管理输入值，而是由 DOM 自身维护内部状态。由于输入值由 DOM 控制，需要通过 `ref` 来获取输入框的值。非受控组件类似于原生的HTML表单。

```jsx
import { useRef } from "react";

function App() {
  const nameRef = useRef();

  const handleSubmit = (e) => {
    e.preventDefault();
    console.log(nameRef.current.value);
  };

  return (
    <form onSubmit={handleSubmit}>
      <label htmlFor="name">Your</label>{" "}
      <input type="text" ref={nameRef} id="name" />
      <button type="submit">Submit</button>
    </form>
  );
}

export default App;
```

非受控组件的优点：

- 代码量少
- 效率高

## 合理选用受控组件和非受控组件

- 表单需要动态更新，实时验证，需要与状态同步时，使用受控组件
- 简单表单，只在提交时获取数据，非react代码时，使用非受控组件

react项目中的所有表单都应该遵守：

- 阻止提交表单时自动刷新页面
- 提交前进行表单验证
- 登录、表单验证不通过或其他情形，应该给用户提供清晰的反馈
