
Linux 下有多种命令行文本编辑器。实际开发多以 VSCode 等 GUI 编辑器为主，命令行编辑器主要用在**服务器远程维护**（SSH 无 GUI 环境）和快速改配置场景。因此本讲只做概览，掌握基本用法、能应付日常即可。

## nano：最易上手的编辑器

nano 是面向新手设计的编辑器，**无模态**，快捷键提示常驻屏幕底部，适合快速编辑配置文件。

```bash
$ nano file.txt        # 打开（不存在则新建）
```

底部快捷键（`^` 表示 Ctrl）：

```text
^G 帮助    ^O 保存    ^X 退出    ^W 查找
^K 剪切    ^U 粘贴    ^\ 替换
```

```bash
# 退出时按 ^X，若未保存会询问是否保存（Y 保存 / N 丢弃）
```

> 需要 root 权限编辑系统文件时：`sudo nano /etc/ssh/sshd_config`。

## vim：经典模态编辑器

vim 是 vi 的增强版，兼容 vi 全部指令，是服务器上最常见的编辑器。vim 是**模态**编辑器，按键含义取决于当前模式。

### 三种模式

| 模式 | 说明 |
|---|---|
| 普通模式 | 默认入口，按键被解释为命令 |
| 输入模式 | 自由编辑文本 |
| 底线命令模式 | 保存、退出、执行 `:` 命令 |

模式切换：普通 → 输入按 `i`；输入 → 普通按 `Esc`；普通 → 命令按 `:`。

### 打开与保存退出

```bash
$ vim file.txt        # 打开文件，不存在则创建
```

```vim
:q       # 不保存退出
:q!      # 强制退出不保存
:w       # 保存
:wq      # 保存并退出
:set nu  # 显示行号
```

### 最小常用集（普通模式）

```text
i / a       进入输入模式（光标前 / 后）
h j k l     左 下 上 右移动
dd          删除整行
yy          复制整行
p           粘贴
u           撤销
/word       向下搜索，n 下一个、N 上一个
gg / G      跳到首行 / 末行
```

### 查找替换（了解）

vim 的查找替换语法较复杂，日常以 `/` 搜索 + 手动改为主；如需替换：

```vim
:%s/old/new/g       # 全文替换（% 表示所有行）
:3,5s/old/new/g     # 只替换第 3~5 行
:set hlsearch       # 搜索高亮
```

> [!NOTE]
> 对 vim 的存储缓冲区概念要知道：对已有文件的修改不会自动写回原文件，必须 `:w` 保存；直接 `:q!` 会丢失未保存修改。

## emacs：非模态编辑器

emacs 与 vim 并列的经典编辑器，但**非模态**，全部通过组合快捷键操作（`C`=Ctrl、`M`=Alt）。功能极强，但学习曲线陡，了解基本操作即可。

```bash
$ emacs file.txt        # 图形界面打开
$ emacs -nw file.txt    # 终端内打开（适合 SSH）
```

```emacs
C-x C-f     打开文件
C-x C-s     保存
C-x C-c     退出
C-x C-w     另存为
C-p/C-n     上 / 下移动
C-a/C-e     行首 / 行尾
C-s/C-r     向前 / 向后搜索
C-w         剪切区域
C-y         粘贴
C-g         取消当前操作
```

## 编辑器选型建议

| 场景 | 推荐 |
|---|---|
| 服务器改配置、快速编辑 | nano 或 vim |
| 服务器编程维护 | vim（预装率高） |
| 本地/远程开发 | VSCode（主流，配合 Remote-SSH） |

> [!IMPORTANT]
> 只要掌握**一种**命令行编辑器能应付远程环境即可；开发主力建议用 VSCode + Remote-SSH 插件，可直接在 GUI 中编辑服务器文件，避免手记各种快捷键。
