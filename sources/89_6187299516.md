
## STL 简介

**STL（Standard Template Library）** 是 C++ 标准库中**容器 + 迭代器 + 算法**的统称，基于模板实现，开箱即用地提供各种数据结构。

| 组成 | 作用 |
| --- | --- |
| 容器 | 存储数据的数据结构（vector、map 等） |
| 迭代器 | 在容器元素间移动的"指针" |
| 算法 | 对容器做查找、排序、遍历等操作 |

所有容器都提供 `begin()` / `end()` 迭代器，配合 `auto` 遍历非常方便。

> **本篇统一使用 `using namespace std;`** 简化代码（省去 `std::` 前缀）。工程代码通常建议省略或按需 `using std::vector;`

## `std::vector` — 动态数组（最常用）

**特点**：连续内存、可变长、尾部增删快（O(1)）、按下标随机访问 O(1)。

```cpp
#include <vector>
#include <iostream>
using namespace std;

int main() {
    vector<int> v = {1, 2, 3, 4};

    v.push_back(5);          // 尾部插入
    v.pop_back();            // 尾部删除
    v.insert(v.begin() + 1, 99); // 指定位置插入
    v.erase(v.begin());      // 指定位置删除

    cout << v[0] << " " << v.size() << endl; // 0 下标访问、大小

    // 遍历
    for (int x : v) cout << x << " ";
    // 迭代器遍历
    for (auto it = v.begin(); it != v.end(); ++it) cout << *it << " ";
    return 0;
}
```

### 常用成员

| 成员 | 作用 |
| --- | --- |
| `push_back` / `pop_back` | 尾部插入 / 删除 |
| `size()` / `empty()` | 元素个数 / 是否为空 |
| `operator[]` / `at(i)` | 按下标访问（`at` 越界抛异常） |
| `front()` / `back()` | 首 / 尾元素 |
| `insert` / `erase` | 插入 / 删除 |
| `reserve(n)` / `resize(n)` | 预留容量 / 调整大小 |

## `std::string` — 字符串

**特点**：封装 `char[]`，自动管理长度，支持拼接、查找、切片。

```cpp
#include <string>
#include <iostream>
using namespace std;

int main() {
    string s = "Hello";
    s += " World";            // 拼接
    string sub = s.substr(0, 5); // 切片 "Hello"
    cout << s.size() << " " << sub << endl;

    // 查找（找不到返回 npos）
    if (s.find("World") != string::npos) {
        cout << "found" << endl;
    }

    // 转数字 / 数字转字符串
    int n = stoi("42");
    string t = to_string(3.14);
    return 0;
}
```

> **⚠️ 常见误区：下标返回的是 `char`，不是 `string`**
>
> `s[i]`（或 `s.at(i)`）返回该位置的**单个字符 `char`**（左值，可修改），**不是** `string`。
>
> ```cpp
> string s = "Hello";
> char c = s[1];            // char，c == 'e'
> s[1] = 'a';               // 可修改，s == "Hallo"
>
> auto x = s[0];            // x 的类型是 char（auto 推导为 char，而非 string）
> ```
>
> 若要得到"单个字符的 string"（例如方便与字符串比较），需显式构造：
>
> ```cpp
> string ch(1, s[0]);  // 用单个 char 构造成 string
> // 或
> string ch2 = string(1, s[0]);
> ```
>
> 注意：**`string` 的重载 `operator[]` 返回 `char&`**，而 C 语言风格的 `str[i]` 同样返回 `char`——两者下标语义一致，区别在于 string 还会做边界检查（`at()`）与自动管理长度。

## `std::deque` — 双端队列

**特点**：两端增删都快（O(1)），支持下标随机访问，但内存非连续。

```cpp
#include <deque>
using namespace std;

deque<int> d = {1, 2, 3};
d.push_back(4);      // 尾插
d.push_front(0);     // 头插，O(1)
d.pop_front();       // 头删
cout << d[0];   // 随机访问
```

## `std::list` — 双向链表

**特点**：任意位置插入/删除快（O(1)，需先找到位置），但**无随机访问**（按下标需 O(n)）。

```cpp
#include <list>
using namespace std;

list<int> lst = {1, 2, 3};
lst.push_back(4);
lst.push_front(0);
lst.insert(next(lst.begin()), 99); // 在第二个位置插入

for (int x : lst) cout << x << " ";
```

## 序列容器对比

| 容器 | 内存 | 尾增删 | 头增删 | 随机访问 | 中间插入 | 适用场景 |
| --- | --- | --- | --- | --- | --- | --- |
| `vector` | 连续 | O(1) | O(n) | O(1) | O(n) | **默认首选**，频繁按下标访问 |
| `deque` | 分段 | O(1) | O(1) | O(1) | O(n) | 需要两端操作 |
| `list` | 非连续 | O(1) | O(1) | ❌ | O(1)* | 频繁中间插入/删除 |
| `string` | 连续 | O(1) | O(n) | O(1) | O(n) | 文本处理 |

> *`list` 中间插入 O(1) 的前提是**已持有**该位置的迭代器；单纯"按值找位置"仍需 O(n)。
> 实践建议：**默认用 `vector`**，只有明确需要两端/中间高频操作时才换 deque/list。
