
Linux 是开源的类 Unix 内核，不同的发行版在内核之上打包工具链、包管理器、桌面与配置文件，形成完整可用的操作系统。主流分支：

- **Debian/Ubuntu 系**：使用 `apt` 包管理器，社区活跃，是 WSL 的默认推荐发行版。
- **RHEL/CentOS Stream 系**：使用 `dnf`/`yum`/`rpm` 包管理器，多用于服务器与运维生产环境。

## WSL2

WSL（Windows Subsystem for Linux，适用于 Linux 的 Windows 子系统）让 Windows 上直接运行 Linux。**WSL2** 采用轻量级虚拟化技术，运行完整的 Linux 内核，性能与兼容性远好于 WSL1（WSL1 是翻译层，性能差，新项目一律使用 WSL2）。

### WSL 基础操作（在 Windows 终端执行）

```bash
$ wsl --list --verbose        # 列出已安装发行版及运行状态
$ wsl --install -d Ubuntu     # 安装 Ubuntu
$ wsl --shutdown              # 关闭所有 WSL 实例
$ wsl --terminate Ubuntu      # 终止指定发行版
$ wsl --set-version Ubuntu 2  # 将发行版切换为 WSL2
```

### WSL 的文件访问

- Linux 内访问 Windows 磁盘：`/mnt/c/`（C 盘）、`/mnt/d/`（D 盘）…
- Windows 访问 WSL 文件：`\\wsl$\Ubuntu\home\<用户名>`

> [!IMPORTANT]
> 不要在 Windows 编辑器（如记事本、VSCode 的 Windows 侧）直接修改 WSL 内的 Linux 文件，容易破坏文件权限与换行符，导致程序异常。
