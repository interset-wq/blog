
## OpenAPI 文档（drf-spectacular）

drf-spectacular 能**自动从你的 Serializer / ViewSet 推断出 OpenAPI 3.0 schema**，无需手写文档。生成后可通过 Swagger UI 或 ReDoc 展示和在线调试。

### 安装与配置

```powershell
uv add drf-spectacular
```

在 `INSTALLED_APPS` 注册，并配置 `DEFAULT_SCHEMA_CLASS`。本项目的实际配置（`config/settings.py`）：

```python
INSTALLED_APPS = [
    # ...
    'drf_spectacular',
]

REST_FRAMEWORK = {
    'DEFAULT_SCHEMA_CLASS': 'drf_spectacular.openapi.AutoSchema',
}

SPECTACULAR_SETTINGS = {
    'TITLE': 'Learning Log API',
    'VERSION': '1.0.0',
    'SERVE_INCLUDE_SCHEMA': False,
}
```

`SPECTACULAR_SETTINGS` 常用键：

| 配置 | 作用 | 示例值 |
|---|---|---|
| `TITLE` | API 文档标题 | `'Learning Log API'` |
| `DESCRIPTION` | API 说明文字 | `'一个 DRF API 的说明文档'` |
| `VERSION` | 版本号 | `'1.0.0'` |
| `SERVE_INCLUDE_SCHEMA` | 是否把 schema 端点自身也纳入 schema | `False` |
| `COMPONENT_SPLIT_REQUEST` | 请求 / 响应 body 是否拆分 | `True` |

### 路由接入

在项目 URLconf 中添加 schema 和文档页面。本项目的实际配置（`config/urls.py`）：

```python
from drf_spectacular.views import (
    SpectacularAPIView,
    SpectacularSwaggerView,
)

urlpatterns = [
    path('api/schema/', SpectacularAPIView.as_view(), name='schema'),
    path('api/docs/', SpectacularSwaggerView.as_view(url_name='schema'), name='api-docs'),
]
```

若还需要只读的 ReDoc 视图：

```python
# 通用示例（非项目代码）
from drf_spectacular.views import SpectacularRedocView

urlpatterns += [
    path('api/redoc/', SpectacularRedocView.as_view(url_name='schema'), name='redoc'),
]
```

启动开发服务器后访问：

| 路径 | 内容 |
|---|---|
| `/api/schema/` | OpenAPI 3.0 原始 schema（JSON / YAML） |
| `/api/docs/` | Swagger UI（可在线调试） |
| `/api/redoc/` | ReDoc（只读文档视图） |

## API 版本化

当 API 需要多版本并存时，DRF 提供版本控制机制。最常用的是 `AcceptHeaderVersioning`——客户端通过 `Accept` 请求头指定版本。

```python
# 通用示例（非项目代码）
REST_FRAMEWORK = {
    'DEFAULT_VERSIONING_CLASS': 'rest_framework.versioning.AcceptHeaderVersioning'
}
```

视图中通过 `self.request.version` 判断当前版本：

```python
# 通用示例（非项目代码）
@action(detail=False, methods=['get'])
def version_api(self, request):
    music = Music.objects.all()
    if self.request.version == '1.0':
        serializer = MusicSerializerV1(music, many=True)
    else:
        serializer = MusicSerializer(music, many=True)
    return Response(serializer.data)
```

客户端调用时带版本头：

```
GET /api/music/version_api/
Accept: application/json; version=1.0
```

## 一个完整的 DRF 应用骨架（本项目 api 应用）

把各组件串起来，`backend/api` 就是一个最小而完整的 DRF 应用。它由四部分构成。

序列化器（`api/serializers.py`）：

```python
from rest_framework import serializers

from learning_logs.models import Topic, Entry


class TopicSerializer(serializers.ModelSerializer):
    entry_count = serializers.IntegerField(read_only=True)

    class Meta:
        model = Topic
        fields = ['id', 'text', 'date_added', 'entry_count']
        read_only_fields = ['id', 'date_added']
```

视图集（`api/views.py`）：

```python
from rest_framework import permissions, viewsets

from learning_logs.models import Topic
from .serializers import TopicSerializer


class TopicViewSet(viewsets.ModelViewSet):
    """主题 CRUD API：仅本人数据，owner 由视图注入。"""

    queryset = Topic.objects.all()
    serializer_class = TopicSerializer
    permission_classes = [permissions.IsAuthenticated, IsOwnerOrReadOnly]

    def perform_create(self, serializer):
        serializer.save(owner=self.request.user)
```

路由（`api/urls.py`）：

```python
from django.urls import include, path
from rest_framework.routers import DefaultRouter

from . import views

router = DefaultRouter()
router.register('topics', views.TopicViewSet, basename='topic')

urlpatterns = [
    path('', include(router.urls)),
]
```

项目级挂载（`config/urls.py`）：

```python
urlpatterns = [
    # ...
    path('api/', include('api.urls')),
    path('api/schema/', SpectacularAPIView.as_view(), name='schema'),
    path('api/docs/', SpectacularSwaggerView.as_view(url_name='schema'), name='api-docs'),
]
```

启动 `python manage.py runserver`，浏览器打开 `/api/topics/` 即可看到 Browsable API 界面；打开 `/api/docs/` 查看自动生成的 Swagger 文档。
