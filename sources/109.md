# TypeScript

## 一、为什么需要 TypeScript

**JavaScript** 是动态类型语言，变量运行时可接收任意值。动态类型的挑战是缺乏类型安全，可能引入错误。例如，即使 JS 函数期望一个数组，也可以传入数字：

```js
const getRandomValue = (array) => {
  return array[Math.floor(Math.random() * array.length)];
};

console.log(getRandomValue(10));   // 输出 undefined
```

**TypeScript** 扩展了 JavaScript，加入**静态类型**，有助于在运行代码前捕获类型不匹配错误。为 `array` 参数定义类型：

```ts
const getRandomValue = (array: string[]) => {
  return array[Math.floor(Math.random() * array.length)];
};
```

该类型定义告诉 TypeScript `array` 必须是字符串数组；传入数字时会在编译期报错。

**编译器**：需先把 TypeScript 代码编译成普通 JavaScript。编译器评估代码，发现类型不匹配时抛出错误。

## 二、安装 TypeScript 与编译为 JS

### 1. 安装 TypeScript

```bash
# 全局安装
$ npm install -g typescript

# 或作为项目开发依赖（推荐）
$ npm install --save-dev typescript
```

验证安装：

```bash
$ tsc --version
```

### 2. 初始化项目

```bash
$ tsc --init    # 生成 tsconfig.json
```

### 3. 编写代码

```ts
// hello.ts
const greet = (name: string): string => `Hello, ${name}!`;
console.log(greet("TypeScript"));
```

### 4. 编译为 JS

```bash
# 编译单个文件
$ tsc hello.ts          # 生成 hello.js
$ node hello.js         # 运行编译产物

# 按 tsconfig.json 编译整个项目
$ tsc
```

`tsc` 会把 `.ts` 文件转译成 `.js`（类型在编译期被擦除，运行时仍是普通 JS）。若代码有类型错误，编译会失败并报错：

```bash
$ tsc hello.ts
# error TS2345: Argument of type 'number' is not assignable to parameter of type 'string'.
```

### 5. 监听模式与运行工具

```bash
$ tsc --watch     # 文件变化自动重新编译
$ npx tsx hello.ts  # tsx 直接运行 TS，无需先编译（适合开发/脚本）
```

> [!NOTE]
> 生产构建通常由构建工具（Vite、Webpack、tsup 等）内部调用 `tsc` 完成转译；Node 端可用 `tsx` / `ts-node` 直接运行 TS 源码。

## 三、TypeScript 中的数据类型

### 1. 原始数据类型

对原始类型 `string`、`null`、`undefined`、`number`、`boolean`、`bigint`，TypeScript 提供对应类型关键字：

```ts
let str: string = "Naomi";
let num: number = 42;
let bool: boolean = true;
let nope: null = null;
let nada: undefined = undefined;
```

### 2. 数组

两种定义特定类型数组的语法：

```ts
const arrOne: string[] = ["Naomi"];
const arrTwo: Array<string> = ["Camperchan"];
```

### 3. 对象

定义对象的确切结构：

```ts
const obj: { a: string; b: number } = { a: "Naomi", b: 42 };
```

键为任意字符串、所有值必须是字符串的对象（两种写法）：

```ts
const objOne: Record<string, string> = {};
const objTwo: { [key: string]: string } = {};
```

### 4. 其他有用类型

| 类型 | 说明 |
|---|---|
| `any` | 值可以是任意类型，告诉编译器停止关心该变量类型 |
| `unknown` | 你关心值的类型但不知道它具体是什么；通常优于 `any` |
| `void` | 用于定义无返回值的函数 |
| `never` | 表示永远不存在的类型（如永远抛错或无限循环的函数返回） |

### 5. type 关键字

类似 `const`，但用于**声明类型**而非变量。用于声明自定义类型，如联合类型或只包含特定值的类型：

```ts
type stringOrNumber = string | number;
type bot = "camperchan" | "camperbot" | "naomi";
```

### 6. interface

接口类似于「类型的类」，可实现或扩展其他接口，**专门用于对象类型**，通常优先使用（除非需要 `type` 提供的特定功能，如联合类型）：

```ts
interface wowie {
  zowie: boolean;
  method: () => void;
}
```

### 7. 定义返回类型

可在函数签名中声明返回类型：

```ts
const getRandomValue = (array: string[]): string => {
  return array[Math.floor(Math.random() * array.length)];
};
```

若尝试返回其他类型，TypeScript 会报编译错误。

## 四、泛型

**泛型（Generics）**让你定义可复用的类型，相当于给函数提供的「特殊参数」，用于控制函数类型定义的行为。

定义泛型函数：

```ts
const getRandomValue = <T>(array: T[]): T => {
  return array[Math.floor(Math.random() * array.length)];
};

const val = getRandomValue([1, 2, 4]);   // val 被推断为 number
```

- `<T>` 语法告诉 TypeScript 你正为函数定义泛型类型 `T`。`T` 是泛型常用名称，可用任意名字。
- `array: T[]` 表示参数是泛型类型的数组，返回值是该类型的单个元素。

在调用时指定类型参数（函数名和参数之间用尖括号）：

```ts
const email = document.querySelector<HTMLInputElement>("#email");
console.log(email.value);
```

这告诉 TypeScript 期望找到的是输入元素，`email.value` 有类型检查。

## 五、类型缩小（Type Narrowing）

类型缩小是在代码分支中把宽泛类型收窄为具体类型的过程。

### 1. 通过真值缩小

`document.querySelector` 可能返回 `null`，直接访问 `value` 会报错：

```ts
const email = document.querySelector<HTMLInputElement>("#email");
console.log(email.value);   // 编译错误：email 可能为 null
```

用条件语句确认真值后再访问：

```ts
if (email) {
  console.log(email.value);
}
```

真值检查也可反向使用——抛错结束代码逻辑，其后 TypeScript 知道 `email` 非 null：

```ts
if (!email) {
  throw new ReferenceError("Could not find email element!");
}
console.log(email.value);
```

### 2. 可选链

**可选链 `?.`** 也是类型缩小的一种形式：若 `email` 为 null 则不会访问属性：

```ts
console.log(email?.value);
```

### 3. typeof 操作符

用 `typeof` 判断变量类型：

```ts
const myVal = Math.random() > 0.5 ? 222 : "222";
if (typeof myVal === "number") {
  console.log(myVal / 10);
}
```

### 4. instanceof 关键字

对象来自类时用 `instanceof` 缩小类型：

```ts
const email = document.querySelector("#email");
if (email instanceof HTMLInputElement) {
  console.log(email.value);
}
```

### 5. 类型断言

当 TS 无法自动确定值类型（如 `request.json()` 的结果）时，可用类型断言 `as`：

```ts
interface User {
  name: string;
  age: number;
}

const printAge = (user: User) =>
  console.log(`${user.name} is ${user.age} years old!`);

const request = await fetch("url");
const myUser = await request.json() as User;
printAge(myUser);
```

> [!WARNING]
> 类型断言会**削弱 TypeScript 捕获潜在错误的能力**，仅在你确定值类型时使用，尽量用类型保护替代。

### 6. 类型保护

编写类型保护（type guard）函数，用 `值 is 类型` 语法：

```ts
const isValidUser = (user: unknown): user is User => {
  return !!user &&
    typeof user === "object" &&
    "name" in user &&
    "age" in user;
};
```

`user is User` 表示函数返回布尔值；返回 `true` 时表示 `user` 值满足 `User` 接口。

## 六、tsconfig 文件

TypeScript 的编译器设置存放在项目根目录的 `tsconfig.json` 中：

```json
{
  "compilerOptions": {
    "rootDir": "./src",
    "outDir": "./prod",
    "lib": ["ES2023"],
    "target": "ES2023",
    "module": "ES2022",
    "moduleResolution": "Node",
    "esModuleInterop": true,
    "skipLibCheck": true,
    "strict": true
  },
  "exclude": ["test/"]
}
```

各选项说明：

| 选项 | 说明 |
|---|---|
| `compilerOptions` | 控制 TypeScript 编译器行为 |
| `rootDir` / `outDir` | 指定源代码目录与转译后 JS 输出目录 |
| `lib` | 决定编译器使用哪些类型定义，支持特定 ES 版本、DOM 等 |
| `module` / `moduleResolution` | 管理包使用的模块类型——CommonJS 或 ECMAScript |
| `esModuleInterop` | 允许 CommonJS 和 ES 模块更顺畅互操作，自动为导入创建命名空间对象 |
| `skipLibCheck` | 跳过验证未被代码导入引用的 `.d.ts` 文件 |
| `strict` | 启用多项检查，如确保正确处理可空类型、警告回退到 `any` |
| `exclude`（顶层） | 告诉编译器编译时忽略这些文件 |

## 核心总结

1. 安装 `typescript` 后用 `tsc` 将 `.ts` 编译为 `.js`；生产由构建工具调用，开发可用 `tsx` 直接运行。
2. 类型：原始类型、数组、对象、`any/unknown/void/never`；用 `type` 声明联合类型、`interface` 描述对象。
3. **泛型 `<T>`** 复用类型定义；调用时用尖括号指定类型参数。
4. **类型缩小**：真值判断、可选链 `?.`、`typeof`、`instanceof`、类型保护；类型断言 `as` 慎用。
5. `tsconfig.json` 集中配置编译器，`strict` 模式推荐开启。
