# PostgreSQL

PostgreSQL 是关系型数据库管理系统，`psql` 是其交互式命令行客户端。

> 概念对照：数据库(database) ≈ Excel 工作簿，数据表(table) ≈ 工作表，也类似 pandas 的 DataFrame。

## 一、登录

```bash
$ psql --username=freecodecamp --dbname=postgres
```

如果失败，加 `--host=localhost` 再输入密码：

```bash
$ psql --username=freecodecamp --dbname=postgres --host=localhost
Password for user freecodecamp:
psql (16.10 ...)
SSL connection ...
postgres=>
```

直接登录管理员：

```bash
d111kc@D111KC:~$ sudo -u postgres psql
psql (16.15 (Ubuntu 16.15-0ubuntu0.24.04.1))
Type "help" for help.

postgres=#
```

## 二、psql 命令速查

| 命令 | 作用 | 说明 |
|---|---|---|
| `\l` | 列出所有数据库 | — |
| `\c <db>` | 连接数据库 | — |
| `\d` | 显示所有表 | 新库默认空 |
| `\d <table>` | 查看指定表详情 | 主要显示列信息 |

> 提示符：`postgres=>` 就绪；`postgres->` 命令未输完换行（缺分号）。**所有 SQL 语句必须用分号 `;` 结束**；psql 命令（`\l` 等）不需要分号。

## 三、数据库操作

```sql
=> CREATE DATABASE <database_name>;        -- 创建
=> ALTER DATABASE <database_name> RENAME TO <new_name>;   -- 重命名
=> DROP DATABASE <database_name>;          -- 删除
```

> psql 默认有三个数据库：`postgres`、`template0`、`template1`。

## 四、表操作

### 4.1 创建、删除、清空

```sql
=> CREATE TABLE <table_name>();                 -- 创建空表
=> CREATE TABLE <table_name>(col DATATYPE CONSTRAINT);  -- 建表时建列
=> DROP TABLE <table_name>;                     -- 删除表
=> TRUNCATE <table_names>;                      -- 清空表数据（可多表，空格分隔）
```

`TRUNCATE` 清空数据，但若某列被其他表外键引用会失败，需先清空引用表或加 `CASCADE`：

```sql
students=> TRUNCATE majors;
ERROR:  cannot truncate a table referenced in a foreign key constraint
HINT:  Truncate table "students" at the same time, or use TRUNCATE ... CASCADE.
```

### 4.2 修改表结构（ALTER TABLE）

**添加列**：

```sql
=> ALTER TABLE <table_name> ADD COLUMN <column_name> <DATATYPE> [<CONSTRAINT>] [<DEFAULT>];
```

**常用数据类型**：

| 类型 | 说明 |
|---|---|
| `INT` | 整数 |
| `VARCHAR(n)` | 字符串，如 `VARCHAR(30)` 最大 30 字符；插入时字符串用单引号 |
| `SERIAL` | 从 1 开始的整数序列（自增），自动 `INTEGER NOT NULL` + 序列 |
| `DATE` | 日期，默认值可设为 `NOW()` |
| `NUMERIC(p,s)` | 小数，如 `NUMERIC(4,1)` 整数位最多 3 位、小数 1 位 |
| `BOOLEAN` | 布尔值 `TRUE`/`FALSE`；赋值/WHERE 用小写 `true`/`false`，设默认值用大写 |

**常用约束（CONSTRAINT）**：

| 约束 | 说明 |
|---|---|
| `NOT NULL` | 非空 |
| `PRIMARY KEY` | 主键（一般通过限制条件创建） |
| `UNIQUE` | 唯一性 |

示例：

```sql
=> ALTER TABLE bikes ADD COLUMN available BOOLEAN NOT NULL DEFAULT TRUE;
=> ALTER TABLE customers ADD COLUMN customer_id SERIAL PRIMARY KEY;
```

**其他表结构操作**：

| 操作 | 命令 |
|---|---|
| 删除列 | `ALTER TABLE <t> DROP COLUMN <col>;` |
| 重命名列 | `ALTER TABLE <t> RENAME COLUMN <col> TO <new>;` |
| 删除约束 | `ALTER TABLE <t> DROP CONSTRAINT <constraint>;` |
| 添加约束到列 | `ALTER TABLE <t> ALTER COLUMN <col> SET <CONSTRAINT>;` |

## 五、键与关系

### 5.1 主键

每个表都需要主键。把已有列设为主键：

```sql
ALTER TABLE <table_name> ADD PRIMARY KEY(<column_names>);
```

多列可组成**复合主键（Composite Primary Key）**，需同时使用多列才能唯一确定一行。`\d <table>` 查看：

```sql
Indexes:
    "<table_name>_pkey" PRIMARY KEY, btree (<column_name>)
```

删除主键：

```sql
ALTER TABLE <table_name> DROP CONSTRAINT <table_name_pkey>;
```

### 5.2 外键（Foreign Key）

外键数据类型一般与对应主键相同（主键是 `SERIAL` 则外键用 `INT NOT NULL`）。外键建立的关系默认是**一对多**；不用外键可创建**多对多**。

**创建列并设为外键**：

```sql
=> ALTER TABLE <table_name> ADD COLUMN <column_name> <DATATYPE> [<CONSTRAINT>] REFERENCES <referenced_table>(<referenced_column>);
```

`referenced_table(referenced_column)` 是要关联的表和列。一般 `column_name`、`referenced_column_name` 同名同类型。

**将已有列设为外键**：

```sql
ALTER TABLE <table_name> ADD FOREIGN KEY(<column_name>) REFERENCES <referenced_table(referenced_column)>;
```

添加后 `\d <table>` 显示：

```sql
Foreign-key constraints:
    "<table>_<col>_fkey" FOREIGN KEY (<col>) REFERENCES <ref_table>(<ref_col>)
```

### 5.3 关系类型

| 关系 | 实现 |
|---|---|
| 一对多 | 外键（默认） |
| 一对一 | 给外键加 UNIQUE：`ALTER TABLE t ADD UNIQUE(col);` |
| 多对多 | 用连接表（见 §9.1） |

## 六、增删行

### 6.1 插入 `INSERT INTO`

```sql
INSERT INTO <table_name>(column_1, column_2) VALUES(<value1>, <value2>);
```

- 字符串值用单引号包裹；即使只有一列也不能省略小括号
- 可用 `NULL` 置空某单元格
- 一次插多行，多组值用逗号分隔：

```sql
INSERT INTO characters(name, homeland, favorite_color)
VALUES('Mario', 'Mushroom Kingdom', 'Red'),
('Luigi', 'Mushroom Kingdom', 'Green');
```

### 6.2 删除行 `DELETE FROM`

```sql
DELETE FROM <table_name> WHERE <condition>;
-- 例如
=> DELETE FROM second_table WHERE username='Luigi';
```

### 6.3 更新单元格 `UPDATE`

```sql
=> UPDATE <table_name> SET <column_name=new_value> WHERE <condition>;
```

condition 应使用唯一性条件，防止误改其他行。

## 七、查询数据（SELECT）

### 7.1 指定列

```sql
=> SELECT <columns> FROM <table_name>;
=> SELECT * FROM <table_name>;    -- 所有列
```

### 7.2 排序 `ORDER BY`

排序时**空值被视为最大**。

```sql
=> SELECT <columns> FROM <table_name> ORDER BY <column_name>;          -- 升序 ASC（默认）
=> SELECT <columns> FROM <table_name> ORDER BY <column_name> DESC;     -- 降序
=> SELECT <columns> FROM <table_name> ORDER BY <col1>, <col2>;         -- 多列
```

多列示例：先按 gpa 降序，gpa 相同再按 first_name 升序：

```sql
=> SELECT * FROM students ORDER BY gpa DESC, first_name;
```

### 7.3 条件查找 `WHERE`

```sql
SELECT <columns> FROM <table_name> WHERE <condition>;
```

| 条件类型 | 写法 |
|---|---|
| 比较 | `=` `>=` `>` `<=` `<` `!=`；字符串按字母序比较 |
| 逻辑 | `AND` `OR` 连接，从左到右，小括号提高优先级 |
| 模式匹配 | `<col> LIKE '<pattern>'`，`_` 单个字符、`%` 多个字符；`NOT LIKE` 相反 |
| 忽略大小写 | `ILIKE`（可配合逻辑运算符） |
| 空值 | `<col> IS NULL`、`<col> IS NOT NULL` |
| 限行数 | 末尾加 `LIMIT <number>` |

示例：

```sql
SELECT first_name, last_name, gpa FROM students WHERE gpa < 2.5;
=> SELECT * FROM students WHERE last_name < 'M' OR gpa = 3.9;
=> SELECT * FROM courses WHERE course LIKE '%lgorithms%';
=> SELECT * FROM courses WHERE course NOT ILIKE '%A%' AND course LIKE '% %';
=> SELECT * FROM students ORDER BY gpa DESC, first_name LIMIT 10;
```

### 7.4 聚合函数

只对数值列有效；比较时**忽略空值**（与排序不同，排序空值最大）。

| 函数 | 作用 | 备注 |
|---|---|---|
| `MIN(<col>)` | 最小值 | 数值列 |
| `MAX(<col>)` | 最大值 | 数值列 |
| `SUM(<col>)` | 求和 | 数值列 |
| `AVG(<col>)` | 平均值 | 数值列 |
| `CEIL(<num>)` | 向上取整 | — |
| `FLOOR(<num>)` | 向下取整 | — |
| `ROUND(<num>)` | 四舍五入 | `ROUND(<num>, <n>)` 保留 n 位小数 |
| `COUNT(<col>)` | 计数 | 空值不计数 |
| `COUNT(*)` | 总行数 | 常用 |
| `DISTINCT(<col>)` | 去重 | — |

### 7.5 分组 `GROUP BY`

```sql
SELECT <column> FROM <table> GROUP BY <column>;
SELECT <column_1>, COUNT(<column_2>) FROM <table> GROUP BY <column_1>;
```

`GROUP BY` 可配合聚合函数，例如统计每种 major_id 的行数、gpa 最小值：

```sql
SELECT major_id, COUNT(*) FROM students GROUP BY major_id;
SELECT major_id, MIN(gpa) FROM students GROUP BY major_id;
```

**条件分组 `HAVING`**：分组后的过滤条件**必须含聚合函数**：

```sql
SELECT <column> FROM <table> GROUP BY <column> HAVING <condition>;
SELECT major_id, MIN(gpa), MAX(gpa) FROM students GROUP BY major_id HAVING MAX(gpa) = 4.0;
```

**别名 `AS`**：给聚合结果列改名（默认是函数名小写形式），也可给表起别名：

```sql
SELECT <column> AS <new_column_name>;
=> SELECT major_id, COUNT(*) AS number_of_students FROM students GROUP BY major_id;
=> SELECT s.major_id FROM students AS s FULL JOIN majors AS m ON s.major_id = m.major_id;
```

## 八、多表查询（JOIN）

### 8.1 连接表（Junction Table）与多对多

多对多关系通常用**连接表**实现，拆成两个一对多：

- 连接表也是数据表，创建方式相同
- 需要两个外键，分别对应两张表的主键
- 将这两个外键设为该表的主键

### 8.2 查询两表

**通用写法**：

```sql
SELECT <columns> FROM <t1> FULL JOIN <t2> ON <t1.pkey_or_fkey> = <t2.fkey_or_pkey>;
```

> [!NOTE]
> `FULL JOIN` 可替换为 `LEFT JOIN`、`RIGHT JOIN`、`INNER JOIN`：
> - `LEFT JOIN`：结果左半部分去重后与 t1 完全相同，忽略右表关系列为空的行
> - `RIGHT JOIN`：结果右半部分去重后与 t2 完全相同，忽略左表关系列为空的行
> - `FULL JOIN`：以行数最多的表为准
> - `INNER JOIN`：只保留关系列有对应值且不为空的行
>
> JOIN 后关系列会出现两列，`SELECT` 指定时要写 `<table>.<column>`。

示例：major_id 是 students 的外键、majors 的主键，通过它合并两表：

```sql
=> SELECT * FROM students FULL JOIN majors ON students.major_id = majors.major_id;
=> SELECT students.major_id FROM students FULL JOIN majors ON students.major_id = majors.major_id;
```

**简写 `USING`**：仅当两表关系列同名时可用，输出自动合并为一列：

```sql
SELECT * FROM <t1> FULL JOIN <t2> USING(<column>);
=> SELECT * FROM students FULL JOIN majors USING(major_id);
```

### 8.3 多表查询

```sql
SELECT <columns> FROM <junction_table>
FULL JOIN <t1> ON <junction_table.fkey> = <t1.pkey>
FULL JOIN <t2> ON <junction_table.fkey> = <t2.pkey>;
```

同名列可用 `USING` 链式简写：

```sql
=> SELECT * FROM students FULL JOIN majors USING(major_id) FULL JOIN majors_courses USING(major_id);
=> SELECT * FROM students FULL JOIN majors USING(major_id) FULL JOIN majors_courses USING(major_id) FULL JOIN courses USING(course_id);
```

## 九、导出与重建

| 操作 | 命令 |
|---|---|
| 导出为 SQL | `pg_dump --clean --create --inserts --username=freecodecamp db_name > db_name.sql` |
| 导出（本地） | 上命令失败时加 `--host=localhost --password` |
| 用 SQL 重建 | `psql -U postgres < students.sql` |
| 重建（本地） | `psql -U postgres -h localhost -W < students.sql` |

## 核心总结

1. **连接**：`psql --username=xxx --dbname=xxx`；SQL 语句以 `;` 结尾。
2. **psql 命令**：`\l` 列表、`\c` 连接、`\d` 看表/详情。
3. **库表操作**：`CREATE/ALTER/DROP DATABASE`、`CREATE/DROP/TRUNCATE TABLE`、`ALTER TABLE` 增删改列与约束。
4. **数据类型**：`INT`、`VARCHAR(n)`、`SERIAL`、`DATE`、`NUMERIC(p,s)`、`BOOLEAN`。
5. **约束**：`NOT NULL`、`PRIMARY KEY`、`UNIQUE`、外键 `REFERENCES`；外键可形成一对多/多对多/一对一。
6. **增删改**：`INSERT`、`DELETE ... WHERE`、`UPDATE ... SET ... WHERE`。
7. **查询**：`WHERE`（比较/逻辑/LIKE/ILIKE/IS NULL）、`ORDER BY`、`LIMIT`、聚合函数、`GROUP BY`+`HAVING`、`AS` 别名。
8. **多表**：`FULL/LEFT/RIGHT/INNER JOIN ... ON/USING`；连接表实现多对多。
9. **导入导出**：`pg_dump` 导出、`psql < file.sql` 重建。
