
## Shell 概念

Shell 是用户与内核之间的命令解释器。Linux 默认交互 Shell 是 **bash**（Bourne Again Shell）。除交互使用外，也可把命令写成脚本批量执行。

## 环境变量

环境变量是操作系统运行时记录的关键信息，Key-Value 结构。

```bash
$ env                 # 查看全部环境变量
$ echo $HOME          # 查看单个变量值（$ 取变量值）
$ echo $PATH          # PATH 记录命令搜索路径，用 : 分隔
$ export MY_VAR=hello # 临时设置并导出环境变量
$ echo ${MY_VAR}abc   # 混合时用 {} 标注变量名
```

- 临时变量只对当前 shell 生效；要永久生效写入 `~/.bashrc`（当前用户）或 `/etc/profile`（所有用户），再 `source ~/.bashrc`。
- `PATH`：执行任何命令都按序在这些路径中搜索程序本体，可追加自定义目录 `export PATH=$PATH:~/mybin`。

## 变量

```bash
$ name="world"        # 自定义变量（等号两侧不能有空格）
$ echo "hello $name"  # 输出 hello world
$ readonly pi=3.14    # 只读变量
$ unset name          # 删除变量
```

## 引号

- 双引号 `"`：内部 `$` 变量、反引号会解析。
- 单引号 `'`：全部原样输出，不解析变量。
- 反引号 `` ` ``：包围的内容作为命令执行。

```bash
$ var="linux"
$ echo "$var"     # linux
$ echo '$var'     # $var
$ echo `date`     # 输出 date 命令结果
```

## 通配符

| 通配符 | 含义 |
|---|---|
| `*` | 0 或多个任意字符 |
| `?` | 恰好 1 个任意字符 |
| `[abc]` | 匹配括号内任意一个字符 |
| `[a-z]` | 匹配范围内的一个字符 |
| `[^abc]` | 匹配不在括号内的字符 |

```bash
$ ls *.txt          # 所有 .txt 结尾
$ ls file?.log      # file1.log、filea.log…
$ rm test*          # 删除所有 test 开头（配合 rm，注意安全）
```

## 标准流与重定向

每个命令默认有三个标准流：标准输入（stdin，0）、标准输出（stdout，1）、标准错误（stderr，2）。

| 符号 | 作用 |
|---|---|
| `>` | stdout 覆写写入文件 |
| `>>` | stdout 追加写入文件 |
| `2>` | stderr 覆写写入文件 |
| `2>>` | stderr 追加写入文件 |
| `&>` | stdout 和 stderr 一起写入文件 |
| `<` | 从文件读取作为标准输入 |

```bash
$ echo hello > out.txt        # 写入/覆写 out.txt
$ echo append >> out.txt      # 追加
$ command 2> error.log        # 错误信息写入 error.log
$ command > all.log 2>&1      # stdout 和 stderr 合并到 all.log
$ command &> all.log          # 等价写法
$ command < input.txt         # 从 input.txt 读入
```

## 管道

管道 `|` 把前一个命令的**标准输出**作为后一个命令的**标准输入**，实现命令串联。凡是能在控制台输出内容的命令都可放管道左侧。

```bash
$ ps aux | grep nginx
$ ls -l | less
$ cat access.log | grep "404" | wc -l
$ dmesg | grep -i error
```

常用组合：

```bash
$ history | tail -n 20              # 查看最近 20 条历史命令
$ df -h | awk '{print $1, $5}'      # 取第 1、5 列
$ ps aux | sort -k3 -rn | head -5   # 按 CPU 占用排序取前 5
```
