
## 模板配置与查找顺序

模板由 settings 里的 `TEMPLATES` 列表配置：

```python
TEMPLATES = [
    {
        'BACKEND': 'django.template.backends.django.DjangoTemplates',
        'DIRS': [],            # 项目级额外模板目录（如 BASE_DIR/'templates'）
        'APP_DIRS': True,      # 是否到每个 app 的 templates/ 下找
        'OPTIONS': {
            'context_processors': [ ... ],
        },
    },
]
```

查找规则：

1. `DIRS` 列出的目录按顺序查找；
2. `APP_DIRS=True` 时，再按 `INSTALLED_APPS` 的顺序到每个应用的 `templates/` 下查找。

因此通用约定是把模板放在 `templates/<app>/xxx.html`，避免不同应用同名模板互相覆盖。`render(request, 'learning_logs/base.html')` 时，Django 会在所有已装应用的 `templates/` 里找 `learning_logs/base.html`。

## DTL 三种语法

| 语法 | 用途 | 例子 |
|---|---|---|
| `{{ variable }}` | 输出变量 | `{{ topic.text }}` |
| `{% tag %}` | 逻辑控制（if / for / url…） | `{% if user.is_authenticated %}` |
| `{# comment #}` | 注释（不输出到 HTML） | `{# 注释 #}` |

变量来自视图传入的 **context**，以及 context processors 注入的全局变量（见“context processors：模板里的全局变量”）。

## 变量 `{{ }}`：点号查找规则

`{{ user.username }}` 中的点号，Django 按以下顺序依次尝试，命中即停：

1. **字典键查找**：`user['username']`
2. **属性查找**：`user.username`
3. **无参方法调用**：`user.username()`
4. **列表/元组索引**：`items.0`（取第 0 项）

几个要点：

- 变量不存在、为空或抛出异常时，Django 输出**空字符串**，不报错（这与 Jinja2 默认行为不同）。
- 方法调用不能传参数（模板里不写括号、不传参）。
- 可以多级点号：`{{ entry.topic.text }}`，但不能用任意下标表达式（如 `items.{{ i }}`）。

```html
{{ user.username }}                 {# 属性 #}
{{ entry.date_added }}              {# 模型字段 #}
{{ entry.text|truncatewords:20 }}   {# 属性 + 过滤器 #}
```

## 过滤器 `|`：链式处理输出

过滤器语法 `{{ 值|过滤器:参数 }}`，可用管道 `|` 串联多个。下面按类别给出**全部常用内置过滤器**。

### 字符串类

| 过滤器 | 作用 | 示例 / 结果 |
|---|---|---|
| `upper` | 转大写 | `{{ "hi"|upper }}` → `HI` |
| `lower` | 转小写 | `{{ "HI"|lower }}` → `hi` |
| `title` | 每个词首字母大写 | `{{ "django site"|title }}` → `Django Site` |
| `capfirst` | 句首字母大写 | `{{ "django"|capfirst }}` → `Django` |
| `length` | 长度（字符数 / 列表元素数） | `{{ "abc"|length }}` → `3` |
| `truncatechars:N` | 截断到 N 个字符（加省略号） | `{{ long|truncatechars:10 }}` |
| `truncatewords:N` | 截断到 N 个英文词 | `{{ text|truncatewords:20 }}` |
| `wordcount` | 词数 | `{{ text|wordcount }}` |
| `linebreaks` | 换行转 `<p>`/`<br>`（自动转义） | `{{ entry.text|linebreaks }}` |
| `linebreaksbr` | 只把换行转 `<br>` | |
| `striptags` | 剥掉所有 HTML 标签 | `{{ html|striptags }}` |
| `escape` | HTML 转义（默认行为） | `<` → `&lt;` |
| `safe` | 标记为安全，**不再转义** | `{{ html|safe }}` |
| `urlize` | 文本里的网址转可点击链接 | |
| `urlizetrunc:N` | 同上但截断显示 | |
| `stringformat:fmt` | Python 字符串格式化 | `{{ 5|stringformat:"03d" }}` → `005` |
| `slugify` | 转 slug（小写、连字符、去标点） | |

> **安全提醒**：模板默认对所有输出做 HTML 转义（防 XSS）。只有内容确认为可信 HTML 时才用 `|safe`；`striptags` 是另一条思路——先剥标签再输出。

### 数字类

| 过滤器 | 作用 | 示例 / 结果 |
|---|---|---|
| `add:N` | 加法（字符串数字会尝试转 int） | `{{ n|add:5 }}` |
| `divisibleby:N` | 是否能被 N 整除（布尔） | `{% if n|divisibleby:2 %}` |
| `pluralize` | 根据数量加复数后缀 | `{{ n }} book{{ n|pluralize }}`；可自定义 `pluralize:"ies,y"` |
| `floatformat:N` | 浮点保留 N 位 | `{{ 3.14159|floatformat:2 }}` → `3.14` |
| `getdigit:N` | 取数字第 N 位（从右数） | |

### 日期时间类

| 过滤器 | 作用 | 示例 |
|---|---|---|
| `date:"格式"` | 格式化日期 | `{{ d|date:'M d, Y H:i' }}` |
| `time:"格式"` | 格式化时间部分 | `{{ d|time:'H:i' }}` |
| `timesince` | 距现在多久 | `{{ d|timesince }}` → "2 days, 6 hours" |
| `timeuntil` | 距将来某时刻多久 | `{{ due|timeuntil }}` |

`date` 格式符：`Y` 四位年、`m` 月、`d` 日、`H` 24 小时、`i` 分、`N` 月份缩写、`j` 不补零日。

### 列表类

| 过滤器 | 作用 |
|---|---|
| `join:", "` | 用分隔符拼接列表 |
| `first` / `last` | 取首 / 末元素 |
| `length_is:N` | 长度是否等于 N |
| `random` | 随机取一个元素 |
| `slice:"1:3"` | 切片（同 Python 切片语法） |
| `dictsort:"field"` | 按字典/对象某字段升序排序 |
| `dictsortreversed:"field"` | 同上但降序 |

### 其他常用

| 过滤器 | 作用 |
|---|---|
| `default:"x"` | 值为假（空/None/空串）时给默认值 |
| `default_if_none:"x"` | 仅当值是 `None` 时给默认值 |
| `yesno:"是,否,也许"` | 布尔 → 三选一文字 |
| `center:N` | 居中填充到 N 宽 |
| `cut:"x"` | 删除所有指定子串 |
| `iriencode` | 把 IRI 转成 URL 安全形式 |
| `phone2numeric` | 把字母电话号转数字 |

过滤器可以链式组合：

```html
{{ entry.text|truncatewords:20|linebreaks }}
```

```html
<h4 class="card-header">
  {{ entry.date_added|date:'M d, Y H:i' }}
</h4>
<div class="card-body">{{ entry.text|linebreaks }}</div>
```

## 标签 `{% %}`：逻辑控制

### 条件：`if` / `elif` / `else`

```html
{% if user.is_authenticated %}
  <span>Hello, {{ user.username }}.</span>
{% elif request.path == '/' %}
  <span>You are on the home page.</span>
{% else %}
  <a href="{% url 'accounts:register' %}">Register</a>
{% endif %}
```

比较运算符：`== != < > <= >= in not in is is not`；逻辑：`and or not`。支持嵌套 `{% if %}`。

### 循环：`for` / `empty`

```html
<ul class="list-group border-bottom pb-2 mb-4">
  {% for topic in topics %}
    <li class="list-group-item border-0">
      <a href="{% url 'learning_logs:topic' topic.id %}">
        {{ topic.text }}</a>
    </li>
  {% empty %}
    <li class="list-group-item border-0">No topics have been added yet.</li>
  {% endfor %}
</ul>
```

`{% empty %}` 在被遍历对象为空或不存在时渲染，省去视图里判空。

循环内置变量 `forloop`：

| 变量 | 含义 |
|---|---|
| `forloop.counter` | 当前序号，从 1 开始 |
| `forloop.counter0` | 当前序号，从 0 开始 |
| `forloop.revcounter` | 倒序号，到末尾为 1 |
| `forloop.first` | 是否第一次循环（布尔） |
| `forloop.last` | 是否最后一次循环（布尔） |
| `forloop.parentloop` | 外层循环的 forloop（嵌套时用） |

### `{% with %}`：给复杂变量起别名

```html
{% with total=topic.entry_set.count %}
  {{ total }} entries
{% endwith %}
```

### `{% include %}`：引入子模板片段

```html
{% include "learning_logs/_navbar.html" %}
{% include "learning_logs/_entry.html" with entry=entry %}
```

被 include 的模板共享当前 context，也可临时传 `with` 变量。

### `{% url %}`：URL 反向解析

**不要在模板里硬编码 URL**——用命名路由反解，以后改路由规则不必改模板：

```html
{% url 'learning_logs:index' %}                 {# 无参数 #}
{% url 'learning_logs:topic' topic.id %}        {# 位置参数 #}
{% url 'accounts:register' %}                    {# 跨命名空间 #}
```

URL 的命名通过 `path(name=...)` 与 `app_name` 完成，模板中用 `{% url %}` 反查。

### `{% csrf_token %}`：跨站请求伪造防护

所有 POST 表单必须带，渲染出一个隐藏 input：

```html
<form method="post" action="{% url 'accounts:logout' %}">
  {% csrf_token %}
  <button type="submit">Log out</button>
</form>
```

### `{% load %}`：加载标签库 / 静态文件

```html
{% load static %}                 {# 加载内置 static 标签 #}
{% load django_bootstrap5 %}      {# 加载第三方标签库 #}
```

### `{% static %}`：静态文件 URL

```html
{% load static %}
<link rel="stylesheet" href="{% static 'css/styles.css' %}">
```

文件放在各 app 的 `static/<app名>/` 下；浏览器访问前缀由 settings 的 `STATIC_URL` 决定。

### 其他标签速查

| 标签 | 作用 |
|---|---|
| `{% comment %}…{% endcomment %}` | 多行注释（不输出） |
| `{% now "Y-m-d H:i" %}` | 输出当前时间（格式符同 date 过滤器） |
| `{% autoescape on/off %}…{% endautoescape %}` | 开关自动转义 |
| `{% verbatim %}…{% endverbatim %}` | 原样输出，不解析 DTL（给前端框架模板用） |
| `{% cycle 'row1' 'row2' %}` | 循环中交替输出值（斑马纹） |
| `{% firstof var1 var2 "默认" %}` | 输出第一个非空变量 |
| `{% ifchanged %}…{% endifchanged %}` | 值相对上次循环是否变化（分组渲染常用） |
| `{% lorem %}` | 输出占位 Lorem 文本 |
| `{% regroup list by field as group %}` | 按字段分组（配合 `{% for %}` 渲染） |
| `{% spaceless %}…{% endspaceless %}` | 去掉 HTML 标签间多余空白 |

## 模板继承：`extends` + `block`

模板继承让你定义一个"骨架"基模板，子模板只填充若干区块，避免每个页面复制导航栏、页脚。

### 基模板：用 `{% block %}` 预留插槽


```html
<!doctype html>
<html lang="en">
<head>
  <title>Learning Log</title>
  {% load django_bootstrap5 %}
  {% bootstrap_css %}
</head>
<body>
  <nav class="navbar navbar-expand-md navbar-light bg-light mb-4 border">
    <ul class="navbar-nav ms-auto mb-2 mb-md-0">
      {% if user.is_authenticated %}
        <li class="nav-item">
          <span class="navbar-text me-2">Hello, {{ user.username }}.</span>
        </li>
      {% else %}
        <li class="nav-item">
          <a class="nav-link" href="{% url 'accounts:register' %}">Register</a></li>
        <li class="nav-item">
          <a class="nav-link" href="{% url 'accounts:login' %}">Log in</a></li>
      {% endif %}
    </ul>
    {% if user.is_authenticated %}
      <form action="{% url 'accounts:logout' %}" method='post'>
        {% csrf_token %}
        <button name='submit' class='btn btn-outline-secondary btn-sm'>Log out</button>
      </form>
    {% endif %}
  </nav>

  <main class="container">
    <div class="pb-2 mb-2 border-bottom">
      {% block page_header %}{% endblock page_header %}
    </div>
    <div>
      {% block content %}{% endblock content %}
    </div>
  </main>
</body>
</html>
```

### 子模板：`{% extends %}` + 填充 block

```html
{% extends 'learning_logs/base.html' %}

{% block page_header %}
  <h1>{{ topic.text }}</h1>
{% endblock page_header %}

{% block content %}
  {% for entry in entries %}
    <div class="card mb-3">
      <h4 class="card-header">{{ entry.date_added|date:'M d, Y H:i' }}</h4>
      <div class="card-body">{{ entry.text|linebreaks }}</div>
    </div>
  {% empty %}
    <p>There are no entries for this topic yet.</p>
  {% endfor %}
{% endblock content %}
```

### 继承规则与 `{{ block.super }}`

- `{% extends '父模板.html' %}` 必须是子模板**第一行**；一个子模板只能 extends 一个父模板。
- 子模板不重写的 block，自动显示父模板里的默认内容。
- **多层继承**：`base.html → base_with_sidebar.html → book_list.html` 任意嵌套。
- 在子模板 block 里用 `{{ block.super }}` 可以保留父模板该 block 的原内容，再追加自己的内容。

```html
{% block sidebar %}
  {{ block.super }}

  {% if perms.learning_logs.change_entry or perms.learning_logs.delete_entry %}
  <hr>
  <ul class="sidebar-nav">
    {% if perms.learning_logs.change_entry %}
      <li><a href="{% url 'learning_logs:edit_entry' entry.id %}">Edit Entry</a></li>
    {% endif %}
    {% if perms.learning_logs.delete_entry %}
      <li><a href="{% url 'learning_logs:delete_entry' entry.id %}">Delete Entry</a></li>
    {% endif %}
  </ul>
  {% endif %}

{% endblock %}
```

## 分页模板（通用写法）

ListView 设置 `paginate_by` 后，视图自动给模板传入 `is_paginated`、`page_obj`（PaginatorPage 对象）、`paginator`。

> 示例：分页区块（learning_logs/templates/learning_logs/base.html），放在基模板里供所有列表页复用。

```html
{% block pagination %}
  {% if is_paginated %}
      <div class="pagination">
          <span class="page-links">
              {% if page_obj.has_previous %}
                  <a href="{{ request.path }}?page={{ page_obj.previous_page_number }}">previous</a>
              {% endif %}
              <span class="page-current">
                  Page {{ page_obj.number }} of {{ page_obj.paginator.num_pages }}.
              </span>
              {% if page_obj.has_next %}
                  <a href="{{ request.path }}?page={{ page_obj.next_page_number }}">next</a>
              {% endif %}
          </span>
      </div>
  {% endif %}
{% endblock %}
```

## context processors：模板里的全局变量

settings 的 `TEMPLATES[...]['OPTIONS']['context_processors']` 里配置的处理器，会把变量注入**每一个**模板。Django 默认自带四个：

| 处理器 | 注入的变量 | 内容 |
|---|---|---|
| `django.contrib.auth.context_processors.auth` | `{{ user }}`、`{{ perms }}` | 当前登录用户；当前用户权限字典 |
| `django.template.context_processors.request` | `{{ request }}` | 当前 HttpRequest 对象 |
| `django.contrib.messages.context_processors.messages` | `{{ messages }}` | messages framework 的消息列表 |
| `django.template.context_processors.debug` | `{{ debug }}`、`{{ sql_queries }}` | 调试信息 |

所以模板里能直接写 `{{ user.is_authenticated }}`、`{{ request.path }}`、`{% if perms.learning_logs.can_mark_done %}`，都是这些处理器的功劳。自定义 context processor 就是一个接收 `request`、返回字典的函数，注册到列表即可。

## 自定义过滤器与标签

当内置不够用时，在某个 app 下建 `templatetags/` 包（含 `__init__.py`），重启开发服务器后即可 `{% load %}`。

```
learning_logs/
└── templatetags/
    ├── __init__.py
    └── extras.py
```

### 自定义过滤器

```python
# templatetags/extras.py
from django import template

register = template.Library()          # 必须实例化并命名为 register

@register.filter
def shout(value):
    return str(value).upper() + '!'

@register.filter(name='cut2')          # 自定义过滤器名
def cut_two(value, arg):
    return value.replace(arg, '')
```

模板里用：

```html
{% load extras %}
{{ topic.text|shout }}
```

### 简单标签：`simple_tag`

过滤器是"改值输出"，标签是"执行任意 Python 逻辑后输出字符串"：

```python
@register.simple_tag
def total_entries(topic):
    return topic.entry_set.count()
```

```html
{% load extras %}
{% total_entries topic %} entries
```

需要访问当前上下文时加 `takes_context=True`：

```python
@register.simple_tag(takes_context=True)
def greet_user(context):
    user = context['user']
    return f'Hi, {user.username}' if user.is_authenticated else 'Hi, guest'
```

### 包含标签：`inclusion_tag`（渲染一个子模板）

```python
@register.inclusion_tag('learning_logs/_topic_card.html')
def show_topic(topic):
    return {'topic': topic}
```

```html
{% load extras %}
{% show_topic topic %}
```
