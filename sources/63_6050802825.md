
## 一、为什么需要格式化

pwsh 的 cmdlet 可以生成对象，而这些对象通常含有比 pwsh 默认显示的多得多的属性。屏幕上看到的表格只是对象的一小部分。

那么如何查看全部属性、又如何自定义想要看到的列呢？这里有两个关键命令：

- **`Gm`（Get-Member）**：查看一个对象的**所有**属性
- **`Select-Object`**：自定义想看到的属性（列）

## 二、默认格式从哪里来：.format.ps1xml 文件

运行熟悉的命令 `Get-Process`，注意结果的列头部分：列头名称与属性名称并不完全相符，每个列头都有固定的宽度、别名等。这些结果来自某些**配置文件**。

你可以在 pwsh 安装路径下找到名为 `.format.ps1xml` 的文件，其中进程对象的格式化目录位于 `DotNetTypes.format.ps1xml` 中。

> [!NOTE] 仅 Windows PowerShell
> 下面的示例用记事本打开格式文件，属于 Windows 平台的传统查看方式（`$PSHOME` 指向 Windows PowerShell 安装目录，命令适用于 Windows PowerShell 5）：

``` powershell
PS C:\Users\d111k> cd $PSHOME
PS C:\Windows\System32\WindowsPowerShell\v1.0> notepad dotnettypes.format.ps1xml
```

> [!WARNING]
> **不要保存**对该文件的任何变更。该文件带有数字签名——即使一个简单的回车或空格，都会影响签名，并阻止 pwsh 从中获取信息。

### 找到返回给 Get-Process 的确切类型

``` pwsh
pwsh> get-process | gm
```

通过 `Gm` 查看进程对象的类型名，即可定位 `.format.ps1xml` 中对应的格式化配置，理解 pwsh 为什么以当前样式展示进程信息。

## 三、如何自定义显示格式

了解格式化来源后，就可以按需定制输出：

### 1. 选择列：Select-Object

``` pwsh
# 只显示 Name、ID、VM 三列
Get-Process | Select-Object Name, ID, VM
```

### 2. 切换格式：Format-* 系列

pwsh 提供几个格式化 cmdlet 来改变展示形态：

| 命令 | 作用 |
|---|---|
| `Format-Table` | 以表格（列）形式显示，适合少量属性 |
| `Format-List` | 以列表（每属性一行）形式显示，适合查看对象全部属性 |
| `Format-Wide` | 以宽列表（单列多行）形式显示 |

``` pwsh
# 以列表形式展示进程的所有属性，适合查看完整信息
Get-Process | Format-List *

# 指定只列出某几个属性
Get-Process | Format-List Name, ID, CPU
```

> [!TIP]
> 默认格式由 pwsh 的配置文件决定（表或列表）；当你需要展示大量属性、或属性名较窄不利于表格时，用 `Format-List` 往往更清晰。

## 四、核心总结

1. cmdlet 生成的对象属性远多于默认显示；`Gm`（Get-Member）查看全部属性，`Select-Object` 自定义列。
2. pwsh 的默认显示样式来自安装目录下的 `.format.ps1xml` 配置文件（如进程对象对应 `DotNetTypes.format.ps1xml`）。
3. 格式化文件带有数字签名，**切勿修改保存**，否则会破坏签名、阻止 pwsh 读取。
4. 需要定制显示时，用 `Select-Object` 选列、用 `Format-Table` / `Format-List` 切换展示形态。
