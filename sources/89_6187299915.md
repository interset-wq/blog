
## 关联容器（Associative Containers）

按**键**组织元素，查找/插入效率高。分为两类：**有序**（红黑树，O(log n)）和**无序**（哈希表，平均 O(1)）。

### `std::map` — 键值对，有序

**特点**：每个键唯一，按键**自动排序**，底层红黑树，查找 O(log n)。

```cpp
#include <map>
#include <iostream>
using namespace std;

int main() {
    map<string, int> scores;
    scores["Alice"] = 90;         // 插入/修改
    scores["Bob"] = 85;

    cout << scores["Alice"] << endl; // 90

    // 查找（找不到返回 end()）
    auto it = scores.find("Bob");
    if (it != scores.end()) {
        cout << it->first << ": " << it->second << endl;
    }

    // 遍历（按键排序）
    for (const auto &[k, v] : scores) {
        cout << k << "=" << v << " ";
    }
}
```

### `std::set` — 集合，有序，元素唯一

```cpp
#include <set>
using namespace std;

set<int> s = {3, 1, 2, 1};  // 自动去重并排序
s.insert(5);
cout << s.count(2) << endl; // 1（存在）

for (int x : s) cout << x << " "; // 1 2 3 5
```

### `std::unordered_map` / `std::unordered_set` — 哈希版

**特点**：哈希表实现，平均查找/插入 **O(1)**，**不排序**，性能更高。

```cpp
#include <unordered_map>
#include <unordered_set>
using namespace std;

unordered_map<string, int> um = {{"a", 1}, {"b", 2}};
unordered_set<int> us = {10, 20, 30};

if (us.find(20) != us.end()) cout << "found" << endl;
```

### 关联容器对比

| 容器 | 底层 | 键唯一 | 排序 | 查找 | 适用场景 |
| --- | --- | --- | --- | --- | --- |
| `map` | 红黑树 | ✅ | 有序 | O(log n) | 需要按序遍历的键值对 |
| `set` | 红黑树 | ✅ | 有序 | O(log n) | 去重 + 有序集合 |
| `unordered_map` | 哈希表 | ✅ | 无序 | 平均 O(1) | **默认首选**的高效键值对 |
| `unordered_set` | 哈希表 | ✅ | 无序 | 平均 O(1) | 高频存在性判断 |
| `multimap`/`multiset` | 红黑树 | ❌ | 有序 | O(log n) | 允许重复键 |

## 容器适配器（Container Adapters）

封装底层容器，只暴露**受限接口**，实现特定语义。

### `std::stack` — 栈（LIFO）

```cpp
#include <stack>
using namespace std;

stack<int> st;
st.push(1);
st.push(2);
cout << st.top() << endl; // 2
st.pop();                            // 移除栈顶
cout << st.empty() << endl; // 是否为空
```

### `std::queue` — 队列（FIFO）

```cpp
#include <queue>
using namespace std;

queue<int> q;
q.push(1);
q.push(2);
cout << q.front() << endl; // 1（队首）
q.pop();                             // 出队
```

### `std::priority_queue` — 优先队列（最大堆）

**特点**：默认每次取出**最大值**，基于堆，插入/取出 O(log n)。

```cpp
#include <queue>
using namespace std;

priority_queue<int> pq;
pq.push(3);
pq.push(1);
pq.push(5);
cout << pq.top() << endl; // 5（默认最大）
pq.pop();

// 最小堆：用 greater
priority_queue<int, vector<int>, greater<int>> minpq;
```

### 适配器对比

| 适配器 | 语义 | 顶层/访问 | 底层默认 |
| --- | --- | --- | --- |
| `stack` | 后进先出 | `top()` | deque |
| `queue` | 先进先出 | `front()` / `back()` | deque |
| `priority_queue` | 优先级最高先出 | `top()` | vector（堆） |

## 常用算法（`<algorithm>`）

配合容器使用，传入迭代器范围 `[first, last)`。

```cpp
#include <vector>
#include <algorithm>
#include <iostream>
using namespace std;

int main() {
    vector<int> v = {5, 1, 4, 2, 3};

    sort(v.begin(), v.end());           // 排序（升序）
    reverse(v.begin(), v.end());        // 反转

    auto it = find(v.begin(), v.end(), 3); // 查找
    auto cnt = count(v.begin(), v.end(), 1); // 计数

    int mn = *min_element(v.begin(), v.end()); // 最小
    int mx = *max_element(v.begin(), v.end()); // 最大

    // 二分查找（需有序）：返回是否存在
    bool has = binary_search(v.begin(), v.end(), 3);

    // 求和
    int sum = accumulate(v.begin(), v.end(), 0);
    return 0;
}
```

### 常用算法速查

| 算法 | 作用 |
| --- | --- |
| `sort` | 排序 |
| `reverse` | 反转 |
| `find` | 线性查找，返回迭代器 |
| `binary_search` | 二分查找（要求有序） |
| `count` | 统计出现次数 |
| `min_element` / `max_element` | 最小 / 最大元素 |
| `accumulate` | 求和 |
| `unique` | 去重（常先 sort 再用） |
| `lower_bound` / `upper_bound` | 有序容器中的下/上界（map 常用） |

## 综合示例：统计单词出现次数

```cpp
#include <iostream>
#include <string>
#include <unordered_map>
#include <sstream>
using namespace std;

int main() {
    string text = "apple banana apple cherry banana apple";
    unordered_map<string, int> freq;
    istringstream iss(text);
    string word;

    while (iss >> word) {
        freq[word]++;   // 哈希表统计
    }

    for (const auto &[w, c] : freq) {
        cout << w << ": " << c << endl;
    }
    // apple: 3, banana: 2, cherry: 1（无序输出）
    return 0;
}
```

## STL 选型速查

| 需求 | 选择 |
| --- | --- |
| 变长数组、按下标访问 | `vector` |
| 键值对、需排序遍历 | `map` |
| 键值对、追求性能、不需排序 | `unordered_map` |
| 去重 | `set` / `unordered_set` |
| 后进先出 | `stack` |
| 先进先出 | `queue` |
| 取最大/最小 | `priority_queue` |
| 文本处理 | `string` |
| 任意位置插入删除 | `list` |
