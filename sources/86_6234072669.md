
## 权限

权限决定"已认证的请求者能做什么"。DRF 的权限在认证之后执行。

### 内置权限类

| 权限类 | 说明 |
|---|---|
| `AllowAny` | 无条件允许任何人 |
| `IsAuthenticated` | 必须已登录 |
| `IsAdminUser` | 必须是管理员（`is_staff=True`） |
| `IsAuthenticatedOrReadOnly` | 已登录可写，匿名只读（GET/HEAD/OPTIONS 放行） |
| `DjangoModelPermissions` | 按 Django 模型权限表校验 |
| `DjangoObjectPermissions` | 按对象级权限校验 |

使用方式：全局配置（`DEFAULT_PERMISSION_CLASSES`）或在视图类上指定 `permission_classes`。本项目的全局配置是 `IsAuthenticated`，而注册接口用 `AllowAny` 局部覆盖。

### 自定义权限类

继承 `permissions.BasePermission`，实现两个方法中的一个或两个：

| 方法 | 触发时机 | 作用级别 |
|---|---|---|
| `has_permission(self, request, view)` | 视图入口处 | 视图 / action 级别 |
| `has_object_permission(self, request, view, obj)` | 调用对象时（retrieve/update/destroy） | 对象级别 |

### 项目实例：IsOwnerOrReadOnly

> 示例：项目 `backend/api/permissions.py`

```python
from rest_framework import permissions


class IsOwnerOrReadOnly(permissions.BasePermission):
    """只允许资源的 owner 修改；安全方法（GET/HEAD/OPTIONS）放行。

    Entry 的 owner 是它所属 topic 的 owner。
    """

    def has_object_permission(self, request, view, obj):
        if request.method in permissions.SAFE_METHODS:
            return True
        owner = getattr(obj, 'owner', None)
        if owner is None and hasattr(obj, 'topic'):
            owner = obj.topic.owner
        return owner == request.user
```

要点：

- `permissions.SAFE_METHODS` 等于 `('GET', 'HEAD', 'OPTIONS')`——安全方法对所有人放行，写操作才校验 owner。
- `getattr(obj, 'owner', None)` 先看对象自身有没有 `owner` 属性。
- 若对象没有 `owner`（如 Entry 属于 Topic），用 `obj.topic.owner` 链式取归属——这正是本项目的处理：Entry 的 owner 是它所属 topic 的 owner。

在 ViewSet 上同时挂 `IsAuthenticated` 和 `IsOwnerOrReadOnly`：

```python
from rest_framework import permissions, viewsets


class TopicViewSet(viewsets.ModelViewSet):
    permission_classes = [permissions.IsAuthenticated, IsOwnerOrReadOnly]
```

权限列表按顺序求值：先过 `IsAuthenticated`（未登录直接拒绝），再在对象操作时过 `IsOwnerOrReadOnly`。

## 分页

当列表数据量大时，分页避免一次返回全部数据。DRF 内置三种分页方式。

### PageNumberPagination（页码分页）

最常用的分页方式。客户端通过 `?page=2` 指定页码。

```python
# 通用示例（非项目代码）
# settings.py 全局配置
REST_FRAMEWORK = {
    'DEFAULT_PAGINATION_CLASS': 'rest_framework.pagination.PageNumberPagination',
    'PAGE_SIZE': 10,
}
```

响应结构：

```json
{
    "count": 100,
    "next": "http://api.example.org/topics/?page=2",
    "previous": null,
    "results": [ ... 10 条数据 ... ]
}
```

也可以自定义分页类来调整每页条数参数名等：

```python
# 通用示例（非项目代码）
from rest_framework.pagination import PageNumberPagination


class StandardResultsSetPagination(PageNumberPagination):
    page_size = 10
    page_size_query_param = 'page_size'   # 客户端可通过 ?page_size=20 自定义
    max_page_size = 100
```

### LimitOffsetPagination（偏移分页）

客户端通过 `?limit=10&offset=20` 指定取多少条、从第几条开始。类似 SQL 的 `LIMIT` / `OFFSET`。

### CursorPagination（游标分页）

基于排序字段生成不透明游标，客户端翻页时传游标值而非页码。优点是不会因中间插入数据而重复 / 遗漏，适合无限滚动场景。

## 过滤与排序

### 查询参数手工过滤

ViewSet 里可以从 `self.request.query_params` 读查询串参数做过滤。本项目的 `EntryViewSet` 就支持 `?topic=<id>`：

```python
class EntryViewSet(viewsets.ModelViewSet):
    queryset = Entry.objects.all()

    def get_queryset(self):
        qs = Entry.objects.filter(topic__owner=self.request.user).order_by('-date_added')
        topic_id = self.request.query_params.get('topic')
        if topic_id:
            qs = qs.filter(topic_id=topic_id)
        return qs
```

`topic_id = self.request.query_params.get('topic')` 读 `?topic=5`，非空时追加 `filter(topic_id=5)`。

### SearchFilter（搜索过滤）

基于 `search` 查询参数做字段搜索，在视图上指定 `search_fields`：

```python
# 通用示例（非项目代码）
from rest_framework import filters, viewsets


class MusicViewSet(viewsets.ModelViewSet):
    queryset = Music.objects.all()
    serializer_class = MusicSerializer
    filter_backends = [filters.SearchFilter]
    search_fields = ['song', 'singer']   # ?search=周杰伦
```

### OrderingFilter（排序）

通过 `ordering` 查询参数控制排序方向：

```python
# 通用示例（非项目代码）
class MusicViewSet(viewsets.ModelViewSet):
    queryset = Music.objects.all()
    serializer_class = MusicSerializer
    filter_backends = [filters.OrderingFilter]
    ordering_fields = ['created', 'singer']   # ?ordering=-created
    ordering = ['-created']                   # 默认排序
```

### django-filter（字段精确过滤）

安装 `django-filter` 后，使用 `DjangoFilterBackend` 实现按字段精确过滤：

```powershell
uv add django-filter
```

```python
# 通用示例（非项目代码）
# settings.py
REST_FRAMEWORK = {
    'DEFAULT_FILTER_BACKENDS': ['django_filters.rest_framework.DjangoFilterBackend'],
}

# views.py
class MusicViewSet(viewsets.ModelViewSet):
    queryset = Music.objects.all()
    serializer_class = MusicSerializer
    filterset_fields = ['singer', 'created']   # ?singer=周杰伦&created=2024-01-01
```

> 本项目的 `?topic=<id>` 过滤走的是手工 `query_params` 方式（未引入 django-filter），足够满足按主题筛选条目的需求。
