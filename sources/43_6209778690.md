
> 对应 SQL：`GROUP BY`、`COUNT/SUM/AVG/MAX/MIN`、`HAVING`。
>
> 一句话记忆：**行过滤用 WHERE（分组前），组过滤用 HAVING（分组后）**。统一用这张表演示：

```python
>>> import pandas as pd
>>> df = pd.DataFrame({'city': ['北京','上海','北京','上海','北京'],
...                    'month':['1月','1月','2月','2月','1月'],
...                    'sales':[100, 90, 80, 120, 110]})
>>> df
  city month  sales
0  北京   1月    100
1  上海   1月     90
2  北京   2月     80
3  上海   2月    120
4  北京   1月    110
```

## 基础分组

```python
>>> df.groupby('city').size()                 # GROUP BY city; COUNT(*)  ← 高频！
city
北京    3
上海    2
dtype: int64
>>> df.groupby('city')['sales'].sum()         # SUM(sales)
city
北京    290
上海    210
dtype: int64
>>> df.groupby('city')['sales'].mean()        # AVG
city
北京    96.666667
上海   105.000000
dtype: float64
>>> df.groupby('city')['sales'].max()         # MAX
city
北京    110
上海    120
dtype: int64
>>> df.groupby(['city','month']).size()       # 多列分组
city  month
北京  1月      2
     2月      1
上海  1月      1
     2月      1
dtype: int64
```

## agg：多个聚合 + 自定义列名

```python
>>> df.groupby('city')['sales'].agg(['sum','mean','max'])   # 多个聚合
      sum       mean  max
city
北京   290   96.666667  110
上海   210  105.000000  120
>>> df.groupby('city')['sales'].agg(总销售额='sum', 平均='mean')  # 自定义列名
        总销售额   平均
city
北京       290   96.666667
上海       210  105.000000
>>> df.groupby('city').agg({'sales':'sum', 'month':'count'})    # 多列不同聚合
      sales  month
city
北京     290      3
上海     210      2
>>> df.groupby(['event_day','emp_id'])['total_time'].sum().reset_index()  # 多列分组聚合
```

### 真题实例：统计每个老师教的课程数（nunique → COUNT DISTINCT）

```python
# teacher: teacher_id, subject_id, dept_id
>>> df = teacher.groupby(['teacher_id'])['subject_id'].nunique().reset_index()
>>> df = df.rename(columns={'subject_id': 'cnt'})
# SQL: SELECT teacher_id, COUNT(DISTINCT subject_id) AS cnt FROM teacher GROUP BY teacher_id
```

### 真题实例：按员工按天算总工时（groupby + sum）

```python
>>> employees['total_time'] = employees['out_time'] - employees['in_time']
>>> df = employees.groupby(['event_day','emp_id'])['total_time'].sum().reset_index()
>>> df = df.rename(columns={'event_day': 'day'})
>>> df['day'] = df['day'].astype(str)
# SQL: SELECT event_day AS day, emp_id, SUM(out_time-in_time) FROM employees
#      GROUP BY event_day, emp_id
```

## 分组后过滤（HAVING）← 力扣高频

两种思路：

```python
# 思路1（推荐）：先聚合得到汇总，再对汇总布尔筛选
>>> g = df.groupby('city')['sales'].sum().reset_index()
>>> g
  city  sales
0  北京    290
1  上海    210
>>> g[g['sales'] > 250]                      # HAVING SUM(sales) > 250
  city  sales
0  北京    290

# 思路2：filter 在分组内过滤（返回原表行）
>>> df.groupby('city').filter(lambda g: g['sales'].sum() > 250)
  city month  sales
0  北京   1月    100
2  北京   2月     80
4  北京   1月    110
```

### 真题实例：班级学生数 ≥ 5

```python
# courses: class, student。显示学生数量 >= 5 的 class
>>> df = courses.groupby('class').size().reset_index(name='count')
>>> df = df[df['count'] >= 5][['class']]
# SQL: SELECT class FROM courses GROUP BY class HAVING COUNT(student) >= 5
#      （或用子查询再 WHERE）
```

## 分组键回到普通列（reset_index）

`groupby(...)` 的分组键默认变成索引。要再 merge / 筛选 / 输出成普通列时，先 `reset_index()`：

```python
>>> df.groupby('city')['sales'].sum()
city
北京    290
上海    210
dtype: int64
>>> df.groupby('city')['sales'].sum().reset_index()   # 分组键回到普通列
  city  sales
0  北京    290
1  上海    210
>>> # 分组时用 as_index=False 也可直接让分组键保持普通列：
>>> df.groupby('customer_id', as_index=False).size()
```

> 链式写法：`.groupby(...).agg(...).reset_index().sort_values(...)` 常连写（力扣 2891 专考方法链）。

## transform：把聚合结果广播回每一行

`transform` 返回与原表等长的列（不像聚合会压行），常用于"每组最大值/最小值/求和后逐行比较"。

```python
# 真题：删除重复 email，保留 id 最小的行
>>> min_id = person.groupby('email')['id'].transform('min')   # 每行得到它这组的最小 id
>>> removed = person[person['id'] != min_id]
>>> person = person.drop(removed.index)
# 等价 SQL: DELETE p1 FROM Person p1, Person p2 WHERE p1.Email=p2.Email AND p1.Id>p2.Id

# 真题：每个部门最高工资（配合 merge 用，见 05）
>>> max_salary = df.groupby('Department')['Salary'].transform('max')
>>> df = df[df.Salary == max_salary]
```

```python
# 常用聚合字符串在 transform 里的写法：'min'/'max'/'sum'/'mean'/'count'
>>> df.groupby('k')['v'].transform('max')
```

## 分组内"每组的第 N / 最大"行（窗口套路）

```python
# 每个部门工资最高的人：用 idxmax 找每组的行索引，再 loc 取
>>> idx = df.groupby('dept')['salary'].idxmax()
>>> df.loc[idx]

# 通用：每个组按某列排序取前 1（方法链）
>>> df.sort_values('salary', ascending=False).groupby('dept').head(1)
```

## 分组内累积 / 行号（窗口函数入口）

```python
>>> df['row_num'] = df.groupby('city').cumcount() + 1      # 分组内行号（ROW_NUMBER）
>>> df['cum_sum'] = df.groupby('city')['sales'].cumsum()   # 分组内累计（SUM OVER）
>>> df['grp_rank'] = df.groupby('city')['sales'].rank(method='dense', ascending=False)
```

> 更完整的窗口操作（rank / shift / rolling / diff）见 `08`。

## 一页速览

```python
>>> df.groupby('k').size()                    # GROUP BY COUNT
>>> df.groupby('k')['v'].sum()                # GROUP BY SUM
>>> df.groupby('k')['v'].agg(['sum','mean'])  # 多聚合
>>> df.groupby(['k','j'])['v'].max()          # 多列分组
>>> df.groupby('k')['v'].sum().reset_index()  # 键回普通列
>>> (df.groupby('k')['v'].sum() > 100)[...]   # HAVING
>>> df.groupby('k')['v'].transform('max')     # 聚合广播回每行
>>> idx = df.groupby('k')['v'].idxmax(); df.loc[idx]   # 每组最大
```
