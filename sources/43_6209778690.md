
> 对应 SQL：`GROUP BY`、`COUNT/SUM/AVG/MAX/MIN`、`HAVING`。
>
> 一句话记忆：**行过滤用 WHERE（分组前），组过滤用 HAVING（分组后）**。统一用这张表演示：

```python
>>> import pandas as pd
>>> df = pd.DataFrame({'city': ['北京','上海','北京','上海','北京'],
...                    'month':['1月','1月','2月','2月','1月'],
...                    'sales':[100, 90, 80, 120, 110]})
>>> df
  city month  sales
0  北京   1月    100
1  上海   1月     90
2  北京   2月     80
3  上海   2月    120
4  北京   1月    110
```

```python
>>> df.groupby('city').size()                 # GROUP BY city; COUNT(*)  ← 高频！
city

>>> df.groupby('city')['sales'].sum()         # SUM(sales)
```

## agg：多个聚合 + 自定义列名

```python
>>> df.groupby('city')['sales'].agg(['sum','mean','max'])   # 多个聚合
      sum       mean  max
city
北京   290   96.666667  110
上海   210  105.000000  120
>>> df.groupby('city')['sales'].agg(总销售额='sum', 平均='mean')  # 自定义列名
        总销售额   平均
city
北京       290   96.666667
上海       210  105.000000
>>> df.groupby('city').agg({'sales':'sum', 'month':'count'})    # 多列不同聚合
      sales  month
city
北京     290      3
上海     210      2
>>> df.groupby(['event_day','emp_id'])['total_time'].sum().reset_index()  # 多列分组聚合
```

> 🚨 **高频坑：`agg` 没有 `'size'`！**
>
> `groupby(...).agg('size')` 一定会报错（`ValueError: No objects to concatenate`），因为 **`size` 不是 `agg` 认识的聚合函数**。它属于 `GroupBy` 对象自己的方法，只能通过 `.size()` 调用，不能作为字符串塞进 `agg` 的括号里。
>
> `agg` 支持的字符串是这些：`'sum'` `'mean'` `'count'` `'nunique'` `'min'` `'max'` `'median'` `'std'` `'var'` `'first'` `'last'` ...（没有 `'size'`）。
>
> | 想做的事 | ✅ 正确写法 | ❌ 报错写法 |
> |---|---|---|
> | 每组行数 | `df.groupby('k').size()` | `df.groupby('k').agg('size')` |
> | 每组行数（同写法） | `df.groupby('k').agg(cnt=('col','count'))` | `df.groupby('k').agg(cnt=('col','size'))` |
>
> **`size` vs `count` 的区别**：
> - `.size()`：每组**行数**（含 `NaN` 的行也计数）。
> - `.agg(('col','count'))`：该列**非空值**个数（`NaN` 不计入）。
> - 两者在没有缺失值时才相等；有缺失时 `size ≥ count`。

### 真题实例：统计每个老师教的课程数（nunique → COUNT DISTINCT）

```python
# teacher: teacher_id, subject_id, dept_id
>>> df = teacher.groupby(['teacher_id'])['subject_id'].nunique().reset_index()
>>> df = df.rename(columns={'subject_id': 'cnt'})
# SQL: SELECT teacher_id, COUNT(DISTINCT subject_id) AS cnt FROM teacher GROUP BY teacher_id
```

### 真题实例：每日领导与合作伙伴（多列分组 + 两个去重计数）★力扣 1693

> 表 `daily_sales(date_id, make_name, lead_id, partner_id)`：求每个 `(date_id, make_name)` **去重后**的 lead 数、partner 数（多列 COUNT DISTINCT）：

```python
>>> daily_sales
   date_id   make_name  lead_id  partner_id
0  2020-12-8     toyota        0           1
1  2020-12-8     toyota        1           0
2  2020-12-8     toyota        1           1   # lead_id 重复
3  2020-12-7     toyota        0           2
4  2020-12-7     toyota        0           1
5  2020-12-8  ford      ...                  # （示意，略）
```

```python
# 推荐：agg 指定每个去重计数列（对应两个 COUNT(DISTINCT ...)）
>>> df = daily_sales.groupby(['date_id','make_name']).agg(
...     unique_leads    = ('lead_id',   'nunique'),
...     unique_partners = ('partner_id','nunique'),
... ).reset_index()
# SQL: SELECT date_id, make_name,
#            COUNT(DISTINCT lead_id) AS unique_leads,
#            COUNT(DISTINCT partner_id) AS unique_partners
#      FROM DailySales GROUP BY date_id, make_name

# 另一种：两列分开 nunique 再 merge 进分组表（不推荐，多写几行）
>>> g = daily_sales.groupby(['date_id','make_name']).sum().reset_index()   # ✗ 会求和 lead/partner
>>> g['unique_leads'] = daily_sales.groupby(['date_id','make_name'])['lead_id'].nunique().reset_index(name='cnt')['cnt']
```

> ⚠️ **易错**：`reset_index(name='cnt')` 才能给去重结果列改名；写成 `reset_index('cnt')` 会被当成 level 参数而报 `KeyError`。也别用 `groupby().sum()` 去承载去重结果——它把 lead_id/partner_id 加成了无意义的大数。

### 真题实例：按日期分组销售产品（自定义 lambda 聚合）★力扣 1484

> 表 `activities(sell_date, product)`：求每个 `sell_date` 的产品种类数 + 去重按字典序拼接的产品列表。第二个聚合列用自定义 lambda：`set` 去重 → `sorted` 排序 → `','.join` 拼接：

```python
>>> activities
   sell_date product
0  2020-05-30  头戴式耳机
1  2020-06-01  自行车
2  2020-06-02   手机     # 同日重复产品
3  2020-06-02   手机
4  2020-06-02   平板
5  2020-06-03   手机
6  2020-06-03   手表

>>> df = activities.groupby('sell_date').agg(
...     num_sold = ('product', 'nunique'),                      # 产品种类数
...     products = ('product', lambda x: ','.join(sorted(set(x)))),  # 去重+排序+拼接
... ).reset_index()
>>> df
   sell_date  num_sold         products
0 2020-05-30         1          头戴式耳机
1 2020-06-01         1            自行车
2 2020-06-02         2           手机,平板   # 手机去重，字典序拼接
3 2020-06-03         2           手机,手表
```

> **拆解 lambda**：`set(x)` 去重（去掉同日的重复"手机"）→ `sorted(...)` 按字典序排序 → `','.join(...)` 拼成一个字符串。聚合函数可以是任何"收一组值、吐一个标量"的函数——这是 `agg` 最强大的地方。
>
> 对应 SQL：`SELECT sell_date, COUNT(DISTINCT product) AS num_sold, GROUP_CONCAT(DISTINCT product ORDER BY product) AS products FROM Activities GROUP BY sell_date`。

### 真题实例：按员工按天算总工时（groupby + sum）

```python
>>> employees['total_time'] = employees['out_time'] - employees['in_time']
>>> df = employees.groupby(['event_day','emp_id'])['total_time'].sum().reset_index()
>>> df = df.rename(columns={'event_day': 'day'})
>>> df['day'] = df['day'].astype(str)
# SQL: SELECT event_day AS day, emp_id, SUM(out_time-in_time) FROM employees
#      GROUP BY event_day, emp_id
```

## 分组后过滤（HAVING）← 力扣高频

两种思路：

```python
# 思路1（推荐）：先聚合得到汇总，再对汇总布尔筛选
>>> g = df.groupby('city')['sales'].sum().reset_index()
>>> g
  city  sales
0  北京    290
1  上海    210
>>> g[g['sales'] > 250]                      # HAVING SUM(sales) > 250
  city  sales
0  北京    290

# 思路2：filter 在分组内过滤（返回原表行）
>>> df.groupby('city').filter(lambda g: g['sales'].sum() > 250)
  city month  sales
0  北京   1月    100
2  北京   2月     80
4  北京   1月    110
```

### 真题实例：班级学生数 ≥ 5

```python
# courses: class, student。显示学生数量 >= 5 的 class
>>> df = courses.groupby('class').size().reset_index(name='count')
>>> df = df[df['count'] >= 5][['class']]
# SQL: SELECT class FROM courses GROUP BY class HAVING COUNT(student) >= 5
#      （或用子查询再 WHERE）
```

### 真题实例：合作过至少三次的演员和导演（多列分组 + HAVING）★力扣 1050

> 表 `actor_director(actor_id, director_id, timestamp)`：找合作 **≥ 3** 次的 `(actor_id, director_id)` 对（多列分组 + 计数过滤）：

```python
>>> actor_director
   actor_id  director_id  timestamp
0         1            1          0
1         1            1          1
2         1            1          2    # 这一对出现 3 次
3         1            2          0
4         1            2          1    # 这一对出现 2 次
5         2            1          0

>>> df = actor_director.groupby(['actor_id','director_id']).size().reset_index(name='cnt')
>>> df
   actor_id  director_id  cnt
0         1            1    3
1         1            2    2
2         2            1    1
>>> df = df[df['cnt'] >= 3][['actor_id','director_id']]   # HAVING COUNT(*) >= 3
>>> df
   actor_id  director_id
0         1            1
```

> 等价写法：`actor_director.groupby(['actor_id','director_id']).filter(lambda g: len(g) >= 3)`（思路 2）。但力扣这类题"先 `size()` 聚合再布尔筛"更常用，因为既拿到计数又避免 `filter` 逐组开销。
>
> 对应 SQL：`SELECT actor_id, director_id FROM ActorDirector GROUP BY actor_id, director_id HAVING COUNT(*) >= 3`。

### 真题实例：至少有 5 名直接下属的经理（自引用表 + HAVING）★力扣 570

> 表 `employee(id, name, department, managerId)`（`managerId` 自引用本表 `id`）：找**直接下属 ≥ 5 人**的经理名字。先按 `managerId` 计数 → 筛 ≥5 的 id → 回查拿名字：

```python
>>> employee
   id   name  department  managerId
0  101   John            A        NaN   # 顶头经理，managerId 为空
1  102   Dan             A        101
2  103   James           A        101
3  104   Amy             A        101
4  105   Anne            A        101
5  106   Ron             B        101   # 101 有 4 名下属
6  107   Bob             B        102   # 102 有 3 名下属
7  108   Tom             B        102
8  109   Jim             B        102

>>> # ① 数每个经理的直接下属数（= managerId 出现的次数）
>>> cnt = employee.groupby('managerId').size().reset_index(name='cnt')
>>> cnt
   managerId  cnt
0        101    4
1        102    3

>>> # ② 筛出下属 >= 5 的经理 id（HAVING COUNT(*) >= 5）
>>> ids = cnt[cnt['cnt'] >= 5]['managerId']     # 本例没有 >=5，示意写法
>>> ids

>>> # ③ 回查 employee 拿经理名字（自引用：managerId 即员工的 id）
>>> employee[employee['id'].isin(ids)][['name']]
```

> **为什么这道题总有人卡住**：
> 1. 计数方向：是数 **`managerId` 出现的次数**（一个经理被多少行当上级引用），不是数 `id`。
> 2. `managerId` 为 `NaN`（如 John）会被 `groupby` 默认剔除（`dropna=True`），顶头经理不会计入下属名单。
> 3. 要用 `groupby(...).size()` 或 `agg(('id','count'))`，别用 `agg('size')`（`size` 不是聚合函数，会报错）。
>
> 对应 SQL：`SELECT e.name FROM Employee e WHERE e.id IN (SELECT m.managerId FROM Employee m GROUP BY m.managerId HAVING COUNT(*) >= 5)`。

## 分组键回到普通列（reset_index）

`groupby(...)` 的分组键默认变成索引。要再 merge / 筛选 / 输出成普通列时，先 `reset_index()`：

```python
>>> df.groupby('city')['sales'].sum()
city
北京    290
上海    210
dtype: int64
>>> df.groupby('city')['sales'].sum().reset_index()   # 分组键回到普通列
  city  sales
0  北京    290
1  上海    210
>>> # 分组时用 as_index=False 也可直接让分组键保持普通列：
>>> df.groupby('customer_id', as_index=False).size()
```

> 链式写法：`.groupby(...).agg(...).reset_index().sort_values(...)` 常连写（力扣 2891 专考方法链）。

## transform：把聚合结果广播回每一行

`transform` 返回与原表等长的列（不像聚合会压行），常用于"每组最大值/最小值/求和后逐行比较"。

```python
# 真题：删除重复 email，保留 id 最小的行
>>> min_id = person.groupby('email')['id'].transform('min')   # 每行得到它这组的最小 id
>>> removed = person[person['id'] != min_id]
>>> person = person.drop(removed.index)
# 等价 SQL: DELETE p1 FROM Person p1, Person p2 WHERE p1.Email=p2.Email AND p1.Id>p2.Id

# 真题：每个部门最高工资（配合 merge 用，见 05）
>>> max_salary = df.groupby('Department')['Salary'].transform('max')
>>> df = df[df.Salary == max_salary]
```

```python
# 常用聚合字符串在 transform 里的写法：'min'/'max'/'sum'/'mean'/'count'
>>> df.groupby('k')['v'].transform('max')
```

## 分组内"每组的第 N / 最大"行（窗口套路）

```python
# 每个部门工资最高的人：用 idxmax 找每组的行索引，再 loc 取
>>> idx = df.groupby('dept')['salary'].idxmax()
>>> df.loc[idx]

# 通用：每个组按某列排序取前 1（方法链）
>>> df.sort_values('salary', ascending=False).groupby('dept').head(1)
```

## 分组内累积 / 行号（窗口函数入口）

```python
>>> df['row_num'] = df.groupby('city').cumcount() + 1      # 分组内行号（ROW_NUMBER）
>>> df['cum_sum'] = df.groupby('city')['sales'].cumsum()   # 分组内累计（SUM OVER）
>>> df['grp_rank'] = df.groupby('city')['sales'].rank(method='dense', ascending=False)
```

```python
>>> df.groupby('k').size()                    # GROUP BY COUNT
>>> df.groupby('k')['v'].sum()                # GROUP BY SUM
>>> df.groupby('k')['v'].agg(['sum','mean'])  # 多聚合
>>> df.groupby(['k','j'])['v'].max()          # 多列分组
```
