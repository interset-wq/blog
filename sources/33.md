

# HTML 基础与核心元素

## 一、HTML 基础

- **HTML 的作用**：网页结构的基础，定义网页的各个元素。
- **HTML 元素**：用来表示页面内容，多数由**开始标签 + 结束标签**组成（`<h1></h1>`、`<p></p>`）。
- **HTML 结构**：由 `head`（元数据、样式）和 `body`（内容）组成。
- **常用元素**：标题（`<h1>`~`<h6>`）、段落（`<p>`）、容器（`<div>`）。
- **`div` 元素**：通用元素，**不含任何语义**，仅作为容纳其他元素的容器。

### 双标签与单标签（void elements）

```html
<!-- 双标签：开始标签 + 标签体 + 结束标签 -->
<h1>这是一级标题</h1>
<p>这是一个段落</p>

<!-- 单标签（void elements）：没有结束标签 -->
<img>   <br>   <hr>   <input>
```

> [!NOTE]
> 常见的 void 元素还有 `<meta>`、`<link>`、`<source>`、`<embed>`。它们自成一体，不包裹内容。

### 属性（attributes）

属性给元素附加元数据与行为，写在**开始标签或单标签**中：

```html
<标签名 属性名="属性值">
<img src="cat.jpg" alt="一只猫" width="200">
```

> [!NOTE] **属性规则（attribute rules）**
> 1. 不同标签有不同属性，也有通用属性（见上文"全局属性"）。
> 2. 属性名、属性值不区分大小写，但推荐小写。
> 3. 推荐用双引号包裹属性值（单引号、不写也行）。
> 4. 一个标签不要出现同名属性，否则后写的会失效。
> 5. 特殊属性无属性名、只有值，如 `<input disabled>`。

### id 与 class（Identifiers and Grouping）

FCC 把 id/class 单独列为一节，是给元素做**标识与分组**的两大手段：

| 属性 | 作用 | 特点 |
|---|---|---|
| `id` | **唯一标识** | 一个页面中不能重复；常配合 `label`、CSS、JS、锚点使用 |
| `class` | **分组** | 可给多个元素加同一类名，用于统一设置样式/行为（可多个） |

```html
<div id="header">唯一，页面中只有一个</div>
<p class="warning">多个元素可共用同一 class</p>
```

## 二、Boilerplate 文档骨架与编码

标准 HTML 骨架应作为任何页面的**起点**，它包含 `DOCTYPE`、`html`、`head`、`body`：

```html
<!DOCTYPE html>   <!-- 文档声明，必须放第一行 -->
<html lang="zh-CN">  <!-- 网页语言，利于无障碍与翻译 -->
<head>
    <meta charset="UTF-8">  <!-- UTF-8 字符编码 -->
    <title>Document</title>
</head>
<body>
    <!-- 页面内容写在这里 -->
</body>
</html>
```

- **`DOCTYPE`**：声明文档类型，让浏览器按标准模式渲染。
- **`<html lang>`**：声明语言。
- **UTF-8 字符编码**：`<meta charset="UTF-8">` 确保全世界字符（中文、Emoji 等）正常显示。

## 三、SEO 与社交分享（meta）

`meta` 提供页面元数据，不显示在页面上，但影响 SEO 与浏览器行为。FCC 重点讲了两类：

### meta description（SEO）

给网页提供简短描述，影响搜索引擎摘要：

```html
<meta name="description" content="一段与网站内容相关的描述">
```

### Open Graph（社交分享）

让链接在社交平台（微信、微博等）分享时显示卡片：

```html
<meta property="og:title" content="网页标题">
<meta property="og:description" content="分享描述">
<meta property="og:image" content="分享封面图URL">
```

### 其他常用 meta

```html
<meta charset="utf-8">                                   <!-- 字符编码 -->
<meta name="viewport" content="width=device-width, initial-scale=1.0">  <!-- 移动端适配 -->
<meta name="keywords" content="前端,HTML,CSS,JavaScript">  <!-- 关键词 -->
<meta name="robots" content="index,follow">                  <!-- 爬虫 -->
```

| robots 值 | 含义 |
|---|---|
| `index` / `noindex` | 允许/禁止索引此页 |
| `follow` / `nofollow` | 允许/禁止跟随页内链接 |
| `all` | 等价 `index, follow` |
| `none` | 等价 `noindex, nofollow` |

## 四、特殊字符与 link / script

### HTML 实体（Special Characters）

HTML 实体用于显示会被浏览器当作语法的字符，由 `&` + 实体名（或 `#` + 编号）+ 分号 `;` 组成。FCC 强调 `&amp;`、`&lt;`：

| 显示 | 描述 | 实体名 | 实体编号 |
|:---:|---|---|---|
| (空格) | 空格 | `&nbsp;` | `&#160;` |
| < | 小于号 | `&lt;` | `&#60;` |
| > | 大于号 | `&gt;` | `&#62;` |
| & | 和号 | `&amp;` | `&#38;` |
| " | 引号 | `&quot;` | `&#34;` |
| © | 版权 | `&copy;` | `&#169;` |
| ¥ | 人民币/日元 | `&yen;` | `&#165;` |
| € | 欧元 | `&euro;` | `&#8364;` |

> 例如要在页面上显示 `<p>`，必须写 `&lt;p&gt;`，否则会被当作标签解析。

### link 与 script

```html
<!-- link：链接外部样式表 -->
<link rel="stylesheet" href="styles.css">

<!-- script：嵌入外部 JavaScript 文件 -->
<script src="app.js"></script>
```

## 五、语义化 HTML 与流行三段式结构（重点）

### 标题层级结构

使用正确的标题元素维护内容**结构层级**：`h1` 最高、`h6` 最低。这帮助辅助技术与搜索引擎理解内容。

```html
<h1>页面主标题</h1>
<h2>一级小节</h2>
<h3>二级小节</h3>
```

### 表现型（presentational）元素已废弃

`center`、`big`、`font` 等元素定义**外观**而非含义，已 **deprecated**，不要使用：

```html
<!-- 差：用表现型元素 -->
<center>居中</center>
<font size="5">大号字</font>

<!-- 好：用语义 + CSS -->
<p class="center-title">居中标题</p>
```

### 语义化 HTML 元素

语义化元素为内容**提供含义**，利于 SEO、无障碍与代码可读性。FCC 重点列举：

| 元素 | 含义 |
|---|---|
| `<header>` | 页面或区块的**头部**，介绍性内容 |
| `<nav>` | **导航**链接 |
| `<article>` | **自包含**的内容（文章/帖子/评论） |
| `<aside>` | 侧边栏或**相关内容** |
| `<section>` | 文档中**相关内容的组**（通常含标题） |
| `<footer>` | 页面或区块的**页脚** |

### 流行三段式结构：header / main / footer

现代网页最常见的布局是**三段式**：`header`（页头）+ `main`（主体）+ `footer`（页脚）。这是 FCC 语义化元素的直接应用，也是你要掌握的核心模板：

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <title>三段式布局模板</title>
</head>
<body>
  <!-- ① 页头 -->
  <header>
    <h1>我的网站</h1>
    <nav>
      <a href="#home">首页</a>
      <a href="#about">关于</a>
      <a href="#contact">联系</a>
    </nav>
  </header>

  <!-- ② 主体 -->
  <main>
    <article>
      <h2>文章标题</h2>
      <section><p>正文第一段</p></section>
      <section><p>正文第二段</p></section>
    </article>

    <aside>
      <p>侧边栏相关内容</p>
    </aside>
  </main>

  <!-- ③ 页脚 -->
  <footer>
    <p>版权信息 &copy; 2026</p>
  </footer>
</body>
</html>
```

> [!TIP]
> 页面一般只有一个 `main`；`header`/`footer` 可在页面内多处出现（如 `article` 内也有自己的 header/footer）。`article` 强调**独立性**，`section` 强调**分段**，`article` 里可含多个 `section`。

## 六、语义化文本元素

FCC 逐项列出了内联语义元素，用于给**文本片段**赋予含义：

| 元素 | 含义 | 默认样式 |
|---|---|---|
| `em` | 强调（stress emphasis） | 斜体 |
| `strong` | 语气更重的强调（strong importance） | 加粗 |
| `i` | 替代语气/外来术语/技术名词/内心独白 | 斜体 |
| `b` | 引起注意但不影响语义 | 加粗 |
| `u` | 非文本性注释（如错别字标注） | 下划线 |
| `s` | 不再准确/相关的内容 | 删除线 |
| `q` | 短引用（行内） | 带引号 |
| `blockquote` | 长引用（块级） | 换行+缩进 |
| `abbr` | 缩写/缩略词，配 `title` 显示全称 | — |
| `address` | 联系信息/地址 | 斜体、块级 |
| `time` | 日期/时间 | — |
| `sup` | 上标 | 上标 |
| `sub` | 下标 | 下标 |
| `code` | 计算机代码片段 | 等宽 |
| `kbd` | 键盘输入 | 等宽 |
| `var` | 变量 | 斜体 |
| `mark` | 文本标记（高亮搜索结果） | 高亮背景 |
| `cite` | 作品标题 | 斜体 |
| `dfn` | 术语定义 | 斜体 |
| `small` | 附属细则（版权/法律） | 小字 |
| `ruby` / `rt` | 注音文字（如拼音） | — |

```html
<p>
  这是 <em>强调</em> 与 <strong>更重强调</strong>，
  以及 <i>替代语气</i> 与 <b>引起注意</b>。
  化学式 H<sub>2</sub>O，数学 x<sup>2</sup>。
  <abbr title="HyperText Markup Language">HTML</abbr>
  输入 <kbd>Ctrl+S</kbd> 保存，变量 <var>x</var> = 1。
  <code>const x = 1;</code> <q>短引用</q>
  <mark>高亮</mark> <cite>作品名</cite>
</p>

<blockquote>长引用内容，会换行并缩进。</blockquote>
<address>联系：user@example.com</address>
<time datetime="2026-10-18">2026年10月18日</time>
```

### 描述列表（dl / dt / dd）

`dl` 表示**术语-描述分组**，`dt` 是术语名，`dd` 是描述：

```html
<dl>
  <dt>大学英语</dt>
  <dd>cet-4</dd>
  <dd>cet-6</dd>
</dl>
```

### 列表

```html
<ol>            <!-- 有序列表 -->
  <li>cet-4</li>
  <li>cet-6</li>
</ol>

<ul>            <!-- 无序列表 -->
  <li>前端
    <ul><li>html</li><li>css</li></ul>   <!-- 嵌套列表 -->
  </li>
</ul>
```

> [!NOTE]
> 不要用 `br` 增加行间隔，应使用 `p` 或 CSS `margin`；`hr` 语义是分隔，想画水平线应使用 CSS。

## 七、链接、路径与行为（Paths and Link Behavior）

`a` 是行内元素，通过 `href` 跳转页面、下载文件、跳转锚点、唤起应用。

```html
<a href="https://developer.mozilla.org/zh-CN/" target="_blank">前往MDN</a>
```

### target 属性类型

| 值 | 行为 |
|---|---|
| `_self` | 当前标签页打开（默认） |
| `_blank` | 新标签页打开 |
| `_parent` | 在父框架打开 |
| `_top` | 在顶层框架打开 |

### 绝对路径 vs 相对路径

| 写法 | 含义 |
|---|---|
| `https://...` | **绝对路径**（完整 URL） |
| `./` 或省略 | 同级目录 |
| `../` | 上一级目录 |
| `/` | 站点根 |

```html
<img src="./images/cat.jpg">   <!-- 同级 images 下 -->
<img src="../img/dog.png">     <!-- 上一级 img 下 -->
```

### 链接状态（link states）

CSS 中链接有不同交互状态：

| 伪类 | 状态 |
|---|---|
| `:link` | 未访问的链接 |
| `:visited` | 已访问的链接 |
| `:hover` | 鼠标悬停 |
| `:active` | 点击激活瞬间 |

```css
a:hover { color: orange; }   /* 悬停变色 */
a:visited { color: purple; }
```

### 内部链接 / 锚点（internal links）

链接到页面其他区域：`href="#id"`，目标元素设相同 `id`：

```html
<h1 id="test2">一级标题</h1>
<a href="#test2">去 test2 锚点</a>
<a href="#">回到顶部</a>
<a href="demo.html#test2">去其他页面的锚点</a>
```

### 其他链接用法

```html
<a href="file.zip" download>下载文件</a>
<a href="tel:10086">电话联系</a>
<a href="mailto:user@example.com">邮件联系</a>
<a href="sms:10086">短信联系</a>
```

> [!WARNING]
> 具有 `href` 的 `a` 是超链接；`id` 值区分大小写，最好不要数字开头。

## 八、媒体元素与优化

### replaced elements（可替换元素）

`img`、`iframe` 等是 **replaced elements**（嵌入内容），内容由外部资源决定。

### 图片 img 与格式

`img` 是单标签，**始终提供 `alt` 文本**，利于 SEO 与无障碍：

```html
<img src="cat.jpg" alt="一只橘猫" width="200" height="150">
```

| 属性 | 作用 |
|---|---|
| `src` | 图片地址 |
| `alt` | 文本描述（加载失败时显示，供搜索引擎与屏幕阅读器） |
| `width` / `height` | 宽高（px，单位可省略） |

| 格式 | 特点 | 适用 |
|---|---|---|
| `.jpg` | 有损、颜色丰富、体积小 | 照片、宣传图 |
| `.png` | 无损、支持透明、体积大 | logo、图标 |
| `.gif` | 256 色、支持透明与动图 | 小动画 |
| `.webp` | 综合优点多、体积小 | 网页图片 |
| `.bmp` | 不压缩、体积很大 | 游戏（网页几乎不用） |
| `base64` | 文本形式，随网页加载 | 小图、图标 |

> [!TIP] **优化媒体**：合理选格式（照片用 jpg/webp、图标用 png/svg）、压缩体积、用合适的 `width/height`，可显著提升页面加载性能。

### SVG（可缩放矢量图形）

矢量图放大不失真，适合 logo、图标：

```html
<svg width="100" height="100" viewBox="0 0 100 100">
  <circle cx="50" cy="50" r="40" fill="red" />
</svg>
```

也可用 `<img src="logo.svg">` 引入外部 SVG 文件。

### 音频与视频

```html
<video src="movie.mp4" controls width="640" height="360" poster="cover.jpg">
  您的浏览器不支持 video 标签。
</video>

<audio src="song.mp3" controls>您的浏览器不支持 audio 标签。</audio>
```

`video` 常用属性：`controls`（显示控件）、`muted`（静音）、`autoplay`（自动播放）、`loop`（循环）、`poster`（封面）、`preload`。`audio` 类似（无 `width`/`height`/`poster`）。

> [!NOTE]
> 无障碍最佳实践：为音视频提供**字幕（captions）与文字稿（transcripts）**，为视频提供**音频描述（audio descriptions）**。

### 嵌入 iframe

`iframe` 是 replaced element，用于嵌入外部内容（视频、网页、广告）：

```html
<iframe src="https://www.example.com" width="600" height="400" frameborder="0" name="frame1"></iframe>

<!-- 配合 target 在框架中打开链接 -->
<a href="https://example.com/page" target="frame1">在框架中打开</a>
```

> 部分网站会拒绝被嵌入（如设置 `X-Frame-Options`）。
