## 剖析一个命令
```powershell
PS C:\Users\d111k\Desktop\hello> Get-ChildItem -Path C:\Users\d111k\Desktop\hello -Recurse -Verbose

    目录:C:\Users\d111k\Desktop\hello

Mode                 LastWriteTime         Length Name
----                 -------------         ------ ----
d----          2026/10/11    22:58                routes
-a---          2026/10/11    22:00          29966 package-lock.json
-a---          2026/10/11    22:00            272 package.json

    目录:C:\Users\d111k\Desktop\hello\routes

Mode                 LastWriteTime         Length Name
----                 -------------         ------ ----
-a---          2026/10/11    22:57              0 admin.js
-a---          2026/10/11    22:57              0 user.js
```

> [!NOTE]
> `Get-ChildItem`，别名`ls` `dir`，作用是列出目录下的文件与子文件夹

分析这个命令：

- `Get-ChildItem` 是cmdlet。PowerShell 的 cmdlet 统一遵循 **动词+名词** 的命名格式。
- `-Path C:\Users\d111k\Desktop\hello`：参数1。参数名 `-Path`，参数值为项目目录路径 `C:\Users\d111k\Desktop\hello`。
  > 如果路径字符串包含空格，必须使用双引号包裹，例如 `"C:\Program Files\demo"`。
- `-Recurse`：开关参数，不需要赋值。加上该参数代表**递归遍历子目录**，会把 `routes` 文件夹里面的文件一并列出。
- `-Verbose`：开关参数，不需要赋值。开启详细日志，命令执行时会输出详细过程信息。

> [!IMPORTANT]
> - cmdlet 和参数之间必须用空格隔开
> - 参数名固定以 `-` 开头
> - 多个参数之间用空格分隔；给一个参数传入多个值时，值之间也要有空格
> - `-` 和参数名中间**不能有空格**
> - PowerShell 不区分大小写，`GET-CHILDITEM`、`get-childitem` 执行效果完全相同

## 相关术语

- **cmdlet（command-let）**：PowerShell 原生内置命令，是PowerShell独有的概念，由.NET编写。
- **函数**：功能和cmdlet类似，但使用PowerShell脚本语言编写，不是.NET编译程序。
- **工作流**：PowerShell中一类特殊函数，用于长时间运行的分布式任务，新版本PowerShell已经很少使用。
- **应用程序**：外部独立可执行程序，不属于PowerShell cmdlet。例如查看目录树用到的 `tree.exe`，还有常见 `ping`、`ipconfig`
- **命令**：通用统称。cmdlet、函数、工作流、外部应用程序，都可以叫做命令。

## 命名规范

PowerShell cmdlet 强制推荐使用 **动词-名词单数** 的格式命名。

动词必须从 `Get-Verb` 命令返回的官方动词列表中选择，保证全生态命名统一；名词可以根据业务自定义。

示例：`Get-ChildItem`

- `Get`：官方动词，含义：获取、检索
- `ChildItem`：名词，含义：子项（文件/文件夹）

## 命令的别名

别名就是cmdlet的简短昵称，用来解决长命令输入繁琐、容易输错的问题。

> 别名仅仅是命令名称的缩写，**本身不能附带任何预定义参数**。

查看一条cmdlet拥有哪些别名，使用命令：

```powershell
PS C:\Users\d111k\Desktop\hello> Get-Alias -Definition Get-ChildItem

CommandType     Name                                               Version    Source
-----------     ----                                               -------    ------
Alias           dir -> Get-ChildItem
Alias           gci -> Get-ChildItem
Alias           ls -> Get-ChildItem
```

## 参数的别名

- **参数简写 + Tab补全** 参数名可以只输入前面若干字符，只要能够唯一识别，配合Tab键自动补全。
- **参数自带内置别名** 部分参数拥有官方内置别名
- **位置参数** 查看命令帮助文档可以看到参数的位置标记，`位置? 0` 代表第1个位置参数。位置参数传参时，可以**省略参数名**，直接填写参数值。
- 
```powershell
# 位置参数写法，省略 -Path
Get-ChildItem C:\Users\d111k\Desktop\hello -Recurse
```
> 建议：位置参数适合简短简单命令；脚本、复杂命令建议显式写出参数名，可读性更强，方便别人阅读维护。

## 快捷传参

```powershell
Show-Command Get-ChildItem
```

执行命令后，会弹出图形化对话框。你可以在界面上可视化填写各个参数，点击运行会自动生成命令，图形界面生成的PowerShell命令语法一定是正确的，适合新手快速构建复杂命令。
