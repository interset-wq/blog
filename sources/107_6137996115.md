
## useActionState Hook

### 服务端操作(server actions)

服务端操作是运行在服务端的函数，可直接在服务端处理表单，无需额外编写 API 接口。

`"use server"` 指令用于将函数标记为服务端操作。例如：

```jsx
"use server";

async function submitForm(formData) {
  const name = formData.get("name");
  return { message: `Hello, ${name}!` };
}
```

### useActionState 钩子

根据表单提交的结果更新状态，不能在服务端组件使用。基本语法如下：

```js
const [state, action, isPending] = useActionState(actionFunction, initialState, permalink);
```

- `state`：服务端操作返回的当前状态
- `action`：触发服务端操作的函数
- `isPending`：布尔值，表示服务端操作是否正在执行
- `actionFunction`：参数，传入的服务端操作函数本身
- `initialState`：参数，服务端操作执行前的初始状态
- `permalink`：可选字符串，包含表单所修改页面的唯一 URL

```jsx
"use server";

export async function submitForm(_, formData) {
  const name = formData.get("name");

  const hour = new Date().getHours();
  let greeting;

  if (hour < 12) {
    greeting = "Good morning";
  } else if (hour < 18) {
    greeting = "Good afternoon";
  } else {
    greeting = "Good evening";
  }

  return { message: `${greeting}, ${name}` };
}
```

```jsx
"use client";

// Import the useActionState hook
import { useActionState } from "react";

// Import the submitForm action
import { submitForm } from "./actions/submitForm";

const Greeter = () => {

 // Initialize the hook
 const [state, submit, isPending] = useActionState(submitForm, {
   message: "",
 });

  return (
    <div className="flex flex-col items-center justify-center min-h-screen bg-gray-100 p-6">
      {/* Rest of component */}
    </div>
  );
};

export default Greeter;
```

## React 数据请求(Data Fetching)

React 中有多种数据请求方式，既可以使用原生的 Fetch API，也可以使用 Axios、SWR 等第三方工具。Axios 是一个基于 Promise 实现的 HTTP 请求库，底层依托 XMLHttpRequest 对象构建；而 SWR 是由 Vercel 团队开发的一款用于数据请求的 React 钩子函数。

无论选择哪种数据请求方式，都需要维护几个核心状态变量：

1.  存储请求到的数据本身
2.  标记数据是否还在请求中
3.  捕获数据请求过程中可能出现的错误

```js
const [data, setData] = useState(null);
const [loading, setLoading] = useState(true);
const [error, setError] = useState(null);
```

由于数据请求属于副作用操作，最佳实践是在 `useEffect` 钩子中执行 Fetch API 调用。

请求完成后，你可以根据状态进行条件渲染：请求中显示加载提示，请求失败显示错误信息，请求成功则渲染数据内容。

### Fetch API

```js
useEffect(() => {
  const fetchData = async () => {
    try {
      const res = await fetch("https://jsonplaceholder.typicode.com/posts");
      
      if (!res.ok) {
        throw new Error("Network response was not ok");
      }

      const data = await res.json();
      setData(data);
    } catch (err) {
      setError(err);
    } finally {
      setLoading(false);
    }
  };

  fetchData();
}, []);
```

```js
if (loading) {
  return <p>Loading...</p>;
}

if (error) {
  return <p>{error.message}</p>;
}

return (
  <ul>
    {data.map((post) => (
      <li key={post.id}>{post.title}</li>
    ))}
  </ul>
);
```

### Axios

```js
import axios from "axios";

const [data, setData] = useState(null);
const [loading, setLoading] = useState(true);
const [error, setError] = useState(null);

useEffect(() => {
  const fetchData = async () => {
    try {
      const res = await axios.get(
        "https://jsonplaceholder.typicode.com/users"
      );
      setData(res.data);
    } catch (err) {
      setError(err);
    } finally {
      setLoading(false);
    }
  };

  fetchData();
}, []);
```

### SWR

```js
import useSWR from "swr";

const fetcher = (url) => fetch(url).then((res) => res.json());

const FetchTodos = () => {
 const { data, error } = useSWR(
   "https://jsonplaceholder.typicode.com/todos",
   fetcher
 );

 if (!data) {
   return <h2>Loading...</h2>;
 }
 if (error) {
   return <h2>Error: {error.message}</h2>;
 }

 return (
   <>
     <h2>Todos</h2>
     <div>
       {data.map((todo) => (
         <h3 key={todo.id}>{todo.title}</h3>
       ))}
     </div>
   </>
 );
};

export default FetchTodos;
```

## useOptimistic Hook

该钩子用于在异步操作后台执行时，保持用户界面的响应性。它支持在 UI 中实现“乐观更新”策略，即根据异步操作的预期结果，立即更新界面，无需等待服务端响应。

基本语法如下：

```js
const [optimisticState, addOptimistic] = useOptimistic(actualState, updateFunction);
```

- `optimisticState`：临时状态，会立即更新以提升用户体验
- `addOptimistic`：在实际状态更新前，应用乐观更新的函数
- `actualState`：真实状态值，来源于服务端操作等异步行为的结果
- `updateFunction`：函数，决定调用乐观更新时状态的更新逻辑

```js
"use client";

import { useOptimistic } from "react";

export default function TaskList({ tasks, addTask }) {
  const [optimisticTasks, addOptimisticTask] = useOptimistic(
    tasks,
    (state, newTask) => [...state, { text: newTask, pending: true }]
  );

  async function handleSubmit(e) {
    e.preventDefault();
    const formData = new FormData(e.target);

    addOptimisticTask(formData.get("task"));

    addTask(formData);
    e.target.reset();
  }

  return <>{/* UI */}</>;
}
```

### startTransition

`startTransition` 用于标记部分 UI 渲染和状态更新为非紧急过渡操作。这能确保在执行耗时更新时，输入、点击等紧急 UI 操作不会被阻塞。

基本语法如下：

`startTransition(action)` 其中 `action` 是执行状态更新或触发过渡相关逻辑的函数。

## useMemo Hook

### 记忆化（Memoization）

记忆化是一种优化技术，会根据特定参数缓存耗时函数的执行结果。当再次传入相同参数时，直接返回缓存结果，无需重新计算。

### useMemo 钩子

该钩子用于对计算值进行记忆化处理。例如，对大型数组排序的场景，使用 `useMemo` 后，耗时的排序函数只会在数组发生变化时重新执行。

```js
const memoizedSortedArray = useMemo(
  () => expensiveSortFunction(largeArray),
  [largeArray]
);
```

## useCallback Hook

该钩子用于对函数引用进行记忆化处理。

```js
const handleClick = useCallback(() => {
 // code goes here
}, [dependency]);
```

## React.memo

`React.memo` 用于对组件进行记忆化包装，当组件的属性未发生变化时，可避免不必要的重新渲染。

```js
const MemoizedComponent = React.memo(({ prop }) => {
 return (
   <>
     {/* Presentation */}
   </>
 )
});
```
