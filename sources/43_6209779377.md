
## SQL ↔ pandas 速查表

| 你想要 | SQL | pandas |
|---|---|---|
| 取某些列 | `SELECT a,b` | `df[['a','b']]` |
| 取一行 | — | `df.loc[0]` / `df.iloc[0]` |
| 条件筛选 | `WHERE age>25` | `df[df.age>25]` |
| AND / OR / NOT | `AND/OR/NOT` | `&` `\|` `~`（各加括号） |
| IN 列表 | `IN ('a','b')` | `df.col.isin(['a','b'])` |
| 排重 | `DISTINCT` | `df.drop_duplicates()` / `.unique()` |
| 排序 | `ORDER BY a DESC` | `df.sort_values('a', ascending=False)` |
| 前 N | `LIMIT N` | `df.head(n)` / `.nlargest(n,'col')` |
| 新增计算列 | `SELECT a*b AS c` | `df['c']=df.a*df.b` |
| 条件分支 | `CASE WHEN` | `np.where` / `.mask` / `.map` |
| 类型转换 | `CAST` | `df.col.astype(int)` |
| 分组计数 | `GROUP BY c; COUNT(*)` | `df.groupby('c').size()` |
| 分组求和 | `SUM(x)` | `df.groupby('c')['x'].sum()` |
| 多聚合 | `SUM/AVG/MAX...` | `.agg(['sum','mean','max'])` |
| 分组过滤 | `HAVING` | `.agg().reset_index()` 后布尔筛，或 `.filter()` |
| 内连接 | `INNER JOIN ON id` | `pd.merge(df1,df2,on='id')` |
| 左连接 | `LEFT JOIN` | `pd.merge(df1,df2,how='left',on='id')` |
| 右连接 | `RIGHT JOIN` | `pd.merge(df1,df2,how='right',on='id')` |
| 全连接 | `FULL OUTER JOIN` | `pd.merge(df1,df2,how='outer',on='id')` |
| 纵向合并 | `UNION ALL` | `pd.concat([df1,df2], ignore_index=True)` |
| 空值判断 | `IS NULL` | `df.col.isna()` |
| 空值填充 | `COALESCE(x,0)` | `df.col.fillna(0)` / `.ffill()` |
| 行号 | `ROW_NUMBER()` | `df.groupby(..).cumcount()+1` 或 `rank(method='first')` |
| 排名 | `RANK()/DENSE_RANK()` | `.rank(method='min'/'dense')` |
| 上一行 | `LAG(x,1)` | `df.x.shift(1)` / 组内 `.groupby(..).shift(1)` |
| 环比 | 计算式 | `df.x.pct_change()` |
| 移动均值 | 窗口函数 | `df.x.rolling(n).mean()` |
| 取年月 | `YEAR(d)/MONTH(d)` | `df.d.dt.year / .dt.month` |
| 长表变宽 | 条件聚合 | `df.pivot(...)` / `pivot_table` |
| 宽表变长 | — | `df.melt(...)` |
| 每组最大行 | 相关子查询 | `df.loc[df.groupby('k')['v'].idxmax()]` |

## 方法论

1. **先翻译成 SQL**：把题目描述写成 SQL（哪怕脑子里），再逐子句映射成 pandas。
2. **顺序检查**：`先取列 → 再筛行 → 该排序排序 → 要分组分组 → 要合并 merge`。
3. **方法链**（：`.groupby(...).agg(...).reset_index().sort_values(...)` 连续写。
4. **`groupby` 后记得 `reset_index()`**：让分组键回到普通列，才能 merge / 筛选 / 输出。
5. **空值优先处理**：先 `fillna` / `dropna`，避免聚合被 NaN 污染。
6. **多表对齐**：`merge(indicator=True)` 排查左右不匹配（对不上/缺失题）。
7. **测试小样例**：造几行数据先跑通，再验证边界（空表、单行、重复值）。

## 一页速览：最常用的 20 个操作

```python
>>> import pandas as pd, numpy as np
>>> df = pd.DataFrame(...)                 # 建表
>>> df.head(3); df.shape; df.columns       # 查看
>>> df[['a','b']]                          # 取列
>>> df[df['a']>5]                          # WHERE
>>> df[(df.a>1)&(df.b<9)]                  # AND
>>> df['c']=df['a']*2                      # 计算列
>>> df.drop_duplicates()                   # DISTINCT
>>> df.sort_values('a',ascending=False)    # ORDER BY
>>> df.nlargest(3,'a')                     # Top-3
>>> df.dropna(); df.fillna(0); df.ffill()  # 空值
>>> df.groupby('k').size()                 # GROUP BY COUNT
>>> df.groupby('k')['v'].sum()             # GROUP BY SUM
>>> df.groupby('k')['v'].agg(['sum','mean'])
>>> df.merge(df2, on='id', how='left')     # JOIN
>>> pd.concat([df1,df2], ignore_index=True)# UNION ALL
>>> df['d']=pd.to_datetime(df['d']); df.d.dt.year
>>> df['rk']=df.groupby('k')['v'].rank(method='dense', ascending=False)  # 组内排名
>>> df['prev']=df.groupby('k')['v'].shift(1)
>>> df.pivot(index=..,columns=..,values=..)
>>> df.melt(id_vars=[..],var_name=..,value_name=..)
```
