
## 概览

C++ 在 C 之上加入了**面向对象**、**泛型**和**标准模板库（STL）**。它兼容绝大多数 C 语法，同时提供了更安全、更高层的抽象。

| 特性 | 说明 |
| --- | --- |
| 多范式 | 面向对象 + 泛型 + 过程式 |
| 编译型 | 与 C 相同，需编译运行 |
| RAII | 资源管理自动化（析构释放） |
| STL | 标准模板库，内置常用数据结构和算法 |

## 编译与运行

```bash
g++ main.cpp -o main
./main
```

## 与 C 的语法差异

### 输入输出（iostream）

```cpp
#include <iostream>

int main() {
    int age;
    std::cout << "Enter age: ";
    std::cin >> age;
    std::cout << "Age is " << age << std::endl;
    return 0;
}
```

#### `std::endl` 与 `'\n'` 的区别

两者都换行，但**行为不同**：

| | `std::endl` | `'\n'` |
|---|---|---|
| 作用 | 插入换行 **并刷新缓冲区**（flush） | 只插入换行字符，**不刷新** |
| 副作用 | 触发一次输出缓冲刷新，**更慢** | 无额外开销，**更快** |
| 适用 | 少量输出、调试、需要立即显示 | 大量输出、循环内（性能关键） |

```cpp
#include <iostream>
int main() {
    // 大规模/循环输出用 '\n'，快很多
    for (int i = 0; i < 100000; ++i) {
        std::cout << i << '\n';      // 不刷新缓冲区，高效
    }
    // 少量输出、需要立刻显示时用 endl
    std::cout << "Done" << std::endl;   // 强制刷新，立即输出
    return 0;
}
```

> 记忆：**`endl` = 换行 + 刷新**，所以更"重"；默认缓冲的流（如输出到文件）里，若不用 `endl`/`flush`，内容可能要等到缓冲满或程序结束才真正写入。练习和多数场合两者都能用，追求性能时优先 `'\n'`。

## 引用（Reference）

引用是 C++ 新增的"别名"机制，比指针更安全、语法更简洁。

```cpp
int x = 10;
int &ref = x;   // ref 是 x 的别名
ref = 20;       // 等价于 x = 20

// 函数参数传引用（避免拷贝）
void increment(int &n) { n++; }
```

## 类与对象（面向对象）

```cpp
#include <iostream>
#include <string>

class Student {
private:
    std::string name;
    int age;

public:
    // 构造函数
    Student(const std::string &n, int a) : name(n), age(a) {}

    // 成员方法
    void introduce() const {
        std::cout << name << " (" << age << ")" << std::endl;
    }
};

int main() {
    Student s("Alice", 20);
    s.introduce();
    return 0;
}
```

### 三个核心特性

| 特性 | 说明 | 示例 |
| --- | --- | --- |
| 封装 | 隐藏内部细节 | `private` 成员 + 公有方法 |
| 继承 | 复用与扩展 | `class Derived : public Base` |
| 多态 | 同一接口多种实现 | 虚函数 + 基类指针/引用 |

### 继承与虚函数

```cpp
class Shape {
public:
    virtual double area() const { return 0; }  // 虚函数：支持多态
    virtual ~Shape() {}
};

class Circle : public Shape {
    double r;
public:
    explicit Circle(double radius) : r(radius) {}
    double area() const override { return 3.14159 * r * r; }
};

// 通过基类指针调用派生类实现
Shape *s = new Circle(2.0);
std::cout << s->area() << std::endl;  // 12.5664
delete s;
```

## 内存管理：new / delete

```cpp
int *p = new int(42);     // 分配并初始化
int *arr = new int[10];   // 分配数组

delete p;                 // 释放单个对象
delete[] arr;             // 释放数组
```

> 现代 C++ 推荐用 RAII 容器（`std::vector` 等）与智能指针（`std::unique_ptr`），避免手动 `delete`。

## 模板（Template，泛型）

模板让函数/类可以操作任意类型，STL 正是基于模板构建的。

```cpp
template <typename T>
T max_of(T a, T b) {
    return a > b ? a : b;
}

int main() {
    std::cout << max_of(3, 7) << std::endl;        // int
    std::cout << max_of(3.5, 2.1) << std::endl;    // double
    std::cout << max_of('a', 'z') << std::endl;    // char
}
```

## 智能指针（现代 C++）

| 类型 | 作用 |
| --- | --- |
| `std::unique_ptr<T>` | 独占所有权，自动释放，不可拷贝 |
| `std::shared_ptr<T>` | 共享所有权，引用计数归零时释放 |
| `std::weak_ptr<T>` | 弱引用，观察但不拥有 |

```cpp
#include <memory>

auto p = std::make_unique<int>(42);
std::cout << *p << std::endl;  // 42，离开作用域自动释放
```

## 小结：C → C++ 演进

| 维度 | C | C++ |
| --- | --- | --- |
| 编程范式 | 过程式 | 面向对象 + 泛型 |
| 类 | 无 | `class` |
| 内存管理 | `malloc`/`free` | `new`/`delete` + RAII/智能指针 |
| 字符串 | `char[]` | `std::string` |
| 数据结构 | 手写 | **STL 提供** |
| I/O | `printf` | `std::cout` |
