
序列化器是 DRF 的核心组件，承担两个方向的工作：

- **序列化**：把模型实例、QuerySet 等复杂数据转为 JSON 可表示的 Python 原生类型。
- **反序列化**：把客户端发来的 JSON 数据校验后还原为 Python 对象，供保存到数据库。

## 基础 Serializer（声明式字段）

最基础的用法是继承 `rest_framework.serializers.Serializer`，手动声明每个字段：

```python
from rest_framework import serializers


class CommentSerializer(serializers.Serializer):
    id = serializers.IntegerField(read_only=True)
    email = serializers.EmailField()
    content = serializers.CharField(max_length=200)
    created = serializers.DateTimeField(read_only=True)

    def create(self, validated_data):
        """反序列化时创建新对象。"""
        return Comment.objects.create(**validated_data)

    def update(self, instance, validated_data):
        """反序列化时更新已有对象。"""
        instance.email = validated_data.get('email', instance.email)
        instance.content = validated_data.get('content', instance.content)
        instance.save()
        return instance
```

常用字段类型一览：

| 字段 | 对应 Django 模型字段 | 说明 |
|---|---|---|
| `CharField` | CharField / TextField | 字符串，可设 max_length |
| `IntegerField` | IntegerField | 整数 |
| `FloatField` / `DecimalField` | FloatField / DecimalField | 浮点 / 十进制 |
| `BooleanField` | BooleanField | 布尔 |
| `DateTimeField` / `DateField` | DateTimeField / DateField | 时间 / 日期 |
| `EmailField` | EmailField | 邮箱格式校验 |
| `URLField` | URLField | URL 格式校验 |
| `PrimaryKeyRelatedField` | ForeignKey | 外键，客户端传 id |
| `HyperlinkedRelatedField` | ForeignKey | 外键，客户端传 URL |
| `SlugRelatedField` | ForeignKey | 外键，客户端传 slug 字段值 |
| `SerializerMethodField` | —— | 计算字段（见下方"高级技巧"） |

字段级校验通过 `validators` 参数或 `validate_<field_name>()` 方法定义：

```python
from rest_framework import serializers


class RegistrationSerializer(serializers.Serializer):
    username = serializers.CharField(max_length=30)
    password = serializers.CharField(write_only=True, min_length=8)

    def validate_username(self, value):
        """单个字段校验：用户名不能是 admin。"""
        if value.lower() == 'admin':
            raise serializers.ValidationError('用户名不能为 admin')
        return value

    def validate(self, data):
        """多字段联合校验。"""
        if data['password'].lower() in data['username'].lower():
            raise serializers.ValidationError('密码不能包含用户名')
        return data
```

## ModelSerializer：从模型自动生成

`ModelSerializer` 是日常开发中最常用的序列化器基类。它根据 Django 模型**自动推断字段、校验规则**，无需手动重复声明。

Meta 内部类的常用配置项：

| 配置 | 作用 | 示例 |
|---|---|---|
| `model` | 关联的 Django 模型 | `model = Entry` |
| `fields` | 包含哪些字段（元组或 `'__all__'`） | `fields = ['id', 'text', 'date_added']` |
| `exclude` | 排除哪些字段（与 fields 二选一） | `exclude = ('created',)` |
| `read_only_fields` | 指定哪些字段只读（不参与反序列化） | `read_only_fields = ['id', 'date_added']` |
| `extra_kwargs` | 给自动生成的字段追加参数 | `extra_kwargs = {'password': {'write_only': True}}` |

### 项目实例：三个 Learning Log 序列化器

`EntrySerializer` 是基础用法，`read_only_fields` 声明 `id`、`date_added` 只读：

```python
from rest_framework import serializers

from learning_logs.models import Topic, Entry


class EntrySerializer(serializers.ModelSerializer):
    """条目序列化器：topic 用主题 id 传入。"""

    class Meta:
        model = Entry
        fields = ['id', 'topic', 'text', 'date_added']
        read_only_fields = ['id', 'date_added']
```

`TopicSerializer` 额外声明了一个只读的计算字段 `entry_count`——它不在模型上，由视图的 `annotate` 提供（避免 N+1）：

```python
from rest_framework import serializers


class TopicSerializer(serializers.ModelSerializer):
    """主题序列化器：列表带条目计数（由视图 annotate 提供，避免 N+1）。"""

    entry_count = serializers.IntegerField(read_only=True)

    class Meta:
        model = Topic
        fields = ['id', 'text', 'date_added', 'entry_count']
        read_only_fields = ['id', 'date_added']
```

`UserCreateSerializer` 是注册序列化器：`password` 声明 `write_only=True`（只收不回显），重写 `validate_password`（复用站点密码校验器）与 `create`（用 `create_user` 正确哈希密码）：

```python
from django.contrib.auth import password_validation
from django.contrib.auth.models import User
from rest_framework import serializers


class UserCreateSerializer(serializers.ModelSerializer):
    """注册用序列化器：username/email/password，密码只写不回显。"""

    password = serializers.CharField(
        write_only=True,
        style={'input_type': 'password'},
    )

    class Meta:
        model = User
        fields = ['id', 'username', 'email', 'password']

    def validate_password(self, value):
        # 与站点注册页使用同一套密码校验器
        password_validation.validate_password(value)
        return value

    def create(self, validated_data):
        return User.objects.create_user(**validated_data)
```

### 反序列化时的归属校验：validate_topic

创建条目时不能往别人的主题里写。`EntrySerializer` 在 `validate_topic` 里做归属校验，防止越权：

```python
class EntrySerializer(serializers.ModelSerializer):
    class Meta:
        model = Entry
        fields = ['id', 'topic', 'text', 'date_added']
        read_only_fields = ['id', 'date_added']

    def validate_topic(self, value):
        # 创建不走对象级权限，在这里校验 topic 归属，防止往别人主题写条目
        request = self.context.get('request')
        if request and value.owner_id != request.user.id:
            raise serializers.ValidationError('只能往自己的主题添加条目。')
        return value
```

`validate_<字段名>` 的返回值会成为清洗后的数据；抛出 `serializers.ValidationError` 即校验失败，错误会挂在对应字段上。

## 高级序列化技巧

**SerializerMethodField（计算字段）**：在序列化输出时动态计算一个字段，方法名固定为 `get_<字段名>`。

```python
# 通用示例（非项目代码）
from django.utils.timezone import now
from rest_framework import serializers


class MusicSerializer(serializers.ModelSerializer):
    days_since_created = serializers.SerializerMethodField()

    class Meta:
        model = Music
        fields = ('id', 'song', 'singer', 'created', 'days_since_created')

    def get_days_since_created(self, obj):
        return (now() - obj.created).days
```

**嵌套序列化**：一个序列化器作为另一个序列化器的字段，实现一对多的嵌套输出。

```python
# 通用示例（非项目代码）
from rest_framework import serializers
from .models import Topic, Entry


class EntrySerializer(serializers.ModelSerializer):
    class Meta:
        model = Entry
        fields = ['id', 'text', 'date_added']


class TopicSerializer(serializers.ModelSerializer):
    owner = serializers.ReadOnlyField(source='owner.username')
    entries = EntrySerializer(many=True, read_only=True)

    class Meta:
        model = Topic
        fields = ['id', 'text', 'date_added', 'owner', 'entries']
        read_only_fields = ['id', 'date_added', 'owner']
```

常用模式速查：

| 模式 | 写法 | 作用 |
|---|---|---|
| 外键显示属性 | `ReadOnlyField(source='owner.username')` | 输出外键对象的某个字段值（如用户名），而非 id |
| 嵌套子对象 | `EntrySerializer(many=True, read_only=True)` | 一对多嵌套输出 |
| 只收不回显 | `CharField(write_only=True)` | 输入用（如密码），序列化输出时不出现 |
| 只读回显 | `IntegerField(read_only=True)` | 输出用（如 id），反序列化时忽略 |
| 计算字段 | `SerializerMethodField()` + `get_<字段名>` | 动态计算输出字段 |
| 列表 / 详情分离 | 写两个 Serializer，ViewSet 里按 action 切换 | 列表精简、详情完整，控制响应体积 |
| 自定义保存逻辑 | 重写 `create()` / `update()` | 如密码哈希、自动补字段 |

**自定义字段**：继承 `serializers.CharField`（或其他字段类），重写 `to_representation()`（控制序列化输出格式）和 / 或 `to_internal_value()`（控制反序列化输入解析）。
