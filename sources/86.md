

# DRF 入门与全局配置

## DRF 是什么

DRF（Django REST Framework）是 Django 生态中最流行的 REST API 框架。它在 Django 的 request/response 模型之上，提供了一套完整的 API 开发工具链：

| 能力 | 说明 |
|---|---|
| Serializer | 把模型实例 / QuerySet 序列化为 JSON，也负责 JSON 的反序列化与校验 |
| View / ViewSet | 函数视图、类视图、视图集三个层级，逐步自动化 CRUD |
| Router | 根据 ViewSet 自动生成 URL 路由，一行注册 = 一组 REST 端点 |
| 认证 | Session、Basic、Token、JWT 等多种认证方式可组合 |
| 权限 | 内置常用权限类 + 自定义权限，按 action / 对象级别控制访问 |
| 分页 | 页码分页、偏移分页、游标分页三种方式 |
| 过滤 / 排序 | SearchFilter、OrderingFilter、django-filter 集成 |
| 渲染 | JSON 渲染 + 可浏览的 API 界面（Browsable API） |
| OpenAPI | 通过 drf-spectacular 自动生成 Swagger / ReDoc 文档 |

DRF 建立在 Django 之上，直接复用已有的模型、认证与 ORM。

## 安装

用 `uv` 添加依赖：

```bash
uv add djangorestframework
uv add djangorestframework-simplejwt   # JWT 认证（可选）
uv add drf-spectacular                 # OpenAPI 文档（可选）
```

## INSTALLED_APPS 注册

在 `config/settings.py` 的 `INSTALLED_APPS` 中加入 `rest_framework`（及其可选扩展）。本项目的实际注册：

```python
# config/settings.py
INSTALLED_APPS = [
    # 自有应用
    'learning_logs',
    'accounts',
    'api',
    # 第三方
    'django_bootstrap5',
    'rest_framework',
    'rest_framework_simplejwt',
    'drf_spectacular',
    # Django 内置
    'django.contrib.admin',
    'django.contrib.auth',
    'django.contrib.contenttypes',
    'django.contrib.sessions',
    'django.contrib.messages',
    'django.contrib.staticfiles',
]
```

## REST_FRAMEWORK 全局配置

DRF 通过 `settings.py` 中的 `REST_FRAMEWORK` 字典做全局默认配置。本项目的实际配置：

```python
# config/settings.py
REST_FRAMEWORK = {
    'DEFAULT_AUTHENTICATION_CLASSES': (
        'rest_framework_simplejwt.authentication.JWTAuthentication',
    ),
    'DEFAULT_PERMISSION_CLASSES': (
        'rest_framework.permissions.IsAuthenticated',
    ),
    'DEFAULT_SCHEMA_CLASS': 'drf_spectacular.openapi.AutoSchema',
}
```

常用配置键一览：

| 配置键 | 作用 | 常用值 |
|---|---|---|
| `DEFAULT_AUTHENTICATION_CLASSES` | 默认认证方式 | `SessionAuthentication`, `BasicAuthentication`, `JWTAuthentication` |
| `DEFAULT_PERMISSION_CLASSES` | 默认权限 | `IsAuthenticated`, `AllowAny`, `IsAuthenticatedOrReadOnly` |
| `DEFAULT_PAGINATION_CLASS` | 默认分页类 | `PageNumberPagination` |
| `PAGE_SIZE` | 每页条数 | `10` |
| `DEFAULT_FILTER_BACKENDS` | 默认过滤后端 | `SearchFilter`, `OrderingFilter`, `DjangoFilterBackend` |
| `DEFAULT_RENDERER_CLASSES` | 默认渲染器 | `JSONRenderer`, `BrowsableAPIRenderer` |
| `DEFAULT_SCHEMA_CLASS` | OpenAPI schema 类 | `drf_spectacular.openapi.AutoSchema` |
| `DEFAULT_VERSIONING_CLASS` | API 版本控制方式 | `AcceptHeaderVersioning` 等 |

> 全局配置是默认值，任何视图 / ViewSet 上都可以用 `authentication_classes = [...]`、`permission_classes = [...]` 局部覆盖。

## 渲染器与 Browsable API

渲染器决定 DRF 把数据以什么格式返回给客户端。

| 渲染器 | 输出 | 说明 |
|---|---|---|
| `JSONRenderer` | `application/json` | 纯 JSON，生产环境默认 |
| `BrowsableAPIRenderer` | HTML 页面 | 可浏览的 API 调试界面，浏览器访问时自动启用 |

`BrowsableAPIRenderer` 是 DRF 的特色功能：在浏览器里直接打开 API 地址，会看到一个可交互的调试页面，可以在线发请求、看响应、试不同参数。开发阶段非常方便。

DRF 默认同时启用 `JSONRenderer` 与 `BrowsableAPIRenderer`，并根据 `Accept` 请求头自动选择。若需显式指定，可全局配置：

```python
REST_FRAMEWORK = {
    'DEFAULT_RENDERER_CLASSES': (
        'rest_framework.renderers.JSONRenderer',
        'rest_framework.renderers.BrowsableAPIRenderer',
    ),
}
```

## 项目里的 API 入口

REST API 挂载在项目级 URLconf（`config/urls.py`）里：

```python
# config/urls.py
from django.contrib import admin
from django.urls import path, include

urlpatterns = [
    path('admin/', admin.site.urls),
    path('accounts/', include('accounts.urls')),
    path('', include('learning_logs.urls')),
    # REST API (DRF)
    path('api/', include('api.urls')),
]
```

`api.urls` 里用 Router 自动生成端点。开发时访问 `/api/topics/` 即可看到 Browsable API 界面。
