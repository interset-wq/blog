
## 查看内容

```bash
$ cat file.txt          # 一次性输出全部内容（适合小文件）
$ cat -n file.txt       # 带行号输出
$ more file.txt         # 分页查看，空格翻页、q 退出
$ less file.txt         # 分页查看，支持上下翻/搜索（推荐）
$ head -n 10 file.txt   # 查看前 10 行
$ tail -n 20 file.txt   # 查看最后 20 行
$ tail -f /var/log/syslog   # 实时跟踪文件新增内容（看日志）
```

## 统计与排序

```bash
$ wc -l file.txt        # 统计行数（-c 字节、-m 字符、-w 单词）
$ sort file.txt         # 排序
$ sort -r file.txt      # 反向排序
$ sort -n file.txt      # 按数值排序
$ uniq file.txt         # 去重（常与 sort 连用）
```

## grep：文本过滤

`grep`（global regular expression print）在一个或多个文件中搜索匹配模式的行并打印，不修改原文件。常与管道、正则配合做日志与配置文件分析。

### 基本用法

```bash
$ grep "error" app.log              # 过滤包含 error 的行
$ grep "error" *.log                # 匹配多个文件，结果前显示文件名
$ grep "error" file1 file2 file3    # 显式指定多个文件
```

### 常用选项

| 选项 | 作用 |
|---|---|
| `-i` | 忽略大小写 |
| `-n` | 显示匹配行号 |
| `-v` | 反向匹配，输出**不**匹配的行 |
| `-r` / `-R` | 递归搜索目录（-R 跟随软链接） |
| `-c` | 只统计匹配行数 |
| `-l` / `-L` | 只列出包含/不包含匹配的文件名 |
| `-o` | 只输出匹配的部分（而非整行） |
| `-w` | 整词匹配（word），避免子串误匹配 |
| `-E` | 使用扩展正则（等价 `egrep`） |
| `-P` | 使用 Perl 兼容正则（支持前瞻/后顾） |
| `-A n` / `-B n` / `-C n` | 同时输出匹配后/前/前后各 n 行（context） |
| `--include=*.log` | 递归时只搜索指定类型文件 |
| `--exclude=*.tmp` | 递归时排除指定文件 |

```bash
$ grep -rn "listen" /etc/nginx/          # 递归+行号，查配置
$ grep -c "404" access.log               # 统计 404 次数
$ grep -oE "[0-9]{1,3}\.[0-9]{1,3}\.[0-9]{1,3}\.[0-9]{1,3}" access.log | sort | uniq -c | sort -rn
$ grep -A2 -B1 "timeout" app.log         # 查看匹配行附近上下文
$ grep -w "is" text.txt                  # 精确匹配单词 is，不匹配 this
$ grep -E "error|warn|fatal" app.log     # 多关键词（扩展正则）
```

### 正则表达式

| 元字符 | 含义 | 示例 |
|---|---|---|
| `^` | 行首锚点 | `^#` 匹配以 # 开头的行 |
| `$` | 行尾锚点 | `error$` 匹配以 error 结尾 |
| `.` | 任意单个字符 | `a.c` 匹配 abc、adc |
| `*` | 前一个字符重复 0 次或多次 | `ab*c` 匹配 ac、abbc |
| `+` | 前一个字符重复 1 次或多次（需 -E） | `a+c` 匹配 ac、aac |
| `?` | 前一个字符出现 0 次或 1 次（需 -E） | `colou?r` 匹配 color、colour |
| `{n}` / `{n,m}` | 重复次数（需 -E） | `[0-9]{3}` 匹配三位数字 |
| `[abc]` | 字符集，任一 | `[Ff]ile` 匹配 File、file |
| `[a-z]` / `[0-9]` | 范围 | `[0-9]` 匹配任意数字 |
| `[^abc]` | 取反字符集 | `[^0-9]` 匹配非数字 |
| `\|` | 或（需 -E） | `error\|fatal` |
| `\(...\)` | 分组捕获（基础正则） | `\(ab\)\+` |
| `\b` | 单词边界 | `\bcat\b`（需 -P 或 -E） |
| `\d` | 数字（需 -P） | 等价 `[0-9]` |

> [!NOTE]
> 基础正则（BRE）中 `+`、`?`、`{`、`\|`、`(` 需加反斜杠转义；使用 `grep -E` 或 `egrep`（扩展正则 ERE）则无需转义。日志里的 IP、时间戳、状态码过滤常用 `-E` 或 `-P`。

```bash
# 过滤 2025 年的日志行（基础正则）
$ grep "^2025-" app.log
# 提取所有 IP 地址（扩展正则）
$ grep -Eo "[0-9]+(\.[0-9]+){3}" access.log | sort | uniq
# 过滤 5xx 状态码及前后 1 行
$ grep -E "HTTP/1\.[01]\" 5[0-9][0-9]" -A1 -B1 access.log
```

## sed：流编辑器

`sed`（stream editor）对文本流逐行处理，适合批量替换、行范围操作、原地修改文件。默认把结果输出到标准输出，不改变原文件；加 `-i` 才原地修改。

### 基本格式

```
$ sed [选项] '脚本' 文件
```

`脚本` 由**地址**（选哪些行）和**命令**（对这些行做什么）组成，地址可省略（默认所有行）。

| 选项 | 作用 |
|---|---|
| `-n` | 只输出被命令处理的行（配合 `p` 打印） |
| `-i` | 原地修改文件（可 `-i.bak` 先备份） |
| `-e` | 一次执行多个脚本 |
| `-f` | 从脚本文件读取命令 |

### 地址（选择行）

```bash
$ sed -n '2,5p' file.txt          # 打印第 2~5 行
$ sed -n '1p' file.txt            # 打印第 1 行
$ sed -n '3,$p' file.txt          # 第 3 行到末尾
$ sed -n '/error/p' file.txt      # 匹配 error 的行
$ sed -n '/^#/,/^$/p' file.txt    # 从 # 开头到空行的区间
$ sed -n '1~2p' file.txt          # 从第 1 行开始每隔 2 行（奇数行）
```

### 常用命令

| 命令 | 作用 |
|---|---|
| `p` | 打印匹配行（常配 -n） |
| `d` | 删除匹配行 |
| `s/old/new/` | 行内替换，默认只替换第一个匹配 |
| `s/old/new/g` | 全局替换（行内所有匹配） |
| `a\` | 在匹配行后追加 |
| `i\` | 在匹配行前插入 |
| `c\` | 用新文本整行替换匹配行 |
| `=` | 输出行号 |
| `y/ab/cd/` | 逐字符替换（a→c、b→d） |

### 替换详解 `s///`

```bash
$ sed 's/old/new/' file.txt            # 每行只替换第一个 old
$ sed 's/old/new/g' file.txt           # 全局替换
$ sed 's/old/new/2' file.txt           # 只替换每行第 2 个匹配
$ sed 's/old/new/gi' file.txt          # 全局+忽略大小写
$ sed '3,5s/old/new/g' file.txt        # 只对第 3~5 行替换
$ sed '/^#/s/old/new/g' file.txt       # 只对 # 开头的行替换
$ sed 's/old/new/g' -i.bak file.txt    # 原地修改，原文件备份为 file.txt.bak
$ sed 's/\(旧组\)/\1 新组/'            # \1 引用捕获组
```

```bash
# 经典：把 /home/user 改为 /opt（/ 分隔符冲突时改用 | 替代）
$ sed 's|/home/user|/opt|g' file.txt
# 去除每行首尾空格
$ sed 's/^[[:space:]]*//; s/[[:space:]]*$//' file.txt
# 用捕获组调换两列（基于冒号分隔）
$ echo "a:b" | sed 's/\([^:]*\):\([^:]*\)/\2:\1/'
# 批量替换配置文件中的端口
$ sed -i 's/Listen 80/Listen 8080/g' /etc/apache2/ports.conf
```

> [!WARNING]
> `sed -i` 会直接改写文件且不可撤销，务必先备份（`-i.bak`）或先不带 `-i` 预览输出。

### 删除与行操作

```bash
$ sed '/^#/d' config.conf          # 删除所有注释行（输出，不写回）
$ sed -i '/^$/d' file.txt          # 原地删除所有空行
$ sed '2d;5d' file.txt             # 删除第 2 行和第 5 行
$ sed '/error/d' app.log           # 删除含 error 的行
$ sed '/debug/a\# new line' f.txt  # 在含 debug 的行后追加
$ sed '/debug/i\# before' f.txt    # 在含 debug 的行前插入
```

### 与管道组合

```bash
$ ps aux | sed -n '2,$p' | sort -k3 -rn | head -5   # 去掉标题行再排 CPU
$ df -h | sed -n '2,$p'                              # 跳过表头
$ cat access.log | grep 404 | sed 's/.*"\([A-Z]*\) .*/\1/'   # 提取请求方法
```

## 组合用法

```bash
$ cat access.log | grep "404" | head -n 10   # 管道串联
$ ps aux | grep nginx
$ tail -f /var/log/syslog | grep error
```
