
`fs`（文件系统）与 `path`（路径）常常配合使用：先定位路径，再读写文件。

## `fs` 模块

**用途**：提供创建、读取、写入、追加、删除文件和目录的方法。

### 三种使用风格

| 风格 | 特点 | 适用场景 |
| --- | --- | --- |
| 回调式（异步） | 基于回调 | 常规异步代码 |
| Promise 式（`fs/promises`） | 基于 Promise/async-await | 现代推荐 |
| 同步式（`Sync` 后缀） | **阻塞事件循环** | 仅适合脚本 |

> 同步方法会阻塞事件循环，因此只适合脚本场景，不适合服务器请求处理。

### 核心文件方法

| 方法 | 作用 |
| --- | --- |
| `writeFile()` | 写入文件（不存在则创建） |
| `appendFile()` | 向已存在文件**追加**内容，不覆盖原内容 |
| `readFile()` | 读取文件。传 `"utf8"` 返回字符串，省略则返回 **Buffer** |
| `unlink()` | 删除文件。文件不存在时抛出 `ENOENT` |

```js
const fs = require("fs/promises");

async function writeToFile() {
  try {
    await fs.writeFile("article.md", "## Node `fs` Module", "utf8");
    console.log("File written to!");
  } catch (err) {
    console.error("Error writing to file:", err);
  }
}
```

### 目录方法

| 方法 | 作用 |
| --- | --- |
| `mkdir(dir, { recursive: true })` | 递归创建目录 |
| `readdir(dir)` | 读取目录内容（返回数组） |
| `rm(dir, { recursive: true, force: true })` | 递归删除目录 |

### 三种使用风格对比

```js
// 1. 回调风格（异步，旧式）
const fsCb = require("fs");
fsCb.writeFile("a.txt", "hello", "utf8", (err) => {
  if (err) return console.error(err);
  console.log("written (callback)");
});

// 2. Promise 风格（推荐）
const fsP = require("fs/promises");
async function demo() {
  await fsP.writeFile("a.txt", "hello", "utf8");
  const data = await fsP.readFile("a.txt", "utf8");
  console.log(data); // hello
}

// 3. 同步风格（阻塞事件循环，仅脚本使用）
const fsS = require("fs");
fsS.writeFileSync("a.txt", "hello", "utf8");
const out = fsS.readFileSync("a.txt", "utf8");
```

### 读取并解析 JSON 配置

```js
const fs = require("fs/promises");

const text = await fs.readFile("config.json", "utf8"); // 以字符串读取
const cfg = JSON.parse(text);
console.log(cfg.port);

const raw = await fs.readFile("logo.png"); // 省略编码，返回 Buffer
```

## `path` 模块

**用途**：以平台无关的方式处理文件与目录路径。

### 全局变量

> 以下 `__dirname` / `__filename` **仅存在于 CommonJS**（`require`）环境中。

- `__filename`：当前文件的**绝对路径**。
- `__dirname`：当前文件所在目录的**绝对路径**。

> **ES6（ESM，`import`）中没有这两个内置变量**，需用 `import.meta.url` 结合 `path` 手动构造

### ESM（ES6）中不存在 `__dirname` / `__filename`

当使用 ES Modules（`.mjs` 或 `"type": "module"`）时，`__dirname` 和 `__filename` 是**未定义**的，会直接报 `ReferenceError`。要用 `import.meta.url`（当前模块的 URL）配合 `url` 与 `path` 模块构造：

```js
import { fileURLToPath } from "url";
import path from "path";

// import.meta.url 形如: file:///C:/.../app.mjs
const __filename = fileURLToPath(import.meta.url); // 当前文件绝对路径
const __dirname = path.dirname(__filename);        // 当前文件所在目录绝对路径

console.log(__dirname);  // C:\...\project
console.log(__filename); // C:\...\project\app.mjs

const filePath = path.join(__dirname, "public", "index.html");
```

### ESM 导入不能省略文件后缀

CommonJS 的 `require("./math")` 会自动补全 `.js`，但 **ESM 的 `import` 必须写全文件扩展名**（`.js`/`.mjs` 等），省略会报 `ERR_MODULE_NOT_FOUND`：

```js
// CommonJS —— 可省略后缀
const { multiply } = require("./math"); // ✅

// ESM —— 必须写完整后缀，不可省略
import { multiply } from "./math.mjs"; // ✅
import { multiply } from "./math";     // ❌ 报错：ERR_MODULE_NOT_FOUND

// 相对路径导入同样要求显式后缀与 ./ 前缀
import { helper } from "./utils/helper.mjs"; // ✅
```

### 常用方法

| 方法 | 作用 | 示例返回 |
| --- | --- | --- |
| `path.basename(p)` | 路径的最后一部分（文件名） | `'app.js'` |
| `path.dirname(p)` | 路径的目录部分 | `/home/user/proj` |
| `path.extname(p)` | 文件扩展名 | `'.js'` |
| `path.join(...segments)` | 拼接路径段并归一化，修正多余斜杠 | `/a/b/c` |
| `path.resolve(...segments)` | 从当前工作目录解析为绝对路径 | `C:\...\a\b` |
| `path.parse(p)` | 返回含 `root`/`dir`/`base`/`ext`/`name` 的对象 | — |
| `path.format(obj)` | 由含 `dir`/`name`/`ext` 的对象构建路径字符串 | — |

### 完整示例

```js
const path = require("path");

console.log(__dirname);  // 当前文件所在目录绝对路径
console.log(__filename); // 当前文件绝对路径

const filePath = path.join(__dirname, "public", "index.html");
console.log(path.basename(filePath)); // index.html
console.log(path.extname(filePath));  // .html
console.log(path.dirname(filePath));  // .../public

const abs = path.resolve("src", "server.js"); // 从 cwd 解析为绝对路径

const parsed = path.parse("/home/user/app.js");
// { root: '/', dir: '/home/user', base: 'app.js', ext: '.js', name: 'app' }
```

### fs 与 path 配合的典型场景

```js
const fs = require("fs/promises");
const path = require("path");

// 读取资源目录下的文件（路径跨平台安全）
const publicDir = path.join(__dirname, "public");
const entries = await fs.readdir(publicDir);
console.log(entries);
```
