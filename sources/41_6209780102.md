## 最常用的绘图：直接用 df.plot

pandas内置绘图

```python
>>> df.plot(kind='line')    # 折线（看趋势）
>>> df.plot(kind='bar')     # 柱状（比大小）
>>> df.plot(kind='barh')    # 水平柱状
>>> df.plot(kind='pie')     # 饼图（占比）
>>> df.plot(kind='hist')    # 直方图（看分布）
>>> df.plot(kind='box')     # 箱线图（找离群）
>>> df.plot(kind='scatter') # 散点（看关系）
>>> plt.legend(); plt.show()   # 弹出窗口显示图形
```

> 每行都会在当前交互里画出一张图（`plt.show()` 之前可能不显示）。上面的 `kind` 参数决定了图形类型。

常见定制：

```python
>>> plt.xlabel('x'); plt.ylabel('y'); plt.title('标题')
>>> plt.xticks(rotation=0)          # 横轴刻度旋转
>>> plt.ylim(0, 600)                # 纵轴范围
>>> plt.savefig('chart.png')        # 先 savefig 再 show（show 后画布被释放）
>>> plt.show()
```

## 选图口诀

**看趋势→折线，比数据→柱状，定关系→散点，查占比→饼图，看分布→直方图，找离群→箱线图。**

## 箱线图（离群值判定）

离群值：数据 `< Q1 − 1.5×IQR` 或 `> Q3 + 1.5×IQR`（IQR = Q3−Q1）。

```python
>>> plt.boxplot(data, whis=1.5, showmeans=True)   # whis 改 3 检测极端离群值
>>> plt.show()
```

> 箱线图直接画出中位数、四分位距和离群点，是数据清洗阶段找"异常值"的首选。

## 真实分析场景：多图拼一张（分析报告标配）

真实分析中很少只画一张图，而是"一页多图"看全貌。用 `subplots` 一次画多个：

```python
>>> import pandas as pd, numpy as np
>>> import matplotlib.pyplot as plt
>>> df = pd.DataFrame({
...     'date': pd.date_range('2024-01-01', periods=30, freq='D'),
...     'sales': np.random.randint(80, 120, 30),
...     'cost':  np.random.randint(50, 90, 30),
... })
>>> fig, axes = plt.subplots(2, 2, figsize=(12, 8))   # 2 行 2 列

>>> # ① 销售趋势（折线）
>>> axes[0,0].plot(df['date'], df['sales'], marker='o')
>>> axes[0,0].set_title('销售趋势')

>>> # ② 销售额分布（直方图）
>>> axes[0,1].hist(df['sales'], bins=10, alpha=0.7)
>>> axes[0,1].set_title('销售额分布')

>>> # ③ 成本 vs 销售（散点，看相关）
>>> axes[1,0].scatter(df['cost'], df['sales'])
>>> axes[1,0].set_title('成本-销售关系')

>>> # ④ 销售累计（面积图，看总量增长）
>>> axes[1,1].plot(df['date'], df['sales'].cumsum())
>>> axes[1,1].set_title('累计销售')

>>> plt.tight_layout()   # 自动调整间距
>>> plt.show()
```

> **分析型选图思路**：看趋势→折线、看分布→直方图、看关系→散点、看占比→饼图、找离群→箱线、比大小→柱状。多图拼一张能在一屏内同时回答"趋势、分布、关系"三类问题，是做分析报告时的标准做法。
