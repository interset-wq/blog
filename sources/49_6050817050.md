
Linux 采用多用户权限管理模式，**root 是超级管理员**，拥有最大权限；普通用户在自身家目录内权限不受限，家目录外多为只读/执行。

## 用户与组

- **用户**：每个用户有唯一用户名与密码，登录时校验。
- **用户组**：具有相同特征用户的逻辑集合，方便批量授权。用户可加入多个组。

Linux 用 **UID**（用户 ID）、**GID**（组 ID）识别身份，用户名只是方便记忆。账号信息存于 `/etc/passwd`、`/etc/shadow`（密码）、`/etc/group`、`/etc/gshadow`。

## 用户与组管理

```bash
$ whoami            # 当前用户名
$ id                # 当前 UID / GID / 所属组
# 以下需 root 权限
# useradd testuser          # 创建用户
# useradd -m -s /bin/bash testuser   # 创建并建家目录、指定 shell
# passwd testuser           # 设置/修改密码
# useradd -g dev -G sudo testuser    # 指定初始组 -g、附加组 -G
# usermod -aG sudo testuser # 追加附加组（-a 保留原有组）
# userdel -r testuser       # 删除用户及家目录（-r）
# groupadd devgroup         # 创建组
# groupdel devgroup         # 删除组
```

Ubuntu 中给普通用户 sudo 权限：`# usermod -aG sudo testuser`。

## 权限位

`ls -l` 第一列共 10 个槽位，如 `drwxr-xr-x`：

- 第 1 位：文件类型（`d` 目录、`-` 普通文件、`l` 链接、`b` 块设备、`c` 字符设备）
- 第 2~4 位：所属用户（u）权限 `rwx`
- 第 5~7 位：所属组（g）权限
- 第 8~10 位：其它用户（o）权限

| 权限 | 针对文件 | 针对目录 |
|---|---|---|
| r (4) | 查看内容 | 列出目录内容 |
| w (2) | 修改内容 | 创建/删除/改名 |
| x (1) | 作为程序执行 | cd 进入 |

## 修改权限

数字法：r=4、w=2、x=1，每位用户用一个 0~7 的数字，如 `chmod 751` = `rwxr-x--x`。

```bash
$ chmod 755 script.sh          # u=rwx, g=rx, o=rx
$ chmod u=rwx,g=rx,o=x file    # 符号法
$ chmod -R 755 testdir/        # -R 递归应用到目录内全部内容
$ chmod a+x script.sh          # 给所有用户加执行权限
```

> 只有文件属主或 root 能修改权限。

## 修改属主 / 属组

```bash
# chown root file.txt          # 改属主
# chown root:dev file.txt      # 改属主与属组
# chown -R root testdir/       # 递归
# chgrp dev file.txt           # 仅改属组
```

## umask 与默认权限

`umask` 决定新建文件/目录的初始权限。文件默认最大 `666`、目录默认最大 `777`，减去 umask 得到实际权限：

```bash
$ umask        # 查看，常见 0022
$ umask 022    # 设置
```

## 切换用户与 sudo

```bash
$ su -              # 切换 root（- 加载完整环境）
$ su - testuser     # 切换指定用户
$ exit              # 退回原用户
$ sudo apt update   # 普通用户临时以 root 身份执行单条命令
```
