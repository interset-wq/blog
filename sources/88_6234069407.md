
HTML `<form>` 只负责把数据 POST 给服务器；Django 的 Form 框架多做三件事：

1. **校验（validate）**：字段类型、长度、必填、格式、跨字段规则、自定义规则。
2. **清洗（clean）**：把字符串转成正确的 Python 类型（`"2026-10-16"` → `datetime.date`，`"42"` → `int`）。
3. **渲染与回显**：自动生成 HTML 控件，校验失败时保留用户输入并在对应字段旁显示错误。

## Form vs ModelForm

| 维度 | `forms.Form` | `forms.ModelForm` |
|---|---|---|
| 字段来源 | 手动逐字段声明 | 从 Model 自动推导 |
| 用途 | 与模型无关（登录、搜索、联系我们、续借） | 直接对应某模型的增/改 |
| 保存 | 手动读 `cleaned_data` 处理 | `form.save()` 直接落库 |
| 校验 | 自己写 | 自动继承模型字段的 `max_length`、`unique`、`choices` 等约束 |
| 典型场景 | 登录、搜索、联系我们（非模型表单） | Learning Log 的 `TopicForm` / `EntryForm` |

**选择原则**：要落库的数据用 `ModelForm`（省力、校验自动）；与库无关或逻辑特殊的用 `Form`。

## Form 字段家族

### 常用字段类型

| 字段 | Python 类型 | 说明 |

| `NullBooleanField` | `Optional[bool]` | 三态：未选 / True / False |

| `ChoiceField` | `str` | 下拉单选，配 `choices=[(v, label), ...]` |

| `UUIDField` | `uuid.UUID` | UUID |

### 字段通用参数

```python
class ExampleForm(forms.Form):
    name = forms.CharField(
        max_length=100,
        label='你的名字',                          # 显示在 <label> 里
        label_suffix='：',                         # 标签后缀（默认 ':'）
        help_text='请输入全名，不超过 100 字',       # 字段下方帮助文本
        required=True,                             # 必填（默认 True）
        initial='张三',                            # 初始值（GET 时显示）
        disabled=False,                            # 禁用
        error_messages={'required': '名字不能为空'}, # 覆盖默认错误信息
        validators=[                               # 额外验证器
            RegexValidator(r'^[\u4e00-\u9fa5]+$', '只能输入中文'),
        ],
        widget=forms.TextInput(attrs={
            'class': 'form-control',
            'placeholder': '请输入名字',
        }),
    )
```

## 校验流程

### 一次 `is_valid()` 内部发生了什么

```
form.is_valid()
  │
  ├─ full_clean()
  │    ├─ 1. _clean_fields()
  │    │     对每个字段：to_python → validate → run_validators
  │    │     然后调用表单的 clean_<fieldname>()
  │    │     任一失败 → 把错误存到 self._errors[field]
  │    │
  │    ├─ 2. _clean_form()
  │    │     调用表单的 clean()（跨字段整体校验）
  │    │
  │    └─ 3. _post_clean()
  │          ModelForm 钩子：调用模型自身的 clean()
  │
  └─ 返回 self.is_bound and not self.errors
```

校验通过后，清洗后的数据统一放在 **`form.cleaned_data`**（dict，key 为字段名）；错误在 **`form.errors`**（一个 ErrorDict）。

### 字段级校验：`clean_<fieldname>`

方法名必须是 `clean_` + 字段名。在此之前，字段类型、`required`、`max_length`、validators 已经跑过；这里做业务规则。

```python
from django import forms
from django.core.exceptions import ValidationError
from django.utils.translation import gettext_lazy as _
from .models import Entry

PROGRESS_CHOICES = [('todo', '待办'), ('doing', '进行中'), ('done', '已完成')]


class EntryForm(forms.ModelForm):
    """Form to add or edit an entry under a topic."""
    progress = forms.ChoiceField(choices=PROGRESS_CHOICES)

    class Meta:
        model = Entry
        fields = ['text', 'progress']

    def clean_progress(self):
        value = self.cleaned_data['progress']

        # Check value is one of the allowed choices.
        if value not in [c[0] for c in PROGRESS_CHOICES]:
            raise ValidationError(_('Invalid progress value'))

        # Remember to always return the cleaned data.
        return value
```

要点：
- 从 `self.cleaned_data['字段名']` 取值（字段级校验已经通过，值是 Python 类型）。
- 不通过就 `raise ValidationError(_('...'))`。
- **必须 `return data`**，否则该字段的 `cleaned_data` 会被设为 `None`。

### 表单级校验：`clean()`

处理跨字段规则（"结束日期不能早于开始日期"、"密码与确认密码必须一致"）：

```python
class RangeForm(forms.Form):
    start = forms.DateField()
    end = forms.DateField()

    def clean(self):
        cleaned = super().clean()           # 先让父类/字段校验跑完
        start = cleaned.get('start')
        end = cleaned.get('end')
        if start and end and end < start:
            self.add_error('end', '结束日期必须晚于开始日期')
        return cleaned
```

- `self.add_error(field, message)`：`field=None` 时错误进入 `non_field_errors()`；指定字段名则挂到该字段下。
- 一定要 `return cleaned`，否则 `cleaned_data` 丢失。

### ValidationError 与 errors 结构

| API | 作用 |
|---|---|
| `ValidationError(message, code=None, params=None)` | 抛出校验错误；可带 `code` 便于模板分支 |
| `form.errors` | ErrorDict，按字段名分组 |
| `form.errors.as_data()` | 返回 `{field: [ValidationError, ...]}`，便于程序化判断 |
| `form.errors.get_json_data()` | 返回结构化 JSON |
| `form.non_field_errors()` | 来自 `clean()` / `add_error(None, ...)` 的整表错误 |
| `form.field.errors` | 某字段的错误列表（模板里用 `{{ field.errors }}`） |

### 自定义验证器

验证器是可复用的函数（或可调用对象），声明式挂在多个字段上：

```python
from django.core.exceptions import ValidationError
from django.utils.translation import gettext_lazy as _

def validate_even(value):
    if value % 2 != 0:
        raise ValidationError(_('%(value)s 不是偶数'), params={'value': value})

class MyForm(forms.Form):
    lucky_number = forms.IntegerField(validators=[validate_even])
```

内置常用验证器（`django.core.validators`）：`RegexValidator`、`EmailValidator`、`URLValidator`、`MinLengthValidator`、`MaxLengthValidator`、`MinValueValidator`、`MaxValueValidator`、`DecimalValidator`、`FileExtensionValidator`、`validate_image_file_extension`。

## ModelForm：从模型自动生成

### 真实示例

```python
from django import forms

from .models import Topic, Entry


class TopicForm(forms.ModelForm):
    class Meta:
        model = Topic
        fields = ['text']
        labels = {'text': ''}

class EntryForm(forms.ModelForm):
    class Meta:
        model = Entry
        fields = ['text']
        labels = {'text': ''}
        widgets = {'text': forms.Textarea(attrs={'cols': 80})}
```

### Meta 全部常用选项

| 选项 | 作用 |
|---|---|
| `model` | 关联的模型（必填） |
| `fields` | 白名单，列出表单包含的字段（**推荐**） |
| `exclude` | 黑名单，排除哪些字段（与 `fields` 二选一） |
| `widgets` | 自定义控件：`{'text': forms.Textarea(attrs={'cols': 80})}` |
| `labels` | 自定义标签：`{'text': ''}`（空串 = 不显示标签） |
| `help_texts` | 自定义帮助文本 |
| `error_messages` | 覆盖字段级错误信息：`{'title': {'required': '标题必填'}}` |
| `field_classes` | 为某字段换一个 form field 类 |
| `localized_fields` | 启用本地化（日期/数字按本地格式） |

> **安全约定**：始终用 `fields` 显式白名单。`exclude` 看似省事，但模型新增字段时会自动出现在表单里，可能把 `owner`、`is_admin` 这类敏感字段暴露给前端。外部字段一律用 `save(commit=False)` 手动赋值（见”文件上传”）。

### ModelForm 的字段级扩展

Meta 之外，可以在表单类里直接写字段覆盖或新增：

```python
class EntryForm(forms.ModelForm):
    # 显式声明一个字段，覆盖模型默认 widget
    text = forms.CharField(widget=forms.Textarea(attrs={'rows': 5}))

    class Meta:
        model = Entry
        fields = ['text', 'progress']
```

## 模板里渲染表单

### 整表快捷渲染

| 写法 | 渲染结果 |
|---|---|
| `{{ form.as_p }}` | 每个字段包一个 `<p>` |
| `{{ form.as_table }}` | 每个字段包 `<tr>`（最老的默认） |
| `{{ form.as_ul }}` | 每个字段包 `<li>` |
| `{{ form.as_div }}` | 每个字段包 `<div>`（Django 4+ 推荐，语义更干净） |
| `{{ form }}` | 等价 `as_table` |

最小可用模板：

```html
<form method="post">
  {% csrf_token %}
  {{ form.as_div }}
  <button type="submit">提交</button>
</form>
```

### 逐字段精细渲染

需要完全控制布局时：

```html
<form method="post">
  {% csrf_token %}
  {{ form.non_field_errors }}
  {% for field in form %}
    <div class="fieldWrapper">
      {{ field.errors }}
      {{ field.label_tag }}
      {{ field }}
      {% if field.help_text %}<p class="help">{{ field.help_text }}</p>{% endif %}
    </div>
  {% endfor %}
  <button type="submit">提交</button>
</form>
```

字段对象在模板里的可用属性：

| 表达式 | 含义 |
|---|---|
| `{{ field.label }}` | 标签文本 |
| `{{ field.label_tag }}` | 完整 `<label for="...">` |
| `{{ field.value }}` | 当前值 |
| `{{ field.errors }}` | 该字段错误（`<ul class="errorlist">`） |
| `{{ field.help_text }}` | 帮助文本 |
| `{{ field.html_name }}` | 表单字段名（提交时的 name） |
| `{{ field.is_hidden }}` | 是否隐藏字段 |
| `{{ field.field.required }}` | 是否必填 |

### 视图里的 FBV 黄金模式

```python
@login_required
def new_topic(request):
    """Add a new topic."""
    if request.method != 'POST':
        # No data submitted; create a blank form.
        form = TopicForm()
    else:
        # POST data submitted; process data.
        form = TopicForm(data=request.POST)
        if form.is_valid():
            new_topic = form.save(commit=False)
            new_topic.owner = request.user
            new_topic.save()
            return redirect('learning_logs:topics')

    # Display a blank or invalid form.
    context = {'form': form}
    return render(request, 'learning_logs/new_topic.html', context)
```

这套"GET 给空表单 / POST 绑定 `request.POST` → `is_valid()` → 处理 → redirect"是 FBV 处理表单的标准骨架。

```python
# 非模型表单：手动从 cleaned_data 读值
form = DateRangeForm(request.POST)
if form.is_valid():
    start = form.cleaned_data['start_date']
    end = form.cleaned_data['end_date']
    entries = Entry.objects.filter(date_added__range=(start, end))
```

非 ModelForm 没有 `save()`，所有写入都从 `form.cleaned_data['字段名']` 取。

### save(commit=False)：保存前注入外部字段

ModelForm 的 `save()` 默认直接落库。但有些字段**不应该出现在表单里**（否则用户能伪造），却必须在落库前有值：

```python
@login_required
def new_entry(request, topic_id):
    """Add a new entry for a particular topic."""
    topic = Topic.objects.get(id=topic_id)

    if request.method != 'POST':
        form = EntryForm()
    else:
        form = EntryForm(data=request.POST)
        if form.is_valid():
            new_entry = form.save(commit=False)
            new_entry.topic = topic
            new_entry.save()
            return redirect('learning_logs:topic', topic_id=topic_id)

    context = {'topic': topic, 'form': form}
    return render(request, 'learning_logs/new_entry.html', context)


@login_required
def edit_entry(request, entry_id):
    """Edit an existing entry."""
    entry = Entry.objects.get(id=entry_id)
    topic = entry.topic
    if topic.owner != request.user:
        raise Http404

    if request.method != 'POST':
        # Initial request; pre-fill form with the current entry.
        form = EntryForm(instance=entry)
    else:
        # POST data submitted; process data.
        form = EntryForm(instance=entry, data=request.POST)
        if form.is_valid():
            form.save()
            return redirect('learning_logs:topic', topic_id=topic.id)

    context = {'entry': entry, 'topic': topic, 'form': form}
    return render(request, 'learning_logs/edit_entry.html', context)
```

两个关键点：
- `save(commit=False)`：返回一个**还没写库**的模型实例，可以继续给它赋字段（`new_entry.topic = topic`、`new_topic.owner = request.user`），然后手动 `.save()`。
- `ModelForm(instance=obj)`：**编辑已有对象**；不传 `instance` 则是新建。POST 时要同时传 `instance=entry` 和 `data=request.POST`。

### 动态初始值

GET 时给表单预填值，有三种方式：

```python
# 方式一：视图里用 initial=（一次性）
form = TopicForm(initial={'text': '默认主题名'})

# 方式二：CreateView 类属性
class TopicCreateView(CreateView):
    model = Topic
    fields = ['text']
    initial = {'text': '默认主题名'}

# 方式三：在表单里覆盖 __init__，动态算
class RenewBookForm(forms.Form):
    renewal_date = forms.DateField()

    def __init__(self, *args, **kwargs):
        super().__init__(*args, **kwargs)
        self.initial['renewal_date'] = datetime.date.today() + datetime.timedelta(weeks=3)
```

## CSRF 与文件上传

### CSRF

所有 POST 表单必须在模板里写 `{% csrf_token %}`，否则 Django 返 403：

```html
<form method="post">
  {% csrf_token %}
  ...
</form>
```

这是 `CsrfViewMiddleware` 提供的跨站请求伪造防护。

### 文件上传

带文件的表单：
- 模板 `<form>` 必须加 `enctype="multipart/form-data"`；
- 视图里构造表单要传 `request.FILES`：`form = MyForm(request.POST, request.FILES)`。

```html
<form method="post" enctype="multipart/form-data">
  {% csrf_token %}
  {{ form.as_div }}
</form>
```

## Formsets：一页多表单

### formset_factory：裸表单集

一页处理 N 个同构表单（如一次录入 3 个作者）：

```python
from django.forms import formset_factory
from .forms import AuthorForm

AuthorFormSet = formset_factory(AuthorForm, extra=3)   # 3 个空表单

def manage_authors(request):
    if request.method == 'POST':
        formset = AuthorFormSet(request.POST)
        if formset.is_valid():
            for form in formset:
                if form.cleaned_data:        # 跳过完全空白的表单
                    form.save()
            return redirect('authors')
    else:
        formset = AuthorFormSet()
    return render(request, 'manage_authors.html', {'formset': formset})
```

### modelformset_factory：模型表单集

基于 ModelForm 的批量增删改：

```python
from django.forms import modelformset_factory
from .models import Entry

EntryFormSet = modelformset_factory(
    Entry,
    fields=['text', 'progress'],
    extra=2,
    max_num=5,
)

def view(request):
    FormSet = EntryFormSet(request.POST or None, queryset=Entry.objects.all())
    if request.POST and FormSet.is_valid():
        FormSet.save()
        return redirect('learning_logs:topics')
    return render(request, 'learning_logs/entries.html', {'formset': FormSet})
```

### inlineformset_factory：内联表单集

一对多关系的"主对象 + 多条子对象"一次编辑（如一个 Topic + N 条 Entry）：

```python
from django.forms import inlineformset_factory
from .models import Topic, Entry

EntryFormSet = inlineformset_factory(
    Topic,   # 父模型
    Entry,   # 子模型
    fields=['text', 'progress'],
    extra=1,
    can_delete=True,
)

def edit_topic(request, pk):
    topic = get_object_or_404(Topic, pk=pk)
    formset = EntryFormSet(request.POST or None, instance=topic)
    if request.POST and formset.is_valid():
        formset.save()
        return redirect('learning_logs:topic', pk=pk)
    return render(request, 'learning_logs/edit_topic.html', {'formset': formset})
```

### 关键参数与上下文

| 参数 | 作用 |
|---|---|
| `extra` | 额外的空表单数量 |
| `max_num` | 最多展示多少个表单（不含已存在的） |
| `can_order` | 是否允许排序（自动生成 `ORDER` 字段） |
| `can_delete` | 是否允许删除（自动生成 `DELETE` 复选框） |
| `validate_max` | 是否严格执行 `max_num` |
| `min_num` / `validate_min` | 最少表单数 |

模板里必须渲染 `{{ formset.management_form }}`（隐藏的 management 表单，记录总条数、是否删除等元信息），否则 formset 校验会失败：

```html
<form method="post">
  {% csrf_token %}
  {{ formset.management_form }}
  {% for form in formset %}
    {{ form.as_div }}
  {% endfor %}
  <button type="submit">保存</button>
</form>
```

## CBV 里的表单处理

通用类视图 `CreateView` / `UpdateView` / `FormView` 已经把表单骨架封装好了。对应关系：

| FBV 手写 | CBV 自动 |
|---|---|
| `form = MyForm()` GET | `FormView.get()` / `CreateView.get()` |
| `form = MyForm(request.POST)` POST | `FormView.post()` |
| `if form.is_valid(): ...` | `form_valid(form)` |
| `else: ...` | `form_invalid(form)` |
| `return redirect(...)` | `get_success_url()` |
| `form.save(commit=False); form.instance.x = ...; form.save()` | 覆盖 `form_valid`，先 `form.instance.x = ...` 再 `super().form_valid(form)` |
