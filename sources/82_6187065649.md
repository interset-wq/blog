## `<stdlib.h>` — 内存、转换、排序

内存分配、数字转换、排序查找、随机数等通用工具。

### 动态内存：`malloc` / `calloc` / `realloc` / `free`

```c
#include <stdio.h>
#include <stdlib.h>

int main(void) {
    // malloc：分配 n 个字节（内容未初始化）
    int *arr = (int *)malloc(5 * sizeof(int));
    if (!arr) return 1;               // 务必检查 NULL
    for (int i = 0; i < 5; i++) arr[i] = i;
    free(arr);                        // 用完释放，避免内存泄漏

    // calloc：分配并全部清零（比 malloc+memset 更方便）
    int *zero = (int *)calloc(5, sizeof(int));
    printf("%d\n", zero[3]);          // 0（已清零）
    free(zero);

    // realloc：扩容（保留原数据）
    int *grow = (int *)malloc(3 * sizeof(int));
    grow[0] = 100;
    grow = (int *)realloc(grow, 6 * sizeof(int));   // 扩到 6 个
    grow[3] = 400;
    printf("%d %d\n", grow[0], grow[3]); // 100 400（原数据保留）
    free(grow);
    return 0;
}
```

> **区别**：`malloc` 不初始化（可能是垃圾值），`calloc` 自动清零；`realloc` 在保留原内容的前提下扩容。三者失败都返回 `NULL`。

### 字符串 ↔ 数字转换：`atoi` / `strtol` / `strtod` / `atof`

```c
#include <stdio.h>
#include <stdlib.h>

int main(void) {
    int    i = atoi("42");           // 字符串 → int
    double d = atof("3.14");         // 字符串 → double
    long   l = strtol("123abc", NULL, 10);   // 进制可指定（10=十进制）

    // strtol 的 endptr：记录解析停在哪，便于提取"数字后面的部分"
    char *end;
    long v = strtol("42px", &end, 10);
    printf("num=%ld, rest=%s\n", v, end);   // num=42, rest=px

    printf("%d %.2f %ld\n", i, d, l);
    return 0;
}
```

> 建议优先用 `strtol`/`strtod`（能判断是否转换失败、拿到解析终点）；`atoi`/`atof` 简单但不能报错。

### 排序与查找：`qsort` / `bsearch`

```c
#include <stdio.h>
#include <stdlib.h>

// 比较函数（qsort 的"回调"）
int cmp_int(const void *a, const void *b) {
    return *(int *)a - *(int *)b;   // 升序
}

int main(void) {
    int arr[] = {3, 1, 4, 1, 5, 9, 2};
    int n = 7;

    qsort(arr, n, sizeof(int), cmp_int);   // 排序
    for (int i = 0; i < n; i++) printf("%d ", arr[i]);  // 1 1 2 3 4 5 9

    // bsearch：在已排序数组中查找
    int key = 4;
    int *found = (int *)bsearch(&key, arr, n, sizeof(int), cmp_int);
    if (found) printf("\nfound: %d\n", *found);   // found: 4
    return 0;
}
```

### 其他：`exit` / `abort` / `abs`

```c
#include <stdlib.h>

// exit(code)：正常退出程序，code 返回给操作系统（0 表示成功）
if (bad) exit(1);
// abort()：异常终止（立即中止）
int v = abs(-7);   // 绝对值 → 7
```

| 函数 | 作用 |
| --- | --- |
| `malloc` / `calloc` / `realloc` / `free` | 动态内存管理（分配/清零/扩容/释放） |
| `atoi` / `atol` / `atof` | 字符串 → int / long / double |
| `strtol` / `strtod` | 更稳健的字符串转换（可获取解析终点） |
| `qsort` / `bsearch` | 排序 / 二分查找（需自定义比较函数） |
| `rand` / `srand` | 伪随机数 / 设置种子 |
| `exit` / `abort` | 退出程序 |
| `abs` | 整型绝对值 |

### 随机数（`rand` / `srand`）

C 的随机数函数在 `<stdlib.h>` 中：`rand()` 返回一个 `0` 到 `RAND_MAX` 之间的**伪随机整数**，`srand()` 设置随机种子。

```c
#include <stdio.h>
#include <stdlib.h>
#include <time.h>

int main(void) {
    srand(time(NULL));              // 用当前时间做种子，每次运行结果不同
    int r = rand();                 // 0 ~ RAND_MAX
    printf("RAND_MAX = %d\n", RAND_MAX);   // 通常是 32767 或 2147483647
    printf("r = %d\n", r);
    return 0;
}
```

> 若不调用 `srand()`，默认种子为 1，每次运行得到的序列**相同**。想每次不同，通常用 `srand(time(NULL))` 初始化。

生成指定范围：

```c
int a = rand() % 100;          // 0 ~ 99
int b = rand() % 100 + 1;      // 1 ~ 100
double d = (double)rand() / RAND_MAX;          // 0.0 ~ 1.0
double e = 5.0 + (double)rand() / RAND_MAX * 10.0; // 5.0 ~ 15.0
```

**常见误区**：`rand() % n` 在 `n` 不能整除 `RAND_MAX+1` 时分布**不完全均匀**（低余数出现概率略高）。对要求不严的入门/练习足够，严格均匀可用下面的方法：

```c
// 均匀的 [0, n) 随机数（拒绝采样，避免取模偏差）
int rand_uniform(int n) {
    int limit = RAND_MAX - RAND_MAX % n;
    int r;
    do {
        r = rand();
    } while (r >= limit);   // 丢弃末尾不能整除的部分
    return r % n;
}
```

| 项 | 说明 |
| --- | --- |
| `rand()` | 返回 `[0, RAND_MAX]` 伪随机整数 |
| `srand(seed)` | 设种子；`srand(time(NULL))` 每次不同 |
| `rand() % n` | 生成 `[0, n)`，有轻微不均匀（可接受） |
| 均匀生成 | 用拒绝采样（见上） |
| 安全性 | `rand` 是伪随机、**不可用于加密**；需要密码学安全随机用系统接口（如 `/dev/urandom`、`getrandom`） |

## `<math.h>` — 数学函数

需在编译时链接数学库：`gcc main.c -o main -lm`。

```c
#include <stdio.h>
#include <math.h>

int main(void) {
    // 幂与根
    double root = sqrt(16.0);      // 4.0
    double cbrt_val = cbrt(27.0);  // 3.0
    double pw = pow(2, 10);        // 1024.0
    double rem = fmod(7.5, 2.0);   // 1.5（浮点取余）

    // 绝对值与取整
    double absv = fabs(-3.5);      // 3.5
    double fl = floor(3.7);        // 3.0（向下）
    double ce = ceil(3.2);         // 4.0（向上）
    double rd = round(3.5);        // 4.0（四舍五入）
    double tr = trunc(3.7);        // 3.0（截断，直接丢小数）

    // 对数与指数
    double lg = log(2.71828);      // ≈1.0（自然对数 ln）
    double lg10 = log10(100.0);    // 2.0（常用对数）
    double ex = exp(1.0);          // 2.71828（e^x）

    // 三角函数（角度需转弧度：rad = deg * M_PI / 180）
    double s = sin(3.14159 / 2);   // ≈1.0
    double c = cos(0);             // 1.0
    double t = tan(3.14159 / 4);   // ≈1.0
    double a = atan(1.0);          // π/4（反正切）

    printf("%.1f %.1f\n", root, pw);
    return 0;
}
```

| 函数 | 作用 |
| --- | --- |
| `sqrt` / `cbrt` | 平方根 / 立方根 |
| `pow` / `fmod` | 幂 / 浮点取余 |
| `fabs` | 绝对值 |
| `floor` / `ceil` / `round` / `trunc` | 向下 / 向上 / 四舍五入 / 截断取整 |
| `log` / `log10` / `exp` | 自然对数 / 常用对数 / e 的幂 |
| `sin` / `cos` / `tan` / `atan` | 三角函数（输入弧度） |
| `hypot(a, b)` | 计算 `sqrt(a²+b²)`（防溢出） |

> **角度转弧度**：`rad = deg * M_PI / 180`；`M_PI` 定义在 `<math.h>`（部分编译器需 `#define _USE_MATH_DEFINES` 或自行定义 `const double PI = 3.14159...`）。

## `<limits.h>` 与 `<stdint.h>` — 数值极限与定宽整型

```c
#include <stdio.h>
#include <limits.h>
#include <stdint.h>

int main(void) {
    // 各类型极限
    printf("%d\n", INT_MAX);        // 2147483647
    printf("%d\n", INT_MIN);        // -2147483648
    printf("%d\n", CHAR_BIT);       // 8（一个 char 的位数）

    // 定宽整型：保证跨平台位宽一致
    int32_t i32 = 100;              // 固定 4 字节有符号
    uint64_t big = 10000000000ULL;  // 固定 8 字节无符号
    printf("%lld\n", (long long)big);

    // 判断溢出：比较与 INT_MAX
    if (i32 < INT_MAX) i32++;
    return 0;
}
```

| 内容 | 作用 |
| --- | --- |
| `INT_MAX` / `INT_MIN` / `CHAR_BIT` | 各类型极限 / 位数 |
| `SHRT_MAX` / `LONG_MAX` / `LLONG_MAX` | short / long / long long 的极限 |
| `int32_t` / `uint64_t` | 定宽整型（跨平台保证位宽） |
| `intptr_t` / `size_t` | 指针大小 / 无符号大小类型 |

> **为什么需要定宽整型**：`int` 在不同平台可能是 16/32/64 位，写跨平台代码时用 `int32_t` 等可保证行为一致。C++ 同样支持这些类型（`<cstdint>`）。

## `<time.h>` 与 `<assert.h>`

### 计时与日期

```c
#include <stdio.h>
#include <time.h>

int main(void) {
    // 计时（秒）：clock 返回 CPU 时间
    clock_t start = clock();
    for (volatile int i = 0; i < 100000000; i++);
    clock_t end = clock();
    printf("elapsed: %.2f s\n", (double)(end - start) / CLOCKS_PER_SEC);

    // 当前时间戳（自 1970-1-1 起的秒数）
    time_t now = time(NULL);
    printf("timestamp: %ld\n", (long)now);

    // 时间戳 → 本地时间（结构化）
    struct tm *lt = localtime(&now);
    printf("year=%d month=%d day=%d\n",
           lt->tm_year + 1900, lt->tm_mon + 1, lt->tm_mday);

    // 格式化输出日期
    char buf[64];
    strftime(buf, sizeof(buf), "%Y-%m-%d %H:%M:%S", lt);
    printf("now: %s\n", buf);        // 如 2026-10-15 14:30:00

    // 两个时间戳差值（秒）
    time_t later = now + 3600;       // 一小时后
    printf("diff: %.0f s\n", difftime(later, now));   // 3600
    return 0;
}
```

### `assert` 断言

```c
#include <assert.h>

int main(void) {
    int x = 5;
    assert(x == 5);      // 条件为真，继续执行
    // assert(x == 10);  // 条件为假，中止并报告错误位置
    return 0;
}
```

| 内容 | 作用 |
| --- | --- |
| `time(NULL)` | 当前时间戳（秒） |
| `difftime(a, b)` | 两时间戳差值（秒） |
| `clock` / `CLOCKS_PER_SEC` | CPU 计时 |
| `localtime` / `mktime` | 时间戳 ↔ 结构化 `struct tm` |
| `strftime` | 格式化时间字符串（`%Y`年 `%m`月 `%d`日 `%H`时等） |
| `assert(expr)` | 条件为假则报错退出（调试用，可用 `-DNDEBUG` 关闭） |

## 这些库在 C++ 里的对应关系

C 标准库函数在 C++ 中**依然可用**（对应 C++ 头文件是去掉 `.h` 加 `c` 前缀，且都在 `std` 命名空间），但 C++ 通常有更安全、更简洁的替代：

| C 用法 | C++ 头文件 | 说明 |
| --- | --- | --- |
| `printf` / `scanf` | `<cstdio>` | 仍可用；但 C++ 更常用 `std::cout` / `std::cin` |
| `strlen` / `strcpy` | `<cstring>` | 仍可用；但 C++ 有 `std::string`（自动管理，不用管 `\0`） |
| `malloc` / `free` | `<cstdlib>` | 仍可用；但 C++ 用 `new` / `delete`（构造/析构） |
| `qsort` | `<cstdlib>` | 仍可用；但 C++ 更常用 `std::sort`（更安全、支持泛型） |
| `atoi` / `strtol` | `<cstdlib>` | 仍可用；但 C++ 更常用 `std::stoi` / `std::stoll` |
| `sqrt` / `pow` | `<cmath>` | 与 C 完全相同，直接 `std::sqrt` |
| `rand` | `<cstdlib>` | 仍可用；但 C++11 起推荐 `<random>` 的 `std::mt19937` |

```cpp
// C++ 风格替代示例
#include <iostream>
#include <string>
#include <vector>
#include <algorithm>

int main() {
    std::string s = "Hello";           // 替代 char[] + strcpy
    std::cout << s.size() << "\n";     // 替代 strlen

    std::vector<int> v = {3, 1, 4, 1, 5};
    std::sort(v.begin(), v.end());     // 替代 qsort，不用写比较函数

    int n = std::stoi("42");           // 替代 atoi
    return 0;
}
```
