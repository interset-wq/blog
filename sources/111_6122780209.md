
## 一、CSS 预处理器

**CSS 预处理器**是扩展标准 CSS 的工具，将带有扩展语法的代码编译成原生 CSS 文件。对复杂项目编写更简洁、可复用、减少重复且可扩展的 CSS 很有帮助。

- **功能**：提供**变量**、**混入（mixin）**、**嵌套（nesting）**和**选择器继承**等功能。
- **流行预处理器**：**Sass**、**Less**、**Stylus**。
- **潜在缺点**：
  - 编译 CSS 规则为标准 CSS 可能带来额外开销；
  - 编译后的代码可能难以调试。

## 二、Sass 概述

**Sass**（Syntactically Awesome Style Sheets，语法优美的样式表）是最流行的 CSS 预处理器之一。

Sass 支持的功能：**变量**、**嵌套 CSS 规则**、**模块**、**混入**、**继承**和基本**数学运算符**。

## 三、Sass 的两种语法

### 1. SCSS 语法

**SCSS**（Sassy CSS）扩展了 CSS 的基本语法，是 Sass 最广泛使用的语法，文件扩展名为 `.scss`。

定义和使用变量：

```scss
$primary-color: #3498eb;

header {
  background-color: $primary-color;
}
```

### 2. 缩进语法

缩进语法是 Sass 的原始语法，也称「Sass 语法」，扩展名为 `.sass`。不使用花括号和分号，靠缩进组织：

```sass
$primary-color: #3498eb

header
  background-color: $primary-color
```

> [!NOTE]
> 现代项目通常选择 **SCSS**（与 CSS 语法接近、迁移成本低）。缩进语法更简洁但写法不同。

## 四、变量

变量让颜色、尺寸等值集中定义，一处修改全局生效。

```scss
$primary: #3498eb;
$font-size: 16px;

.button {
  background: $primary;
  font-size: $font-size;
}
```

## 五、嵌套

嵌套让选择器结构更接近 HTML，减少重复父选择器：

```scss
.nav {
  display: flex;

  .item {
    padding: 8px;

    &:hover {   // & 引用父选择器 .nav .item
      color: $primary;
    }
  }
}
```

## 六、混入（Mixin）

**混入**允许你将多个 CSS 属性及其值组合在一个名称下，并在整个样式表中复用该 CSS 代码块。

定义混入 `center-flex`，包含三个用 flexbox 居中元素的属性：

```scss
@mixin center-flex {
  display: flex;
  justify-content: center;
  align-items: center;
}
```

使用混入：

```scss
section {
  @include center-flex;
  height: 500px;
  background-color: #3289a8;
}
```

混入也可带参数（类似函数）：

```scss
@mixin box($w, $h: auto) {
  width: $w;
  height: $h;
}

.card {
  @include box(200px, 120px);
}
```

## 七、继承（Extend）

通过 `@extend` 让一个选择器继承另一个选择器的全部样式：

```scss
.base-btn {
  padding: 10px 20px;
  border-radius: 6px;
}

.btn-primary {
  @extend .base-btn;
  background: $primary;
}
```

## 八、运算与模块

- **运算**：`width: 100% / 3`、`font-size: $base * 1.5`。
- **模块（@use）**：把样式拆成多个文件，用 `@use 'variables'` 引入，避免全局污染。

```scss
// _variables.scss
$primary: #3498eb;

// main.scss
@use 'variables';
body { color: variables.$primary; }
```

## 九、如何在项目中使用 SCSS

### 1. 安装 Sass

```bash
# npm 全局安装（或按项目安装到 devDependencies）
$ npm install -g sass
$ sass --version
```

### 2. 独立编译

命令行把 `.scss` 编译为 `.css`：

```bash
# 单文件：scss → css
$ sass styles.scss styles.css

# 监听模式：源文件变化自动编译
$ sass --watch styles.scss:styles.css

# 压缩输出（生产环境）
$ sass styles.scss styles.css --style=compressed
```

### 3. 在构建工具中集成

- **Vite**：内置 Sass 支持，安装 `sass` 依赖后在 `style.scss` 中引入，`vite` 会自动编译并注入。

```bash
$ npm install -D sass
```

Vite 默认开箱即用，无需额外配置；如需定制（如全局注入变量、启用旧版 `@import`），在 `vite.config.ts` 中配置 `css.preprocessorOptions`：

```ts
// vite.config.ts
import { defineConfig } from "vite";

export default defineConfig({
  css: {
    preprocessorOptions: {
      scss: {
        additionalData: `@use "@/styles/variables" as *;`, // 每个 scss 自动注入变量模块
        api: "modern-compiler", // 使用 dart-sass 现代编译器
      },
    },
  },
});
```

```scss
// src/styles/main.scss
body { color: $primary; }   // variables 已被自动注入，无需手动 @use
```

```ts
// 入口文件引入
import "./styles/main.scss";
```

- **Webpack**：配合 `sass-loader` + `css-loader` 使用。

```bash
$ npm install -D sass sass-loader css-loader
```

```js
// webpack.config.js
module: {
  rules: [
    { test: /\.scss$/, use: ["style-loader", "css-loader", "sass-loader"] },
  ],
}
```

### 4. 目录组织建议

```text
src/
  styles/
    _variables.scss     # 变量（文件名下划线：只被引用，不单独编译）
    _mixins.scss        # 混入
    main.scss           # 入口，@use 引入各模块
```

> [!NOTE]
> 以 `_` 开头的部分文件（partial）不会单独编译成 CSS，只能被其他文件 `@use` / `@import` 引入。

## 核心总结

1. 预处理器扩展 CSS：提供变量、混入、嵌套、继承、运算与模块化。
2. Sass 有两种语法：**SCSS**（最常用）与缩进语法。
3. 混入 `@mixin` + `@include` 复用代码块；`@extend` 实现继承；`&` 引用父选择器。
4. 用 `@use` 组织模块化样式。
