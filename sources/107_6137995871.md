
## React 中的事件处理(Event handling)

合成事件系统（Synthetic Event System）：这是 React 处理事件的机制。它是对原生事件（如点击click、键盘按下keydown、表单提交事件submit）的一层封装。React 中的事件处理器采用小驼峰命名规范（例如：onClick、onSubmit 等）。

React 中的事件处理函数通常以 `handle` 为前缀，表明其负责处理事件，例如 handleClick 或 handleSubmit。事件处理函数一般作为prop传递给元素（不需要括号），事件类型作为属性。

```html
<!-- 纯html事件 -->
<button onclick="alert('Button clicked!')">Click Me</button>
```

```jsx
// 使用react实现
function handleClick() {
  console.log("Button clicked!");
}

<button onClick={handleClick}>Click Me</button>;
```

当用户操作触发事件时，React 会向处理函数传递一个合成事件对象(Synthetic Event object)。该对象的行为与原生 JavaScript 中的 `Event` 对象非常相似，提供了 `type`、`target` 和 `currentTarget` 等属性。

例如，要阻止 onSubmit 事件中浏览器刷新等默认行为，可以调用 `preventDefault()` 方法：

```jsx
function handleSubmit(event) {
  event.preventDefault();
  console.log("Form submitted!");
}

<form onSubmit={handleSubmit}>
  <input type="text" />
  <button>Submit</button>
</form>;
```

使用 `event.stopPropagation()` 阻止事件冒泡到父元素。

也可以像这样将处理函数包装在箭头函数中：

```jsx
function handleDelete(id) {
  console.log("Deleting item:", id);
}

<button onClick={() => handleDelete(1)}>Delete Item</button>;
```

## useState Hook

在 React 中，状态是包含组件数据的对象。当状态更新时，组件会重新渲染。React 将状态视为不可变的，这意味着不应直接修改状态。

状态表示React组件中的动态的数据，例如：从输入框获取的用户输入、从API获取的数据等。

钩子是特殊的函数。

`useState()` 钩子，允许你在函数组件中声明状态变量。

```js
import { useState } from "react";
const [stateVariable, setStateFunction] = useState(initialValue);
```

其中：

- `stateVariable` 存储当前状态的变量值
- `setStateFunction`（设置函数）用于更新状态变量
- `initialValue` 用于设置初始状态

```jsx
import { useState } from "react";

function Counter() {
  const [count, setCount] = useState(0);

  return (
    <div>
      <h2>{count}</h2>

      <button onClick={() => setCount(count - 1)}>Decrement</button>
      <button onClick={() => setCount(count + 1)}>Increment</button>
    </div>
  );
}

export default Counter;
```

## 渲染与 React 组件

在 React 中，渲染是指组件出现在用户界面（UI，通常是浏览器）中的过程。渲染过程包含三个阶段：触发`trigger`、渲染`render`和提交`commit`。

- 触发阶段发生在 React 检测到某些内容发生变化，且用户界面可能需要更新时。这种变化通常由状态或属性prop的更新引起。
- 触发后，React 进入渲染阶段。在此阶段，React 会重新计算组件，并确定要显示的内容。为实现这一点，React 会使用一个被称为虚拟 DOM 的轻量级“真实”DOM 副本。借助虚拟 DOM，React 可以快速检查组件中需要更改的部分。
- 提交阶段是 React 将虚拟 DOM 中准备好的更改应用到真实 DOM 的过程。换句话说，这是你在屏幕上看到最终结果的阶段。

## 更新状态中的对象和数组

React中的state是不可变的，不能直接修改。

更新状态中的对象：如果需要更新状态中的对象，应先创建一个新对象或复制现有对象，然后为这个新对象设置状态。放入状态的任何对象都应被视为只读的。以下示例展示了如何设置用户的姓名、年龄和城市。handleChange 函数用于处理用户信息的更新：

```jsx
import { useState } from "react";

function Profile() {
  const [user, setUser] = useState({ name: "John Doe", age: 31, city: "LA" });

  const handleChange = (e) => {
    const { name, value } = e.target;

    setUser((prevUser) => ({...prevUser, [name]: value}));
  };

  return (
    <div>
      <h1>User Profile</h1>
      <p>Name: {user.name}</p>
      <p>Age: {user.age}</p>
      <p>City: {user.city}</p>

      <h2>Update User Age </h2>
      <input type="number" name="age" value={user.age} onChange={handleChange} />

      <h2>Update User Name </h2>
      <input type="text" name="name" value={user.name} onChange={handleChange} />

      <h2>Update User City </h2>
      <input type="text" name="city" value={user.city} onChange={handleChange} />
    </div>
  );
}

export default Profile;
```


更新状态中的数组：更新状态中的数组时，无法使用 push() 或 pop() 等方法直接修改数组。相反，应在更新状态时创建一个新数组：

```jsx
const addItem = () => {
  const newItem = {
    id: items.length + 1,
    name: `Item ${items.length + 1}`,
  };

  // Creates a new array
  setItems((prevItems) => [...prevItems, newItem]);
};
```

如果想要从数组中删除元素，应使用 filter() 方法，该方法会过滤掉要删除的元素后返回一个新数组：

```jsx
const removeItem = (id) => {
  setItems((prevItems) => prevItems.filter((item) => item.id !== id));
};
```

## useRef Hook

原生JS需要使用 `getElementById()` `querySelector()` 等方法访问DOM，在React中可以通过 ref 属性在 React 中访问 DOM 节点。

```js
import { useRef } from "react";

const Focus = () => {
  const inputRef = useRef(null);

  const handleFocus = () => {
    if (inputRef.current) {
      inputRef.current.focus();
    }
  };

  return (
    <div>
      <input ref={inputRef} type="text" placeholder="Enter text" />
      <button onClick={handleFocus}>Focus Input</button>
    </div>
  );
};

export default Focus;
```

## useEffect Hook

在 React 中，“副作用side effect”，简称effect，指的是发生在组件渲染过程之外的任何操作。即 React 不直接作为 UI 渲染一部分处理的任何操作。常见示例包括获取数据、更新浏览器标签页的标题、读取或写入浏览器的本地存储、获取用户位置等等。这些与外部世界交互的操作被称为副作用。React 提供了 useEffect 钩子来处理这些副作用。useEffect 允许你在组件渲染或更新后运行一个函数。

```js
import { useEffect } from "react";

useEffect(() => {
 // Your side effect logic (usually a function) goes here
}, [dependencies]);
```

副作用函数会在组件渲染后运行，而可选的`dependencies`参数则控制副作用的运行时机。

依赖项 `dependencies` 可以是一个包含“响应式值reactive values”（状态、属性、函数、变量等）的数组、空数组，或者完全省略。以下是这些选项对 useEffect 工作方式的影响：

- 如果`dependencies`是包含一个或多个响应式值的数组，副作用会在这些值发生变化时运行。
- 如果`dependencies`是空数组，`useEffect` 仅在组件首次渲染时运行一次。
- 如果省略 `dependencies`，副作用会在组件每次渲染或更新时运行。

```jsx
import { useState, useEffect } from "react";

const Counter = () => {
  const [count, setCount] = useState(0);

  useEffect(() => {
    document.title = `The current count is ${count}`;
    console.log('component renders');
  }, [count]);

  return (
    <div
      style={{
        display: "flex",
        alignItems: "center",
        flexDirection: "column",
      }}
    >
      <h2>{count}</h2>
      <div>
        <button onClick={() => setCount(count + 1)}>Increase</button>
        <button onClick={() => setCount(count - 1)}>Decrease</button>
      </div>
    </div>
  );
};

export default Counter;
```

需要注意的是，如果你设置的副作用在组件渲染生命周期结束后仍然持续存在，那么你可能需要另一个函数来在组件完成渲染或更新后 “清理” 这个副作用函数。

例如，若你的副作用函数使用了 setInterval()、添加了 window.addEventListener() 这类事件监听器，或是建立了与服务器的连接，你就需要分别通过清理函数执行 clearInterval()、window.removeEventListener() 和断开服务器连接的操作。

```jsx
useEffect(() => {
  // Your side effect logic here
  return () => {
    // Cleanup logic here (optional)
  };
}, [dependencies]);
```

```jsx
useEffect(() => {
  const handleScroll = () => {
    // Handle scroll logic
  };
  window.addEventListener("scroll", handleScroll);

  return () => {
    window.removeEventListener("scroll", handleScroll);
  };
}, []);
```


## 创建自定义Hook

自定义钩子允许你从组件中提取可复用的逻辑，例如数据获取、状态管理、切换功能以及跟踪在线状态等副作用。在 React 中，所有内置钩子都以 `use` 开头，因此你的自定义钩子也应遵循此约定。例如：

- 若用于获取数据(fetches data)，可命名为 useFetch；
- 若用于切换(toggles)某一状态的开 / 关，可命名为 useToggle；
- 若实现了防抖(debouncing)功能，useDebounce 是合适的命名。

防抖（Debouncing）是一种限制函数执行频率的编程技巧。其原理是：等待用户停止执行某个操作并达到指定时长后，才真正执行目标函数。例如在搜索框场景中，防抖不会在用户每输入一个字符时就发起 API 请求，而是等待用户停止输入（比如）500 毫秒后再执行请求。

以下是创建 useDebounce 防抖钩子的示例：

```jsx
function useDebounce(value, delay) {
  const [debouncedValue, setDebouncedValue] = useState(value);

  useEffect(() => {
    const handler = setTimeout(() => {
      setDebouncedValue(value);
    }, delay);

    return () => {
      clearTimeout(handler);
    };
  }, [value, delay]);

  return debouncedValue;
}

export { useDebounce };
```
