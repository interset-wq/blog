
```python
import numpy as np
import pandas as pd
```

> 对应 SQL：`WHERE`、`IN`、`LIKE`、`CASE WHEN`、`CAST`、计算列。这是最高频的一类操作。本文统一用下面这张小表演示：

```python
>>> df = pd.DataFrame({'name': ['Alice','Bob','Carol','Dave'],
...                    'age':  [25, 30, 17, 65],
...                    'city': ['北京','上海','北京','广州']})
>>> df
    name  age city
0  Alice   25  北京
1    Bob   30  上海
2  Carol   17  北京
3   Dave   65  广州
```

## 布尔索引筛选行（WHERE）

条件写在 `[]` 里：

```python
>>> df[df['age'] > 25]                             # WHERE age > 25
    name  age city
1    Bob   30  上海
3   Dave   65  广州
>>> df[(df['age'] > 25) & (df['city'] == '北京')] # 或 df.query('age > 25 and city=="北京"')   # AND ← 用 & 且每个条件要加括号
Empty DataFrame  # 没有同时满足的行
>>> df[(df['age'] < 20) | (df['age'] > 60)]         # OR  ← 用 |
    name  age city
2  Carol   17  北京
3   Dave   65  广州
>>> df[~(df['age'] > 25)]                           # NOT ← 用 ~
    name  age city
0  Alice   25  北京
2  Carol   17  北京
```

> ⚠️ **易错点**：pandas 里 `AND/OR` 必须写成 **`&` / `|`**（不是 `and` / `or`），并且每个比较条件都要用括号括起来，否则报错。

```python
# SELECT name, age FROM students WHERE student_id = 101
>>> df.loc[df.student_id == 101, ['name','age']] 
# 或
>>> df[df.student == 101][['name', 'age']]
```

## IN / NOT IN（isin）

```python
>>> df[df['name'].isin(['Alice','Bob'])]      # WHERE name IN (...)
    name  age city
0  Alice   25  北京
1    Bob   30  上海
>>> df[~df['name'].isin(['Alice','Bob'])]     # WHERE name NOT IN (...)
    name  age city
2  Carol   17  北京
3   Dave   65  广州
```

### 真题实例：找"没有下过单的顾客"

```python
# customers: id, name
# orders: id, customerId
# 找出 id 不在 orders.customerId 的顾客，列重命名为 customer
>>> df = customers[~customers.id.isin(orders.customerId)][['name']]
>>> df = df.rename(columns={'name': 'customer'})
# SQL: SELECT name AS customer FROM customers
#      WHERE id NOT IN (SELECT customerId FROM orders)
```

> 注：此题也可用 `merge + how='left'` 后筛 `isna()` 解

## 字符串匹配（LIKE / 正则）

```python
>>> df
    name  age city
0  Alice   25  北京
1    Bob   30  上海
2  Carol   17  北京
3   Dave   65  广州
>>> df[df['name'].str.contains('A')]      # LIKE '%A%'
    name  age city
0  Alice   25  北京 # 'A' 出现在 Alice 里；大小写敏感，Bob 无 A → 只中 Alice
>>> df[df['name'].str.startswith('Al')]   # LIKE 'Al%'
    name  age city
0  Alice   25  北京
>>> df[df['name'].str.endswith('e')]      # LIKE '%e'
    name  age city
0  Alice   25  北京
1   Dave   65  广州
```

```python
# 长度判断（SQL: CHAR_LENGTH > 15）→ 逐元素返回布尔 Series
>>> df['name'].str.len()
0    5
1    3
2    5
3    4
Name: name, dtype: int64
# 正则提取（如从 "15k-30k" 抽数字）
>>> pd.Series(['15k-30k','10k']).str.extract(r'(\d+)')
    0
0  15
1  10
# 大小写转换
>>> df['name'].str.upper()
0    ALICE
1      BOB
2    CAROL
3     DAVE
Name: name, dtype: object
```

### 真题实例：字符串切片处理、正则、包含

```python
# 首字母大写其余小写（SQL: CONCAT(UPPER(SUBSTR(name,1,1)), LOWER(SUBSTR(name,2)))）
>>> users['name'] = users['name'].str[0].str.upper() + users['name'].str[1:].str.lower()
# 正则匹配邮箱格式（SQL: REGEXP_LIKE / ~）
>>> users[users['mail'].str.match(r'^[a-zA-Z][a-zA-Z0-9_.-]*\@leetcode\.com$')]
# 条件以 "DIAB1" 开头（SQL: LIKE 'DIAB1%' OR LIKE '% DIAB1%'）
>>> patients[patients.conditions.str.startswith('DIAB1')
...         | patients['conditions'].str.contains(' DIAB1', regex=False)]
```

> 正则提示：`str.match` 从头匹配；`str.contains(regex=True)` 找子串（默认即正则，可用 `regex=False` 关闭转义）。

## CASE WHEN / 条件生成列

```python
# 二分支：age >= 30 → 'old'，否则 'young'
>>> df['level'] = np.where(df['age'] >= 30, 'old', 'young')
>>> df
    name  age city level
0  Alice   25  北京  young
1    Bob   30  上海    old
2  Carol   17  北京  young
3   Dave   65  广州    old

# 多分支（嵌套 np.where）
>>> df['level'] = np.where(df['age']>=60, 'senior',
...               np.where(df['age']>=30, 'middle', 'junior'))
>>> df['level']
0    junior
1    middle
2    junior
3    senior
Name: level, dtype: object

>>> # mask：满足条件的值被替换（其余保留）
>>> df['level'] = df['age'].mask(df['age'] >= 30, 'old')
>>> df['level']
0    young
1      old
2    young
3      old
Name: level, dtype: object

# map：字典 / 函数 一一映射（类似 CASE WHEN 的等价分支）
>>> df['level'] = df['age'].map(lambda a: 'old' if a >= 30 else 'young')
>>> df['level']
0    young
1      old
2    young
3      old
Name: level, dtype: object
```

### 真题实例：工资分级（条件计数）

```python
# accounts: id, income
# 分三档统计人数（SQL 用 UNION + CASE WHEN 计数）
>>> low_count     = (accounts['income'] < 20000).sum()
>>> average_count = ((accounts['income'] >= 20000) & (accounts['income'] <= 50000)).sum()
>>> high_count    = (accounts['income'] > 50000).sum()
>>> ans = pd.DataFrame({
...     'category': ['Low Salary','Average Salary','High Salary'],
...     'accounts_count': [low_count, average_count, high_count],
... })
```

## 类型转换与列改名（CAST / 重命名）

```python
>>> df['age'] = df['age'].astype(float)          # 转类型
>>> df
    name   age city
0  Alice  25.0  北京
1    Bob  30.0  上海
2  Carol  17.0  北京
3   Dave  65.0  广州

>>> df = df.astype({'age': int})                  # 按字典批量转类型
>>> df = df.rename(columns={'name':'姓名', 'age':'年龄'})   # 改列名
>>> df
     姓名  年龄 city
0  Alice   25  北京
1    Bob   30  上海
2  Carol   17  北京
3   Dave   65  广州

>>> df.rename(index={0:'r0'})                     # 改行名
     姓名  年龄 city
r0  Alice   25  北京
```

## 逐元素处理：map / apply / transform

```python
>>> df['年龄'].map(lambda x: x * 2)     # 逐元素（Series 专用，可传字典）
0    50
1    60
2    34
3   130
Name: 年龄, dtype: int64
>>> df['年龄'].apply(lambda x: x * 2)   # 逐元素（与 map 类似）
0    50
1    60
2    34
3   130
Name: 年龄, dtype: int64
>>> df.apply(lambda row: row['a'] + row['b'], axis=1)   # 按行处理整行
>>> df['col'].transform(lambda x: x - x.mean())         # 变换（不减少行数）

>>> # DataFrame 逐元素：新版用 .map（.applymap 已在 pandas 2.3 移除）
>>> df.map(lambda x: x + 1)
```

### 真题实例：按行 apply 算 bonus

```python
# employees: id, name, salary
# id 是奇数 且 name 不以 'M' 开头 → bonus=salary，否则 0（SQL: CASE WHEN）
>>> employees['bonus'] = employees.apply(
...     lambda x: x['salary'] if (x['id'] % 2 != 0 and not x['name'].startswith('M')) else 0,
...     axis=1,
... )
>>> df = employees[['id', 'bonus']]
```
