
单页应用程序（Single page applications，SPAs）是一类只加载单个 HTML 页面的 Web 应用程序，会在用户与应用交互时动态更新该页面，而无需重新加载整个页面。单页应用程序使用 JavaScript 管理应用状态并渲染内容。

单页应用程序存在的一些问题包括：

- 屏幕阅读器难以处理动态更新的内容。
- 用户在应用内导航时，URL 不会发生变化，这使得为特定页面添加书签、回溯或分享变得困难。
- 如果应用规模较大，初始加载时间可能会很慢，因为所有资源都需要提前加载。

React 是一款流行的用于构建用户界面和 Web 应用程序的 JavaScript 库。

React 的核心概念是创建可复用的 UI 组件，这些组件能够随着数据变化独立更新和渲染。

React 允许开发者根据应用状态描述 UI 应呈现的样子。当数据或状态发生变化时，React 会更新并渲染相应的组件。

JSX注释 `{/* */}`

在HTML中挂载React组件 `ReactDOM.render(componentToRender, targetNode)`

- `componentToRender` 需要挂载到HTML的React组件
- `targetNode` 组件挂载到的位置，一般是root

## React 组件(Components)

组件是 React 应用程序的构建块，允许开发者将复杂的用户界面分解为更小、易于管理的部分。

组件命名使用大驼峰

UI 是通过 JSX（JavaScript 语法的扩展）来描述的，它允许开发者在 JavaScript 中编写类 HTML 的代码。

组件本质上是返回一段 UI 的 JS 函数或类。例如：

创建组件：

```jsx
function Greeting() {
  const name = 'Anna';
  return <h1>Welcome, {name}!</h1>;
}
```

在index.html中应用组件：

```html
<Greeting />
```

## 导入和导出

### 默认导出

React 组件可以从一个文件导出，然后导入到另一个文件中。

```jsx
// City.js
function City() {
  return <p>New York</p>;
}

export default City;

// 或
export default function City() {
  return <p>New York</p>;
}
```

```jsx
// App.js
import City from './City';

function App() {
  return (
    <div>
      <h1>My favorite city is:</h1>
      <City />
    </div>
  );
}
```

### 命名导出

```js
// Animals.jsx
export function Cat() {
  return <h2>Mr. Whiskers</h2>;
}

export function Dog() {
  return <h2>Fido</h2>;
}
```

```js
import { Cat, Dog } from './Animals';
// 导入时也可为模块命名
import { Cat as Kitty } from './Animals';
```

### 混合使用

一个文件只能有一个默认导出

```js
// Animals.jsx
// 默认导出
export default function Cat() {
  return <h2>Mr. Whiskers</h2>;
}
// 命名导出
export function Dog() {
  return <h2>Fido</h2>;
}
```

```js
import Cat, { Dog } from './Animals';
```

## 在 React 组件中传递属性props

在 React 中，props（properties 的缩写）是一种将数据从父组件传递到子组件的方式。这种机制是创建可复用且动态的 UI 元素所必需的。

props 可以是任何 JavaScript 值，例如：数字、字符串、布尔值、对象、元组等。要从父组件向子组件传递 props，只需在父组件的 JSX 中使用子组件时，将 props 作为属性添加即可。

```jsx
// Parent component
function Parent() {
  const name = 'Anna';
  return <Child name={name} />;
}

// Child component
function Child(props) {
  return <h1>Hello, {props.name}!</h1>;
}
```

你可以在将 props 转换为对象后，使用扩展运算符（`...`）传递多个 props。

```jsx
// Parent component
function Parent() {
  const person = {
    name: 'Anna',
    age: 25,
    city: 'New York'
  };
  return <Child {...person} />;
}
```

## 条件渲染

React 中的条件渲染允许你创建动态的用户界面。它用于根据应用程序中的特定条件或状态显示不同的内容。

在 React 中有多种条件渲染内容的方式。

### `if`语句

```jsx
function Greeting({ isLoggedIn }) {
  if (isLoggedIn) {
    return <h1>Welcome back!</h1>;
  }
  return <h1>Please sign in</h1>;
}
```

### 三元运算符

```jsx
function Greeting({ isLoggedIn }) {
  return (
    <div>
      {isLoggedIn ? <h1>Welcome back!</h1> : <h1>Please log in</h1>}
    </div>
  );
}
```

### 逻辑与 `&&`

```jsx
function Greeting({ user }) {
  return (
    <div>
      {user && <h1>Welcome, {user.name}!</h1>}
    </div>
  );
}
```

## 列表渲染

可以使用 JS 数组的 `map()` 方法遍历项目数组，并返回一个由 JSX 元素组成的新数组来渲染列表。

```jsx
function NameList({ names }) {
  return (
    <ul>
      {names.map((name, index) => (
        <li key={`${name}-${index}`}>{name}</li>
      ))}
    </ul>
  );
}
```

务必记住为每个列表项提供唯一的 `key`，以帮助 React 管理更新和渲染工作，不推荐使用元素索引或 `Math.random()`生成的伪随机数作为 key，如果是数据库中的数据，一般使用数据库中的id等作为key，也常用 `crypto.randomUUID()`或库 `uuid`生成唯一标识符。


## React 中的内联样式

React 中的内联样式允许你使用 JavaScript 对象将 CSS 样式直接应用于 JSX 元素。

要在 React 中应用内联样式，可以在 JSX 元素上使用 `style` 属性。该属性接受一个对象，其中键是驼峰式命名的 CSS 属性，值是对应的属性值。

```jsx
function Button({ buttonText }) {
function Greeting() {
  return (
    <h1
      style={{ color: 'blue', fontSize: '24px', backgroundColor: 'lightgray' }}
    >
      Hello, world!
    </h1>
  );
}

export default Greeting;
```

你也可以将样式提取到一个单独的对象中，然后在 style 属性中引用它：

```jsx
function Greeting() {

  const styles = {
    color: 'blue',
    fontSize: '24px',
    backgroundColor: 'lightgray'
  };

  return <h1 style={styles}>Hello, world!</h1>;
}

export default Greeting;
```

内联样式支持动态样式设置，允许你根据 props 或状态有条件地应用样式。

```jsx
function Greeting({ isImportant }) {

  const styles = {
    color: isImportant ? 'red' : 'black',
    fontSize: isImportant ? '24px' : '16px'
  };

  return <h1 style={styles}>Hello, world!</h1>;
}

export default Greeting;
```
