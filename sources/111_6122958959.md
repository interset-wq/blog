
## 一、什么是 CSS 自定义属性

**CSS 自定义属性**（Custom Properties），也称 **CSS 变量**，是由 CSS 作者定义的、包含要在整个文档中重用的特定值的实体。它是**原生 CSS 特性**，不需要任何预处理器即可使用。

```css
:root {
  --bg-color: white;
  --text-color: black;
}
```

- 变量名以 `--` 开头，如 `--bg-color`。
- 使用 `var(--bg-color)` 引用。
- 声明在 `:root` 上即为全局变量，任何选择器都可访问。

> 优点：更高效、可维护、灵活的样式表；尤其在**主题设计**中非常有用。

## 二、变量作用域与级联

CSS 变量遵循**级联和继承**规则——在某个选择器内重新声明即可局部覆盖，无需新类名：

```css
:root {
  --bg-color: white;
  --text-color: black;
}

.dark-theme {
  --bg-color: #333;
  --text-color: white;
}

body {
  background-color: var(--bg-color);
  color: var(--text-color);
}
```

```html
<body>
  <!-- 默认主题 -->
  <div>普通内容</div>

  <!-- 套用 dark-theme 后，内部所有 var() 引用自动切换 -->
  <div class="dark-theme">暗色内容</div>
</body>
```

关键特性：`body` 只引用 `var(--bg-color)`，**具体颜色由祖先元素的变量定义决定**——这就是级联的力量，也是运行时动态换肤的基础。

## 三、var() 回退值

使用自定义属性时，可通过 `var()` 的第二个参数提供**回退值**（fallback），当变量未定义或无效时使用：

```css
.button {
  background-color: var(--main-color, #3498db);
}
```

- 若 `--main-color` 未定义，则回退到 `#3498db`。
- 也可嵌套回退：`var(--a, var(--b, red))`。

## 四、@property 规则

`@property` 是更强大的 CSS 特性，允许开发者**定义自定义属性的类型**，从而更好地控制其行为，包括**动画方式**和**初始值**。

### 语法

```css
@property --property-name {
  syntax: '<type>';
  inherits: true | false;
  initial-value: <value>;
}
```

| 字段 | 说明 |
|---|---|
| `--property-name` | 自定义属性名，必须以 `--` 开头 |
| `syntax` | 属性类型：`<color>`、`<length>`、`<number>`、`<percentage>`、`<angle>` 等 |
| `inherits` | 是否从父元素继承值 |
| `initial-value` | 默认值（初始值） |

### 示例：悬停平滑动画的渐变

`@property` 让 `--gradient-angle` 有了明确类型（`<angle>`），浏览器才能在 `transition` 中**插值动画**：

```html
<div class="gradient-box"></div>
```

```css
@property --gradient-angle {
  syntax: "<angle>";
  inherits: false;
  initial-value: 0deg;
}

.gradient-box {
  width: 100px;
  height: 100px;
  background: linear-gradient(var(--gradient-angle), red, blue);
  transition: --gradient-angle 0.5s;
}

.gradient-box:hover {
  --gradient-angle: 90deg;
}
```

> [!IMPORTANT]
> 没有 `@property` 时，CSS 变量被视为「任意值」，无法被 `transition` 平滑过渡。`@property` 声明了类型（`<angle>`），浏览器才知道如何插值（0deg → 90deg）。

## 五、运行时动态修改（JavaScript）

CSS 变量可在运行时用 JS 读写，这是实现动态主题、用户偏好设置的关键：

```js
// 读取
const root = document.documentElement;
const bg = getComputedStyle(root).getPropertyValue("--bg-color");

// 写入（整个页面即时生效）
root.style.setProperty("--bg-color", "#3498db");
```

结合 `prefers-color-scheme` 媒体查询，可自动适配系统亮/暗模式：

```css
:root { --bg: white; --text: black; }

@media (prefers-color-scheme: dark) {
  :root { --bg: #111; --text: #eee; }
}
```

## 六、CSS 变量 vs SCSS 变量

这是很多人的困惑：**SCSS 也能定义变量，CSS 原生也支持变量，二者关系是什么？**

| 维度 | SCSS 变量 | CSS 变量 |
|---|---|---|
| 处理时机 | **编译期**（构建时） | **运行期**（浏览器） |
| 产物 | 编译后**消失**，值被写死进 CSS | 保留在 CSS 中，运行时可变 |
| 作用域 | 词法作用域（Sass 内部） | 级联作用域，随 DOM 继承 |
| 动态性 | 静态，编译后不可改 | 动态，JS / 媒体查询 / 主题可改 |
| 类型 | 无类型，编译期计算 | 无默认类型；`@property` 可声明类型 |
| 用途 | 编译期复用、计算、DRY | 运行时主题、动态交互、级联 |
| 能否动画 | 不能 | 配 `@property` 可过渡动画 |

### 结论：不是替代关系，而是互补

- **SCSS 变量**适合「编译期就定死」的工程化复用——设计令牌、计算尺寸、构建时优化，编译后无运行时开销。
- **CSS 变量**适合「运行期才决定」的动态场景——主题切换、用户配置、JS 联动、响应式。

**实际组合使用**：用 SCSS 定义设计令牌，输出为 CSS 变量，既得编译期管理，又得运行期灵活性：

```scss
// _tokens.scss —— 用 SCSS 管理，产出 CSS 变量
$primary: #3498eb;
$font-base: 16px;

:root {
  --primary: #{$primary};
  --font-base: #{$font-base};
  --space: 8px;
}
```

```css
/* 编译产物：运行时消费者 */
body { color: var(--primary); }
.button { margin: var(--space); }
```

## 核心总结

1. **CSS 变量**是原生特性，`--name` 声明、`var()` 引用，遵循级联继承，天然支持**运行时主题切换**。
2. `var(--x, fallback)` 提供回退值，增强健壮性。
3. **`@property`** 给变量声明类型（`<angle>`、`<color>` 等），使其可参与 `transition` 动画。
4. **JS 可读写** CSS 变量（`setProperty` / `getPropertyValue`），配合媒体查询实现亮暗主题。
5. **CSS 变量 vs SCSS 变量**：一个是运行期、一个是编译期，互补而非互斥；工程上常「SCSS 管定义、CSS 变量管运行时」。
