
## 基本网络参数

| 参数 | 作用 |
|---|---|
| IP 地址 | 标识网卡接口，由网络号 + 主机号组成 |
| 子网掩码 | 确定网络部分的位数 |
| 网关 | 跨区域/跨网段通信 |
| DNS | 域名与 IP 互相映射 |

## 查看网络

```bash
$ ip a            # 查看网卡与 IP（现代推荐）
$ ip route        # 查看路由/默认网关
$ ifconfig        # 传统命令（需 net-tools 包）
$ ss -tulnp       # 查看监听端口（推荐，替代 netstat）
$ netstat -anp    # 查看端口占用（需 net-tools）
$ hostname        # 查看/设置主机名（hostnamectl set-hostname 修改）
```

网络接口命名：`eth0` 以太网、`lo` 回环（127.0.0.1）、`wlan0` 无线。回环接口 `lo` 用于本机内进程通信，不接真实网络。

## DNS 解析

解析顺序：先查本机 `/etc/hosts`（静态），再查 `/etc/resolv.conf` 中列出的 DNS 服务器（动态）。

```bash
$ cat /etc/hosts          # 本地主机名映射
$ cat /etc/resolv.conf    # DNS 服务器配置
$ getent hosts example.com   # 查询解析结果
$ nslookup example.com    # DNS 查询
```

## 测试连通性

```bash
$ ping 8.8.8.8            # 测试 IP 连通性
$ ping -c 4 example.com   # 只测 4 次
$ traceroute example.com  # 追踪数据包路径
$ curl -I https://example.com   # 查看 HTTP 响应头
$ curl https://example.com      # 发送请求/下载
```

## 网络诊断思路

1. 本机环回：`ping 127.0.0.1`（网卡是否正常）
2. 网关：`ping <网关IP>`（本网段是否通）
3. 公网：`ping 8.8.8.8`（外网是否通）
4. DNS：`nslookup example.com`（域名解析是否正常）
5. 端口：`ss -tulnp | grep 22`（服务是否监听）

## DHCP

DHCP（动态主机配置协议）为局域网设备自动分配 IP、网关、DNS。DHCP 客户机无固定 IP，接口上下线时动态获取/释放。接口配置中 `BOOTPROTO=dhcp` 即启用 DHCP（RHEL 系）。Ubuntu 桌面默认由 NetworkManager 管理，常用 `nmcli`：

```bash
$ nmcli dev status                # 设备状态
$ nmcli connection show           # 连接配置
$ nmcli con up "Wired"            # 启用连接
```

## 特殊 IP

- `127.0.0.1`：本机 localhost。
- `0.0.0.0`：表示所有 IP；绑定端口时表示监听所有接口，放行规则中表示允许任意 IP。

## WSL 网络

WSL2 默认 NAT 模式，拥有独立虚拟网卡；`wsl --list --verbose` 查看；可通过 `localhost` 从 Windows 直接访问 WSL 内服务。镜像网络模式可让 WSL 与 Windows 共享 IP（`.wslconfig` 中 `networkingMode=mirrored`）。
