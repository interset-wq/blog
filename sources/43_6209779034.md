
> 对应 SQL 窗口函数（`ROW_NUMBER`/`RANK`/`LAG`/`LEAD`/移动均线）和日期函数（`YEAR`/`MONTH`/`DATE_PART`）。统一用这张表演示：

```python
>>> import pandas as pd
>>> df = pd.DataFrame({'city': ['北京','北京','上海','上海','北京'],
...                    'sales':[100, 80, 90, 120, 110]})
>>> df
  city  sales
0  北京    100
1  北京     80
2  上海     90
3  上海    120
4  北京    110
```

## 排名类（组内 / 全局）

```python
>>> df['rk'] = df['sales'].rank(method='dense', ascending=False)   # 全局 DENSE_RANK
>>> df
  city  sales  rk
0  北京    100   3
1  北京     80   4
2  上海     90   3
3  上海    120   1
4  北京    110   2

>>> df['rk'] = df.groupby('city')['sales'].rank(method='dense', ascending=False)  # 组内排名
>>> df
  city  sales  rk
0  北京    100   2
1  北京     80   3
2  上海     90   2
3  上海    120   1
4  北京    110   1

>>> df['rn'] = df.groupby('city').cumcount() + 1                 # 组内行号 ROW_NUMBER
>>> df
  city  sales  rn
0  北京    100   1
1  北京     80   2
2  上海     90   1
3  上海    120   2
4  北京    110   3
```

> 力扣经典"每个部门工资第 N 高"：`df.groupby('dept')['salary'].rank(method='dense', ascending=False)`，再筛 `rk==N`。

## 取每组的"最大 / 第 N"行

```python
>>> idx = df.groupby('city')['sales'].idxmax()    # 每组最大值所在行索引
>>> idx
city

上海    3
dtype: int64
>>> df.loc[idx]

>>> df.sort_values('sales', ascending=False).groupby('city').head(1)   # 组内 Top1

```

## 移位 / 差分 / 环比（LAG / LEAD / 前一行）

```python
>>> df['prev'] = df['sales'].shift(1)      # 上一行（LAG）  负数=下一行（LEAD）
>>> df
  city  sales  prev
0  北京    100   NaN
1  北京     80  100.0
2  上海     90   80.0
3  上海    120   90.0
4  北京    110  120.0

>>> df['diff'] = df['sales'].diff()        # 与上一行之差
>>> df['diff']
0     NaN
1   -20.0
2    10.0
3    30.0
4   -10.0
Name: diff, dtype: float64
>>> df['pct']  = df['sales'].pct_change()  # 环比百分比
>>> df['pct']
0         NaN
1   -0.200000
2    0.125000
3    0.333333
4   -0.083333
Name: pct, dtype: float64

>>> df['prev'] = df.groupby('city')['sales'].shift(1)   # 组内上一条（更常见，组间不串）
>>> df
  city  sales  prev
0  北京    100   NaN
1  北京     80  100.0
2  上海     90   NaN   # 组内第一条为 NaN
3  上海    120   90.0
4  北京    110   80.0
```

> 注意 `groupby.shift` 只在**组内**错位，组与组之间不会串——这是做"每个客户上次消费"类题的正确姿势。

## 真实数据分析场景：时间序列分析

力扣只考"按日期取数"，但**真实的时间序列分析**通常要算趋势、周期、同比环比、移动平均。这在金融（股价）、运营（DAU）、销售（日订单）里是核心能力：

```python
>>> # 造一份按日的销售数据
>>> idx = pd.date_range('2024-01-01', periods=30, freq='D')
>>> df = pd.DataFrame({'date': idx, 'sales': range(100, 130)})   # 每天递增
>>> df
         date  sales
0  2024-01-01    100
1  2024-01-02    101
2  2024-01-03    102
...       ...    ...
28 2024-01-29    128
29 2024-01-30    129
[30 rows x 2 columns]

>>> # ① 移动平均：平滑波动，看趋势（股价/销量的标配）
>>> df['ma7'] = df['sales'].rolling(7).mean()      # 7 日均线
>>> df['ma30'] = df['sales'].rolling(30).mean()    # 30 日均线（周期更长更平滑）
>>> df
         date  sales        ma7
0  2024-01-01    100        NaN
1  2024-01-02    101        NaN
2  2024-01-03    102        NaN
3  2024-01-04    103        NaN
4  2024-01-05    104        NaN
5  2024-01-06    105        NaN
6  2024-01-07    106  103.000000  # (100..106)/7
...       ...    ...        ...
29 2024-01-30    129  123.000000

>>> # ② 环比 / 累计
>>> df['环比'] = df['sales'].pct_change()           # 与前一天比的变化率
>>> df['累计'] = df['sales'].cumsum()               # 本月累计（月报常用）

>>> # ③ 按周/月重采样聚合（日 → 周报、月报）
>>> df.set_index('date')['sales'].resample('W').sum()   # 按周汇总
>>> df.set_index('date')['sales'].resample('M').mean()  # 按月求平均

>>> # ④ 时间差：计算"距上次购买间隔"（客户复购分析）
>>> #    （数据里有 per customer 时：df.groupby('customer')['date'].diff().dt.days）
```

> 真实分析里的"看趋势"基本 = 数据转成时间索引 → `rolling` 平滑 → `resample` 归并到周/月 → 画折线。力扣不考但任何业务报表都会用到。
