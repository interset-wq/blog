这是一个基于GitHub Issues的静态博客系统，通过GitHub Actions自动将Issues渲染为静态网站，部署到GitHub Pages。

🚀 完全自动化

Issue创建/编辑时自动触发构建和部署，无需手动操作。

📝 GFM支持

完整的GitHub Flavored Markdown支持，任务列表、表格、代码高亮等。

🎨 原生前端

不使用任何CDN资源，完全自定义，响应式设计。

💬 评论系统

集成Giscus评论系统，基于GitHub Discussions。

技术栈

🐍

Python

后端渲染器，处理Markdown和模板

📦

PyGitHub

GitHub官方Python库，获取Issues数据

🎨

Jinja2

模板引擎，生成HTML页面

⚡

GitHub Actions

自动化构建和部署

🌐

GitHub Pages

静态网站托管

💬

Giscus
